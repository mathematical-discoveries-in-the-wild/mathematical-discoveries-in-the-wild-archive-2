# Complete cyclic-group hypercontractivity characterization

Status: `literature_already_answered_full_characterization`.

## Answer

The open arbitrary-order scope in arXiv:2512.03489 is explicitly completed by
Gan Yao's arXiv:2605.30867. For every `n>=4`, the sharp Log–Sobolev constant is
`2`, and

`||P_t f||_q <= ||f||_p` if and only if
`t >= (1/2) log((q-1)/(p-1))`.

Xie–Zhang, arXiv:2606.02847, independently prove the same sharp LSI and
hypercontractivity theorem by a different method.

The packet upgrades the status to a characterization for every cyclic order.
The exceptional group `Z_3` does not obey the universal threshold; its exact
constant for every `1<p<q<infinity` was determined in arXiv:2602.17248 by a
unique two-equation system. Since `P_t=T_{exp(-t)}`, its optimal time is the
negative logarithm of that exact constant. The `Z_2` case is classical.
