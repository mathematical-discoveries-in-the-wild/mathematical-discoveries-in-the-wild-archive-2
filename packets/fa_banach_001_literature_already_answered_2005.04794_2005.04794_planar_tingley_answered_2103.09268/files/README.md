# Planar Tingley problem answered by arXiv:2103.09268

Status: `literature_already_answered`.

The source paper is María Cueto-Avellaneda and Antonio M. Peralta, *Can one
identify two unital JB*-algebras by the metric spaces determined by their sets
of unitaries?*, arXiv:2005.04794. In its introduction (page 1), it states that
Tingley's problem remained open even for two-dimensional normed spaces.

Taras Banakh, *Every 2-dimensional Banach space has the Mazur-Ulam property*,
arXiv:2103.09268, explicitly formulates Tingley's problem as Problem 1.1 and
proves in Theorem 1.3 that every two-dimensional Banach space has the
Mazur-Ulam property. Its abstract and introduction explicitly say this resolves
Tingley's problem in the class of two-dimensional Banach spaces.

This is a direct later-literature answer, not a new proof. It concerns only the
introductory two-dimensional Tingley statement. The source paper's title
question about unitary sets is answered by the source paper itself, while
Tingley's problem in arbitrary dimension remains outside this packet.
