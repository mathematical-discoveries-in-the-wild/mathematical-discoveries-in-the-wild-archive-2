# Interval counterexample to the optimal-constant power law

Status: `full_counterexample_likely_valid`.

This packet disproves Conjecture 5.8 of arXiv:2203.02425.  On `(0,pi)` at
`p=2`, the sharp constants satisfy `C_10=1` and `C_20<1`, rather than
`C_20=C_10^2`.

- `main.tex` — packet source.

- `code/check_clamped_beam.py` — optional numerical orientation.
- `code/crop_source.py` — reproducible source crop.
- `novelty.md` and `verification_report.md` — search and audit records.

The proof itself uses only trace theory, two sharp one-dimensional Poincaré
inequalities, compactness, and their equality cases.
