# Full-sequence convergence for Steiner symmetrals

Candidate full solution of Problem 1 in arXiv:2102.07103.

If one subsequence of successive Steiner symmetrizations converges in
Hausdorff distance to the equal-volume centered ball, then the whole sequence
does. The centered circumradius is nonincreasing; subsequential convergence
forces it to approach the ball radius, and equal volume converts the shrinking
outer shell into full Hausdorff convergence.
