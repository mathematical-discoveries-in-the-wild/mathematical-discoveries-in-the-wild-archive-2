# Hilbert-space inverse generator problem: literature resolution

Status: `literature_answer_verified`

The explicit Hilbert-space question in arXiv:1809.04743v1 is answered negatively by arXiv:2608.06272v1, Theorem 1.2(i). The latter constructs a bounded operator with dense range on a separable Hilbert space whose semigroup is bounded and strongly stable, while the closed densely defined inverse does not generate any C0-semigroup.

This is a literature-resolution packet, not an original result of this run. The resolving paper was submitted on 6 August 2026 and is currently arXiv version 1.
