\section{Source question}

Larsen and Nelson's \emph{The Johnson--Lindenstrauss lemma is optimal for
linear dimensionality reduction} proves an optimal lower bound when the
embedding is linear.  Section~4 (Discussion), PDF page~7, then identifies the
next problem: obtain a lower bound
\[
 m=\Omega\!\left(\min\{n,\varepsilon^{-2}\log N\}\right)
\]
which also applies to nonlinear maps.  The introduction describes the
underlying question---whether some point set forces the Johnson--Lindenstrauss
dimension for arbitrary embeddings---as a major open problem.

\section{Later answer}

The same authors' subsequent arXiv:1609.02094 removes linearity. Its
Theorem~2 (PDF page~2) states that for integers $n,d\geq2$ and
\[
 \varepsilon\in
 \left(\frac{\log^{0.5001}n}{\sqrt{\min\{n,d\}}},1\right),
\]
there is an $n$-point set $X\subset\mathbb R^d$ such that every map
$f:X\to\mathbb R^m$ satisfying
\[
 (1-\varepsilon)\lVert x-y\rVert_2^2
 \leq \lVert f(x)-f(y)\rVert_2^2
 \leq (1+\varepsilon)\lVert x-y\rVert_2^2
 \qquad(x,y\in X)
\]
must obey
\[
 m=\Omega\!\left(\varepsilon^{-2}
                 \log(\varepsilon^2 n)\right).
\]
The abstract gives the cleaner consequence
$m=\Omega(\varepsilon^{-2}\log n)$ in its stated near-full parameter range and
explicitly contrasts this with the previously known result for linear maps.
Thus the central issue raised by arXiv:1411.2404---whether nonlinear
embeddings evade the JL lower bound---was answered negatively.

\centering

\caption{Theorem 2 of arXiv:1609.02094, PDF page 2.}

The 2017 revision also discusses Alon and Klartag's subsequent
all-range lower-bound refinement.  The sharp parameter expression naturally
involves $\log(2+\varepsilon^2n)$, so this status note does not claim that every
literal formula suggested in the 2014 discussion holds unchanged at endpoint
scales.
