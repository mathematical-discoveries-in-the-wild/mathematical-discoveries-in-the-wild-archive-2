# Random-forcing questions from arXiv:1909.09387 are answered

This literature-status packet records that arXiv:2110.04568, a later paper by
the same authors, explicitly answers Questions 6.4 and 6.13 of
arXiv:1909.09387.

- Theorem 4.6 of the answer paper: adding a random real makes every infinite
  ground-model Boolean algebra lose both the Nikodym and Grothendieck
  properties.  Thus random forcing does not preserve the
  Vitali--Hahn--Saks property, answering Question 6.13 negatively.
- Corollary 5.3: `d<nik=gr` in the random model.  Since
  `nik,gr<=vhs`, this answers Question 6.4 positively for
  `nik`, `gr`, and `vhs`.
