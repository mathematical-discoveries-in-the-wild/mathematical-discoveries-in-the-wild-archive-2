## Logical checks

1. The later Theorem 4.6 applies to every infinite ground-model Boolean
   algebra and any forcing adding a random real; it concludes failure of
   both the Nikodym and Grothendieck properties.
2. The Vitali--Hahn--Saks property implies the Nikodym and Grothendieck
   properties, so failure of either rules it out.  This gives a stronger
   negative answer to source Question 6.13.
3. The later Corollary 5.3 gives `d<nik=gr` in the random model.
4. The source records `nik,gr<=vhs`, so the same model also has `d<vhs`.
5. Random measure-algebra forcing is `omega^omega`-bounding, and Theorem 4.6
   applied to the infinite ground-model algebra `P(omega)^V` answers the
   particular clause of Question 6.4.
