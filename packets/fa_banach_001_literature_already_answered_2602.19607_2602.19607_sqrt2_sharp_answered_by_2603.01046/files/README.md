# The `sqrt(2)` question in arXiv:2602.19607 was answered by arXiv:2603.01046

Status: `literature_already_answered`

Jean-Christophe Bourin and Eun-Young Lee ask in Question 2.6 of *Triangle inequalities for the operator symmetric modulus* (arXiv:2602.19607) whether the factor `sqrt(2)` in their eigenvalue and symmetric-norm estimates is best possible.

Teng Zhang's later paper *Operator symmetric moduli and sharp triangle inequalities* (arXiv:2603.01046) explicitly reproduces this question and answers it affirmatively. Theorem 2.5 gives two rank-one real `3 x 3` matrices attaining equality for the operator norm; Remark 2.6 observes that the same example settles the eigenvalue estimate by taking `j=0`. Direct sums with a zero block cover every dimension at least three.

The lane's independent numerical search found the same regular-tetrahedron construction, up to signs and relabelling, before the bounded novelty search found Zhang's paper. It is therefore a rediscovery, not a new result.
