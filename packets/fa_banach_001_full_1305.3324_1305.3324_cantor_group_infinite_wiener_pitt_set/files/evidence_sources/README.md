# Evidence sources

## Original question

Przemysław Ohrysko and Michał Wojciechowski, *On the relationships between
Fourier–Stieltjes coefficients and spectra of measures*, Studia Mathematica
221 (2014), 117–140, arXiv:1305.3324.

- Question location: Section 7, Final Remarks, item 5, journal page 25.
- Stable publisher PDF: <https://www.impan.pl/shop/publication/transaction/download/product/90239>
- Local copy: `../source_paper.pdf`.

## Decisive supporting theorem

Przemysław Ohrysko, Tom Sanders, and Michał Wojciechowski,
*Wiener–Pitt sets for compact Abelian groups*, Journal of Fourier Analysis and
Applications 32 (2026), Article 30, arXiv:2510.24578,
DOI `10.1007/s00041-026-10239-1`.

- Theorem 11: quantitative nearest-integer rounding for real functions in
  `A(F)` on finite abelian groups.
- Theorem 6: extension to compact groups only when the rounded support is
  finite; the present packet replaces that finite-support step specifically
  for the Cantor group by finite quotients and a weak-star limit.
- Theorems 2 and 12 in the supporting paper concern strongly continuous
  norm-one measures and do **not** themselves answer the original question.
- Official accepted manuscript: <https://ora.ox.ac.uk/objects/uuid%3A23b1a9d4-8095-4a6e-9c4c-b88aebfc1a06>
- Local copy: `../supporting_paper_2510.24578.pdf`.
