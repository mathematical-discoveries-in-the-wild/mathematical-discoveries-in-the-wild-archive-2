# Exact annular Agler norm and attainment for matrix Laurent binomials

Status: `candidate partial result — likely valid; human review requested`

Source: Radomił Baran, Piotr Pikul, Hugo J. Woerdeman, and Michał Wojtylak,
*Contractive realization theory for the annulus and other intersections of
discs on the Riemann sphere*, arXiv:2504.03236, Corollary 5.2 and the paragraph
following it on PDF page 13.

## Result

For every `0<r<R`, every pair of integers `p>q`, and all matrices
`A,B in M_n(C)`, the rational bidisk-extension infimum for

\[
 F(z)=z^pA+z^qB
\]

is attained.  The packet gives an explicit rational polynomial lift and the
exact annular Agler norm

\[
 \|F\|_{\mathcal T_{A_{R,r}}}
 =\max_{|\omega|=1}\|a_pA+\omega a_qB\|,
\]

with the natural outer/inner boundary amplitudes `a_p,a_q` specified by the
signs of the powers.

This strictly extends the source's special case `R=1`, scalar coefficients
`A=B=1`, and mixed powers `p=k>0>q=-l`: it allows all matrix sizes, arbitrary
matrix coefficients, arbitrary annuli, all integer two-term supports, and
gives the exact norm.  The packet also records attainment for two broad
one-sided rational classes.

## Main mechanism

For mixed powers `p=k>0>q=-l`, use a cyclic weighted shift of size `k+l`:
the first `k` weights equal `R` and the last `l` weights equal `r`.  It belongs
to the annular operator class.  Both `T^k` and `T^{-l}` send one chosen input
coordinate to the same output coordinate with the exact outer and inner
amplitudes.  Rotating `T` sweeps every relative coefficient phase, so this
single compression gives precisely the supremum norm of the canonical bidisk
lift.  Same-sign powers reduce to scalar boundary operators.

## Scope

This is a substantial partial classification, not a full answer to the
source's question for arbitrary rational matrix functions.  Mixed Laurent
polynomials with three or more exponents remain unresolved.  In particular,
the source example `z+z^{-1}+1` on `A_{1,1/2}` is not decided here.  Eight
upgrade attempts, including compactness, realization-degree, quotient,
counterexample, and affine-example routes, are documented in the companion
attempt note.

## Verification

The proof is self-contained in `main.tex` and `solution_packet.pdf`.  From
this packet directory, run

```bash
conda run --no-capture-output -n sandbox python code/verify_weighted_shift.py
```

The script checks the weighted-shift orientation, its outer and inverse norm
constraints, the decisive matrix compression, phase identity, and lift
restriction in representative dimensions.  It is a transcription check, not
the proof.
