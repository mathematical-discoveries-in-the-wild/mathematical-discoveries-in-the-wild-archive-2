# Questions 3.2 answered by arXiv:2103.10288

Status: `literature_already_answered`

## Source questions

Aron, Garcia, Pellegrino, and Teixeira, *Reflexivity and non-weakly null
maximizing sequences*, arXiv:1906.02162, Questions 3.2 on PDF page 9, ask
whether WMP is stable under isomorphic changes of the domain/range and whether
reflexivity is equivalent to WMP.

## Explicit later answer

Dantas, Jung, and Martinez-Cervantes, *Some remarks on the weak maximizing
property*, arXiv:2103.10288, explicitly say they answer Questions 3.2.
Corollary 2.3 (PDF pages 4-5) constructs reflexive spaces `E1,E2,E3`, all
isomorphic to `ell_2`, such that `(ell_2,E1)`, `(E2,ell_2)`, and `E3` fail
WMP. Since `(ell_2,ell_2)` has WMP, this disproves isomorphic invariance in
both variables and supplies the requested common-domain example. Since `E3`
is reflexive and fails WMP, reflexivity is not equivalent to WMP.

The source's distinct `L_p,L_q` question is only partially answered by the
later paper and is outside this status packet.
