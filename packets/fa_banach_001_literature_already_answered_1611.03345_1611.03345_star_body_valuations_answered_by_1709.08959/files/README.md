# Continuous valuations on star bodies: both open questions answered

Status: `literature_already_answered (Questions 7.5 and 7.6)`

Tradacete and Villanueva ask on PDF page 23 of arXiv:1611.03345:

- Question 7.5: is every radial continuous valuation on star bodies
  uniformly continuous on bounded sets?
- Question 7.6: does their integral representation hold for every star body?

Their follow-up arXiv:1709.08959 answers both affirmatively:

- Theorem 3.8 (PDF page 11) proves uniform continuity on bounded sets for the
  extension to bounded Borel star sets, hence in particular for star bodies.
- Theorem 1.1 (PDF page 2) gives the integral representation for every star
  set with bounded Borel radial function, which is stronger than Question 7.6.
