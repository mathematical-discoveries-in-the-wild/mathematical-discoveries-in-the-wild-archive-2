# Finite-rank necessity for the Dritschel--Rovnyak criterion

This packet gives a candidate strong partial answer to the open question
following Theorem 4.3 of arXiv:0903.3639.

Main result: if a bounded positive factorable operator function has an outer
factor with finite-dimensional output, then the source's analytic and
injective multiplier conditions are necessary.  Consequently the conditions
are necessary in every finite-dimensional Hilbert space and for every
factorable function of uniformly finite rank on an arbitrary separable
Hilbert space.

The unrestricted infinite-dimensional problem is not claimed solved.  The
packet reduces it to a kernel-preserving analytic-minorant problem and the
attempt log records eight focused upgrade routes.
