# Type-2 weak-to-strong disjoint unboundedness

Status: `candidate_partial_result_likely_valid`.

This packet addresses the unresolved extension of Proposition 8 discussed on
page 23 of Marko Kostić, *Disjoint distributional chaos in Fréchet spaces*
(arXiv:1812.03824v4).

Main result: for every finite tuple of bounded operators on an arbitrary
Banach space, the weak positive-density block condition implies the strong
density-one block condition for disjoint distributionally unbounded vectors
of type 2. In fact, one fixed component already has a distributionally
unbounded orbit on a set of upper density one.

Upgrade results: the corresponding type-1 implication holds in finite
dimension and for finite tuples of normal operators on a complex Hilbert
space. In both settings there is a vector for which every component orbit
diverges along all natural numbers.

The unrestricted infinite-dimensional, nonnormal type-1 implication remains
open. Eight focused attempts and the synchronization obstruction are recorded
in the attempt note.
