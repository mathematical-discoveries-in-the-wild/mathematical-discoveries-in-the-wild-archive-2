# Literature-Implied Answer: Strict Slow Dimension Growth Gives Strict Comparison

## Source Question

- Source paper: G. A. Elliott and A. S. Toms, *Regularity properties in the classification program for separable amenable C*-algebras*, arXiv:0704.1803.
- Location: closing list of questions, Question (i) (locally compiled source PDF, page 14).
- Question: whether simple unital inductive limits of recursive subhomogeneous algebras have strict comparison whenever they have strict slow dimension growth.

## Status

`literature_implied_answer (Question (i), affirmative)`.

Andrew S. Toms, *Comparison theory and smooth minimal C*-dynamics*, arXiv:0805.1688, Theorem 1.1, proves that a direct sequence of recursive subhomogeneous C*-algebras with **slow dimension growth** has a limit with strict comparison whenever that limit is unital and simple.

The definition used for recursive subhomogeneous systems makes **strict slow dimension growth** the stronger condition: it is ordinary slow dimension growth with the zero-rank alternative removed for every nonzero projection. Thus the source question's hypothesis implies the later theorem's hypothesis, and Theorem 1.1 answers Question (i) affirmatively.

## Provenance and Scope

- This is an identification of a later literature theorem, not an original proof.
- The supporting paper cites the Elliott--Toms survey, but does not explicitly label Theorem 1.1 as an answer to its Question (i); hence the `literature_implied_answers` bucket.
- Only Question (i) is resolved here. The source paper's Questions (ii)--(iv) are outside this packet.
