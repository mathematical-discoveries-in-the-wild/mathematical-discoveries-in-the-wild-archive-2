# The commuting-pair joint-similarity question was already answered negatively

Status: `literature_already_answered` (one of the two source questions)

Loring--Shulman, arXiv:1007.4655v2, call it open whether two commuting
operators that are each similar to a contraction must admit one common
similarity making both contractions.  Pisier's 1998 paper had already given a
negative answer: it constructs a commuting pair whose members are each
similar to a contraction but which is not jointly similar to contractions.

Clouatre--Mbacke, arXiv:1806.09027, explicitly restate Pisier's example in
their abstract and identify it as Theorem 1 of the 1998 paper.  They further
record that the product of the two operators is not even polynomially bounded.
This makes the contradiction with a common similarity immediate.

questions from the same source.  A focused no-promotion investigation is in
