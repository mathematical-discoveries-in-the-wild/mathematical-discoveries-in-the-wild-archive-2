# Rational-spectrum question answered by arXiv:2607.19858

Status: `literature_already_answered`

This packet records an exact later-literature answer, not a new proof produced
by the run.

## Source question

Dorin Ervin Dutkay and Chun-Kit Lai, *Some reductions of the spectral set
conjecture to integers*, arXiv:1301.0814v2 (2013), page 4, Question (Q1), ask:

> Is it true that every spectral set of Lebesgue measure 1 has some rational
> spectrum?

The same bottleneck is introduced on page 3 immediately after Remark 1.4.

## Exact supporting answer

Xiao-Ye Fu and Zi-Jian Song, *Rational Spectra for Finite Hadamard Pairs and
Bounded Spectral Sets on the real line*, arXiv:2607.19858v1 (2026), Theorem
1.3 on page 4, prove that if a bounded measurable spectral set
`Omega subset R` has measure 1 and `Lambda` is a spectrum with `0 in Lambda`,
then `Lambda subset Q`. The proof appears on page 14. Remark 5.1 explains
that containing zero is only a normalization.

This is stronger than the requested existence statement: translate any
spectrum by one of its elements to obtain a normalized rational spectrum.
The supporting paper cites Dutkay--Lai, identifies rationality as their missing
hypothesis, and explicitly says Theorem 1.3 supplies it.

## Scope and provenance

The answer closes Question (Q1) only. It does not solve the full
one-dimensional Fuglede conjecture, nor Question (Q2) about the
Coven--Meyerowitz property. The earlier arXiv:1908.02794 claimed the same
rationality theorem but was withdrawn after a gap was found in Section 4;
Fu--Song explicitly discuss that failed claim and give a different argument.
