# Open problem 2 answered on compact Lie groups

Status: `literature_already_answered (open problem 2, affirmative under global matrix-symbol positivity)`.

Source question: Duván Cardona, *Spectral inequalities for elliptic
pseudo-differential operators on closed manifolds*, arXiv:2209.10690,
Section 3, physical page 18, second bullet.

Supporting answer: Duván Cardona, Julio Delgado, and Michael Ruzhansky,
*Estimates for sums of eigenfunctions of elliptic pseudo-differential
operators on compact Lie groups*, arXiv:2209.12092, Introduction pages 2–3 and
Theorem 1.1 (starting on physical page 3).

The source asks whether, on manifolds with symmetries and under a suitable
symbol-positivity condition, the restriction `rho >= 1-delta` can be removed
and the spectral inequality obtained for all `0 <= delta < rho <= 1`.
The supporting paper defines global Hörmander classes on a compact Lie group
through matrix-valued symbols in the full parameter range. Its introduction
explicitly says validity in the complete range was open prior to that work,
and Theorem 1.1 proves the spectral inequality for positive elliptic operators
whose global matrix-valued symbol is nonnegative.

The authors knew the provenance: the supporting paper shares the source's
author, cites the source as Cardona's preprint, describes the same complete-range
question as previously open, and arXiv flags text overlap between the papers.

Scope: this answers only the second open problem, with `manifold with
symmetries` realized as a compact Lie group and `suitable positivity` realized
as nonnegativity of the global matrix-valued symbol. The first boundary-value/
polyharmonic problem is not addressed. A separate counterexample packet in
this run shows that positivity of only the principal symbol is insufficient
for the broader Theorem 1.4 of the source; it does not challenge the stronger
global-symbol hypothesis recorded here.
