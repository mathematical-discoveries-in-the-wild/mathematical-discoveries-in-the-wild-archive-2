\section*{The source conjecture}

For a contraction $T\in\mathcal L(\Hh)$, let
\[
 D_T=(I-T^*T)^{1/2},\qquad \D_T=\overline{D_T\Hh}.
\]
Assume $\dim\D_T=\dim\D_{T^*}=N<\infty$, and let $\Uu$ be the set
of unitary $N$-dilations of $T$ acting on $\Hh\oplus\C^N$.  If
$W(A)=\{\langle Ax,x\rangle:\|x\|=1\}$ denotes numerical range, the
source paper defines $\tau(U)=\overline{W(U)}$ and says that $\tau$
\emph{wraps} $\overline{W(T)}$ when every open half-plane containing
$\overline{W(T)}$ contains $\overline{W(U)}$ for some $U\in\Uu$.
Conjecture 6.1 asks whether this always holds.  In particular it asks for
\begin{equation}\label{eq:source}
 \overline{W(T)}=\bigcap_{U\in\Uu}\overline{W(U)}.
\end{equation}

\section*{Exact later answer}

Two years later, Hari Bercovici and Dan Timotin proved the following.
Theorem 2.4 of arXiv:1205.2025 assumes precisely the same condition
$\dim\D_T=\dim\D_{T^*}=n<\infty$:
\begin{enumerate}
 \item every support line $d$ of $\overline{W(T)}$ is also a support line
 of $\overline{W(U)}$ for some unitary $n$-dilation $U$ of $T$; and
 \item the intersection identity \eqref{eq:source} holds using only those
 economical $n$-dilations.
\end{enumerate}

\section*{Why the stronger wrapping clause also follows}

The later paper explicitly states the intersection formula, while the source
conjecture asks for the formally stronger wrapping property.  Theorem 2.4(1)
bridges the two directly.

Let $G$ be an open half-plane containing the compact convex set
$A=\overline{W(T)}$.  After rotating coordinates, write
\[
 G=\{z:\operatorname{Re}z<c\},\qquad
 a=\max_{z\in A}\operatorname{Re}z<c.
\]
The line $d=\{z:\operatorname{Re}z=a\}$ supports $A$.  Theorem 2.4(1)
provides a unitary $n$-dilation $U$ for which $d$ supports
$\overline{W(U)}$.  Since compression gives
$A\subseteq\overline{W(U)}$, both sets lie on the same side of $d$.
Consequently
\[
 \overline{W(U)}\subseteq\{z:\operatorname{Re}z\leq a\}\subset G.
\]
This is exactly the source definition of wrapping.  Thus Conjecture 6.1 is
affirmative in its full stated strength, for every finite $N$ and every
contraction with equal defect indices.

\section*{Scope match}

There is no loss of hypotheses: both papers concern contractions on complex
separable Hilbert spaces, equal finite defect indices, and unitary dilations
on $\Hh\oplus\C^N$.  The later theorem covers arbitrary contractions in
this class, not merely the $C_0(N)$ case proved in the source paper.
