# arXiv:1508.03518 — Euclidean max–min problem answered sharply

Status: `literature_already_answered` for the explicit Euclidean subproblem.

Kobos asks for estimates of the largest simultaneous absolute value attained
by finitely many norm-one functionals, explicitly highlighting the Euclidean
case. Jiang and Polyanskii's proof of Fejes Tóth's zone conjecture implies the
sharp dimension-free universal estimate `sin(pi/(2m))`. Equally spaced
coplanar normals attain equality.

This packet does not claim to settle the source paper's general-norm or
projection-constant problems.

- `main.tex`: note source.
