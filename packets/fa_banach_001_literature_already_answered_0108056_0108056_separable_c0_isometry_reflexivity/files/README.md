# Separable `C_0(X)` has algebraically reflexive isometry group

Status: **literature already answered**.

Cabello Sánchez and Molnár ask at the end of arXiv:math/0108056 (PDF page
18, journal page 430) whether `Iso(C_0(X))` is algebraically reflexive when
`C_0(X)` is separable, equivalently when the one-point compactification of
`X` is metrizable.

The answer is yes.  Cabello Sánchez, *Local isometries on spaces of
continuous functions*, Math. Z. 251 (2005), Appendix, Theorem 1 (journal
page 748), states exactly that if a locally compact space `L` has metrizable
one-point compactification, then the isometry group of the complex space
`C_0(L)` is algebraically reflexive.  The paper cites the source as reference
5 and supplies a corrected proof of the earlier Jarosz–Rao argument.
