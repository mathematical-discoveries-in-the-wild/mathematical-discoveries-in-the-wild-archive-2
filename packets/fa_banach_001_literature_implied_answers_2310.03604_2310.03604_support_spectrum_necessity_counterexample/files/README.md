# Support-spectrum disjointness is not necessary

Status: **literature-implied negative answer**. No new theorem is claimed.

The final open problem of arXiv:2310.03604 asks whether
`supp(mu) cap sigma(u) = empty` is necessary for the bounded embedding
`K_u -> D_mu`. The explicit singular-inner example in arXiv:2509.04907
proves `K_u -> D_mu` but has `sigma(u)={1}` and positive atoms accumulating
at `1`. Thus `1` belongs to both the support and the spectrum.
