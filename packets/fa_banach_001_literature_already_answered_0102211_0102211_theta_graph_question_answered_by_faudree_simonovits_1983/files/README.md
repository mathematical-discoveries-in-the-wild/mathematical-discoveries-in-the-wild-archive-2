# Literature resolution: arXiv:0102211, Question 5.4

This packet identifies Faudree--Simonovits, *On a Class of Degenerate
Extremal Graph Problems*, Combinatorica 3 (1983), Theorem 1, as an exact
affirmative answer to Question 5.4 of *Lacunary matrices*.

The question's `l` independent paths of length `s` with common endpoints
form the theta graph `Theta_{s,l}`.  Faudree--Simonovits proved
`ex(v,Theta_{s,l}) = O_{s,l}(v^{1+1/s})`, so the desired constant exists by
contraposition.  The answering theorem predates the source paper.
