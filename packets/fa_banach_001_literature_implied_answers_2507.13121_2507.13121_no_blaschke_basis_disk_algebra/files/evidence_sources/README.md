# Primary evidence

Ivan V. Ivanov and Boris Shekhtman, *Linear discrete operators on the disk
algebra*, Proceedings of the American Mathematical Society **129** (2001),
1987–1993.

- DOI: <https://doi.org/10.1090/S0002-9939-00-05774-9>
- Stable bibliographic identifier: MR1825912.
- Theorem 4: for arbitrary finite node sets `Z_n` in the disk and arbitrary
  projections `P_n` in `R(Z_n)` (operators depending only on values on
  `Z_n`), some `f` in the disk algebra satisfies `P_n f` not converging to
  `f`.
- The authors explicitly state the consequence that the disk algebra has no
  interpolating basis.
