# Counterexample packet for arXiv:2112.13900

This packet gives a full negative answer to the literal open problem following Theorem 3.5: boundedness of `A` cannot simply be removed.

The counterexample is one-dimensional and uses the positively homogeneous maximal-monotone half-line operator already displayed in the source paper's preliminaries. The packet separately records that this operator is not quasibounded, so the stronger proposed quasibounded replacement remains open.
