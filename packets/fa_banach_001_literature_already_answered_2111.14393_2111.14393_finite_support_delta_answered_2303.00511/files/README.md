# Finitely supported Delta-points are convex sums of Delta-molecules

Status: literature already answered, intended finite-support scope of Problem 3.

Source: Triinu Veeorg, Characterizations of Daugavet- and delta-points in
Lipschitz-free spaces, arXiv:2111.14393.

Answering paper: Trond A. Abrahamsen, Ramon J. Aliaga, Vegard Lima, Andre
Martiny, Yoel Perreau, Antonin Prochazka, and Triinu Veeorg, Delta-points and
their implications for the geometry of Banach spaces, arXiv:2303.00511.

## Identification

Problem 3 on page 20 of the source asks whether the finitely supported
Delta-point arising from a finite molecular representation can always be
represented as a finite convex combination of molecules that are themselves
Delta-points.

The answering paper explicitly cites source Problem 3 and proves in Theorem
6.9, page 34:

> Every finitely supported Delta-point in a Lipschitz-free space is a finite
> convex combination of Delta-molecules.

This is a complete affirmative answer to the intended finite-support problem.

## Notation caveat

The displayed source question literally prints an intersection with the set
of molecules, which would make the question trivial by choosing the molecule
itself.  The surrounding paragraph concerns a finite convex combination, and
the answering paper - coauthored by the source author - explicitly identifies
Problem 3 as the finite-support question.  This packet records that intended
and later-author-confirmed scope.

## Remaining problem

Source Problem 2 asks for the small-molecule slice characterization for every
unit-sphere Delta-point, without finite support.  Theorem 6.9 does not settle
that broader question.  The answering paper also notes that not every
unit-sphere element is a convex sum of molecules.
