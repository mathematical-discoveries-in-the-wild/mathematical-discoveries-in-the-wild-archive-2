# Full candidate: VMO Morse formula and extension criterion for line fields

Status: `candidate_full_solution_likely_valid` (awaiting human review).

Source target: Giacomo Canevari, Antonio Segatti, and Marco Veneroni,
*Morse's index formula in VMO for compact manifolds with boundary*,
arXiv:1407.1707, Section 4 opening paragraph (source PDF page 17).

The packet resolves the proposed extension in the compact oriented surface
setting of the source's Q-tensor application.  If

```text
E = Sym^2_0(TN)
```

and `g` is a nonzero VMO boundary Q-field, let `w(g)` be its total winding
relative to the Q-tensor generated by the positively oriented boundary
tangent.  Then every VMO Q-field with trace `g` satisfies

```text
ind_line(Q,N) + ind_boundary_line(g) = chi(N),
ind_line = (ordinary E-section index)/2,
ind_boundary_line(g) = -w(g)/2.
```

Equivalently, the integer relative Euler number is

```text
e(E,g)[N,boundary N] = 2 chi(N) + w(g).
```

A bounded uniformly positive VMO boundary line field has a bounded uniformly
positive VMO extension if and only if this number vanishes, or equivalently
if and only if its line boundary index equals `chi(N)`.  For a closed surface,
the formula reduces to total line-defect index `chi(N)` and recovers the
source's Poincare--Kneiser consequence.
