# arXiv:1704.07095 — absolute-norming lens and cap-one BPB modulus

Status: `candidate_full_solution_likely_valid`

Section 5 asks whether the scalar spherical operator modulus always satisfies
`Phi^S(X,R,epsilon) <= min(sqrt(2 epsilon),1)`.

This packet gives an affirmative answer and strengthens it to the
nonspherical modulus. The main new lemma says that every pair in
`B_X x B_X*` lies at max-distance at most one from the set of pairs `(y,g)`
with `y` and `g` unit and `|g(y)|=1`. Its proof supports the lens
`B_X intersect (x+B_X)`, decomposes the supporting normal into the normals of
the two balls, and selects the branch with the larger coefficient.

The same rank-one correction proves the cap-one bound for every range space
with property beta at parameter zero. The argument does not settle the
source's broader question for positive beta parameter.
