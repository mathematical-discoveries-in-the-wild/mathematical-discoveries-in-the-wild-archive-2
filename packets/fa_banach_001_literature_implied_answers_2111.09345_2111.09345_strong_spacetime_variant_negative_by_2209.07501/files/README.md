# Strong spacetime Deift variant disproved by arXiv:2209.07501

Status: `literature_implied_answer (partial variant)`

## Source program

David Damanik, Milivoje Lukić, Alexander Volberg, and Peter Yuditskii,
*The Deift Conjecture: A Program to Construct a Counterexample*,
arXiv:2111.09345v1 (2021).

Conjecture 1.1 on arXiv PDF page 2 says that KdV with almost-periodic initial
data evolves almost periodically in time. The paper develops a multi-step
Widom-domain/DCT program intended to construct a counterexample.

## Later scoped counterexample

Andreia Chapouto, Rowan Killip, and Monica Vișan,
*Bounded solutions of KdV: uniqueness and the loss of almost periodicity*,
arXiv:2209.07501v1 (2022).

The later paper explicitly cites arXiv:2111.09345 as the preceding
counterexample program. Its Theorem 1.3, arXiv PDF page 7, constructs a bounded
local KdV solution with almost-periodic initial data whose spatial profile is
not almost periodic at a later time. The authors state that this disproves the
strong spacetime formulation of the Deift conjecture.

## Limitation

This is not recorded as a full answer to the exact temporal conjecture in
arXiv:2111.09345. The later KdV solution is defined only on a finite time
interval, and on PDF page 8 the authors explicitly say that global existence
for their example is unknown. Bohr almost periodicity in time is a global
property. The source's specific Widom/DCT construction problems also remain
unresolved by this identification.
