# Rank-one-cone diffusion uniqueness

Candidate full sufficient-condition theorem for the bounded-data uniqueness
problem in arXiv:2605.00439v3.

If

`a(t,x,s) = sum_r alpha_r(t,s) e_r tensor e_r`

with fixed spanning directions, strictly positive state weights, and the source ellipticity
assumptions, every bounded weak solution satisfies a weighted one-sided `L1`
stability estimate. This yields comparison and global uniqueness for every
bounded initial datum.

The proof converts the difference equation into finitely many directional
monotone diffusions, applies a directional Kato inequality, and uses the
integrable weight `(1+|x|^2)^(-p)`. Source Proposition 3.4(b) supplies the
strong local trace needed to close the weighted estimate at time zero.
