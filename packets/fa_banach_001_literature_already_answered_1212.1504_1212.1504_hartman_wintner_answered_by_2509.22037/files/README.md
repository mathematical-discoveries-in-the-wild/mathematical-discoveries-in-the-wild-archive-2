# Genuine noncommutative Hartman–Wintner LIL: later answer

This packet records that the final possibility question in arXiv:1212.1504
was answered affirmatively by Panja–Ricard–Saha, arXiv:2509.22037v2.

The later paper proves a truncation-based martingale LIL without Zeng's
pointwise small-increment condition (Theorem 3.4) and the noncommutative IID
`L_2` Hartman–Wintner theorem with optimal `sqrt(2)` almost-uniform upper
constant (Theorem 4.4).  The packet does not claim the broader theorem for
every dependent stationary-ergodic martingale-difference sequence.
