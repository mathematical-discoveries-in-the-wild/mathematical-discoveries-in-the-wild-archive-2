# Minkowski splitting question already answered negatively

Status: `literature_already_answered`.

Source: Dušan Repovš and Pavel V. Semenov, *Continuous selections of
multivalued mappings*, arXiv:1401.2257. Problem 5 on printed/PDF page 32 asks
whether every pair of closed convex subsets `A,B` of a Banach space admits
continuous maps `a:A+B->A`, `b:A+B->B` with `c=a(c)+b(c)`.

The exact question was answered negatively by Maxim V. Balashov and Dušan
Repovš, *On the splitting problem for selections*, Journal of Mathematical
Analysis and Applications 355 (2009), 277--287, arXiv:0807.3104. The authors
quote the question verbatim on PDF page 1 and Example 1.1 (PDF pages 1--2)
constructs compact convex `A,B` in `R^3` for which no such continuous splitting
exists. Two boundary arcs approach the same point while the unique possible
`A`-components approach `(1,0,0)` and `(1,0,1)`.

This packet is duplicate/status memory, not a new result.
