# arXiv:2304.09716 — no proper ideal has Hardy/Bergman BCP

Status: `candidate_full_solution_likely_valid`

Open Problem 1 asks whether any nontrivial operator ideal on the Hardy or
Bergman Hankel maps has the Berger–Coburn phenomenon. Under the standard
meaning of a proper two-sided operator ideal, the answer is no.

Every proper operator ideal between infinite-dimensional Hilbert spaces is
contained in the compact operators: a noncompact operator is bounded below on
an infinite-dimensional subspace, so the identity factors through it, forcing
the ideal to contain every bounded operator. The source paper already gives a
bounded analytic symbol `b` with `H_b = 0` and `H_conj(b)` noncompact in each
Hardy/Bergman setting. Thus every proper ideal fails BCP.
