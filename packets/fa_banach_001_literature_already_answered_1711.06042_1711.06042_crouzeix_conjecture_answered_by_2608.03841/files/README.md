# Crouzeix conjecture cited in arXiv:1711.06042

The only open-problem signal extracted from arXiv:1711.06042 is the classical Crouzeix conjecture stated in its Introduction (printed page 2): for every polynomial \(p\) and matrix \(A\),
\[
\|p(A)\|\le 2\max_{z\in W(A)}|p(z)|.
\]

Lorist and Schwenninger, arXiv:2608.03841v1 (August 4, 2026), explicitly prove this statement in Theorem 3, in the stronger form that the numerical range of every bounded Hilbert-space operator is a \(2\)-spectral set for rational functions with poles off \(\overline{W(A)}\).

This is a direct literature answer, not a new proof by this run. The resolving work is a very recent arXiv preprint and is not represented here as peer-reviewed. Its theorem and proof mechanism were checked directly in the official PDF; the run registry also independently records arXiv:2608.03841 in a separate Crouzeix-related literature packet.
