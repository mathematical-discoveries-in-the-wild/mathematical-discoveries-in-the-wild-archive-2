\begin{abstract}
Let \(C:\Hh\to\ell^2\) be the analysis operator of a Bessel family
\(\Gg=(g_j)\), and let \(A\in\B(\Hh)\). For every
\(1\leq p\leq\infty\), stable recovery of all discrete time-dependent
sources from
\[
 x_{n+1}=Ax_n+w_n,\qquad y_n=Cx_n,
\]
as a bounded map
\(\ell^p(\N_0;\ell^2)\to\ell^p(\N_0;\Hh)\), is possible if and only if
\(\Gg\) is a frame. The recovery is
\((Ry)_n=Ly_{n+1}-ALy_n\), where \(LC=I\).
The continuous bounded-generator analogue also holds:
universal stable recovery
\(W^{1,p}(0,T;\ell^2)\to L^p(0,T;\Hh)\) is possible if and only if
\(\Gg\) is a frame, with \(R(y)=Ly'-ALy\).
These theorems answer a standard natural formulation of the source's
time-dependent future-work direction. They do not settle its broader
unbounded-semigroup program.
\end{abstract}

\section{Frame and recovery conventions}

Let \(\Hh\) be a separable Hilbert space and let
\(\Gg=(g_j)_{j\geq1}\subset\Hh\) be Bessel. Its analysis operator is
\[
 C:\Hh\longrightarrow\ell^2,\qquad
 Ch=(\langle h,g_j\rangle)_{j\geq1}.
\]
The family \(\Gg\) is a frame precisely when \(C\) is bounded below:
\[
 \|Ch\|_{\ell^2}\geq a\|h\|_{\Hh}\qquad(h\in\Hh)
\]
for some \(a>0\). Equivalently, \(C\) has a bounded left inverse
\(L:\ell^2\to\Hh\), for example synthesis by the canonical dual frame.

For \(1\leq p\leq\infty\), a \emph{stable universal discrete recovery} is a
bounded linear map
\[
 R_p:\ell^p(\N_0;\ell^2)\longrightarrow\ell^p(\N_0;\Hh)
\]
such that \(R_p((Cx_n)_n)=(w_n)_n\) for every trajectory
\(x_{n+1}=Ax_n+w_n\) for which both the displayed data and source belong to
their indicated spaces. The definition includes all finite-support
trajectories.

\section{Exact discrete characterization}

\begin{theorem}[time-dependent discrete sources]\label{thm:discrete}
Let \(A\in\B(\Hh)\), let \(\Gg\) be Bessel, and fix
\(1\leq p\leq\infty\). A stable universal discrete recovery exists if and
only if \(\Gg\) is a frame.

If \(LC=I\), one recovery operator is
\begin{equation}\label{eq:discreteR}
 (R_py)_n=Ly_{n+1}-ALy_n,\qquad n\geq0,
\end{equation}
and it satisfies
\[
 \|R_p\|\leq \|L\|(1+\|A\|).
\]
Conversely, the existence of any such \(R_p\) implies
\[
 \|Ch\|_{\ell^2}\geq \|R_p\|^{-1}\|h\|_{\Hh}
\qquad(h\in\Hh).
\]
\end{theorem}

\begin{proof}
Assume first that \(\Gg\) is a frame and choose \(L\) with \(LC=I\).
The unilateral shift \(Sy=(y_{n+1})_{n\geq0}\) has norm at most one on every
\(\ell^p\), including \(p=\infty\). Applying \(L\) coordinatewise, formula
\eqref{eq:discreteR} defines the bounded operator
\[
 R_p=L S-A L,
\]
with the asserted norm bound. For trajectory data \(y_n=Cx_n\), we have
\[
 (R_py)_n=LCx_{n+1}-ALCx_n=x_{n+1}-Ax_n=w_n.
\]

Conversely, suppose \(R_p\) is a stable universal recovery. Given any
\(h\in\Hh\), define the finite-support trajectory
\[
 x_0=0,\qquad x_1=h,\qquad x_n=0\quad(n\geq2).
\]
It is generated by
\[
 w_0=h,\qquad w_1=-Ah,\qquad w_n=0\quad(n\geq2).
\]
Its observation sequence has the single nonzero entry \(y_1=Ch\).
Therefore, for finite \(p\),
\[
 \|h\|\leq(\|h\|^p+\|Ah\|^p)^{1/p}
 =\|w\|_{\ell^p}
 =\|R_py\|_{\ell^p}
 \leq\|R_p\|\,\|Ch\|_{\ell^2}.
\]
For \(p=\infty\), the same chain starts with
\(\|h\|\leq\max(\|h\|,\|Ah\|)=\|w\|_{\ell^\infty}\).
Thus \(C\) is bounded below. Since \(\Gg\) was Bessel, it is a frame.
\end{proof}

\begin{remark}
Arbitrary time dependence is decisive in the necessity proof: a one-step
source pulse creates an arbitrary state \(h\), and the next pulse cancels it.
No spectral or stability assumption on \(A\) is needed.
\end{remark}

\section{Continuous bounded-generator upgrade}

Let \(I=(0,T)\), \(0<T<\infty\), and use the norm
\[
 \|y\|_{W^{1,p}(I;\ell^2)}
 =\|y\|_{L^p(I;\ell^2)}+\|y'\|_{L^p(I;\ell^2)}.
\]
A \emph{stable universal continuous recovery} is a bounded linear map
\[
 R_p^c:W^{1,p}(I;\ell^2)\longrightarrow L^p(I;\Hh)
\]
that recovers \(w\) from \(y=Cx\) for every strong solution
\[
 x'=Ax+w,\qquad x\in W^{1,p}(I;\Hh),\quad w\in L^p(I;\Hh).
\]

\begin{theorem}[time-dependent continuous forcing]\label{thm:continuous}
Let \(A\in\B(\Hh)\), let \(\Gg\) be Bessel, and let
\(1\leq p\leq\infty\). A stable universal continuous recovery exists if and
only if \(\Gg\) is a frame.

If \(LC=I\), then
\begin{equation}\label{eq:continuousR}
 R_p^c(y)=Ly'-ALy
\end{equation}
is such a recovery and
\(\|R_p^c\|\leq\|L\|\max(1,\|A\|)\) for the sum norm above.
Conversely, for every \(\lambda>\|A\|\),
\[
 \|Ch\|_{\ell^2}\geq
 \frac{\lambda-\|A\|}{\|R_p^c\|(1+\lambda)}\|h\|_{\Hh}.
\]
\end{theorem}

\begin{proof}
If \(C\) has a bounded left inverse \(L\), boundedness of \(L\) implies that
it commutes with Bochner weak differentiation. Thus \(Ly=x\) and
\(Ly'=x'\) for observation data \(y=Cx\). Formula
\eqref{eq:continuousR} gives
\[
 R_p^c(y)=x'-Ax=w.
\]
Moreover,
\[
 \|R_p^c(y)\|_{L^p}
 \leq\|L\|\|y'\|_{L^p}+\|A\|\|L\|\|y\|_{L^p}
 \leq\|L\|\max(1,\|A\|)\|y\|_{W^{1,p}}.
\]

For necessity, assume a stable recovery exists. Fix \(\lambda>\|A\|\) and
\(h\in\Hh\), and choose the strong trajectory
\[
 x(t)=e^{\lambda t}h,\qquad
 w(t)=e^{\lambda t}(\lambda I-A)h,\qquad
 y(t)=e^{\lambda t}Ch.
\]
Writing \(E_p=\|e^{\lambda(\cdot)}\|_{L^p(0,T)}\), with the usual
interpretation for \(p=\infty\), the reverse triangle inequality gives
\[
 \|w\|_{L^p}
 =E_p\|(\lambda I-A)h\|
 \geq E_p(\lambda-\|A\|)\|h\|.
\]
On the other hand,
\[
 \|y\|_{W^{1,p}}=E_p(1+\lambda)\|Ch\|_{\ell^2}.
\]
Since \(R_p^c(y)=w\), boundedness of \(R_p^c\) and cancellation of \(E_p>0\)
give the displayed lower bound for \(C\). Hence \(\Gg\) is a frame.
\end{proof}

\section{Boundary of the result}

The source's continuous future direction allows an unbounded infinitesimal
generator and an arbitrary \(x_0\in\Hh\), then informally uses
\(\mathcal D_c'(0)\). This derivative need not exist. For example, let
\(T(t)\) be the translation semigroup on \(L^2(\mathbb R)\), whose generator
has domain \(H^1(\mathbb R)\), choose \(x_0\notin H^1(\mathbb R)\), and let
\(\Gg\) be an orthonormal basis. Its analysis map is unitary, so the
\(\ell^2\)-valued observation curve is strongly differentiable at zero if and
only if \(T(t)x_0\) is; it is not for this \(x_0\).

Thus a full unbounded-generator theory must restrict initial states, use weak
or mild derivatives, or adopt an integral observation space. Also, the
source's continuous model has a constant \(w\), whereas Theorem
\ref{thm:continuous} requires recovery for arbitrary \(L^p\) forcing. Time
evolution can create additional observability for a constant source, so the
frame condition need not be necessary in every weaker formulation.

\section{Novelty and review status}

Local and web searches found arXiv:2401.15450, the authors' earlier
constant-source paper, and continuous dynamical-sampling work for
initial-state recovery, but no later source containing Theorems
\ref{thm:discrete}--\ref{thm:continuous}. This is not proof of novelty.
The discrete result substantially resolves the first future direction after
a standard choice of Banach spaces; the continuous result resolves a bounded
strong-solution analogue. Because the source asks a family of formulations
rather than a single theorem, this packet is classified as a promoted partial
result and should receive expert review.
