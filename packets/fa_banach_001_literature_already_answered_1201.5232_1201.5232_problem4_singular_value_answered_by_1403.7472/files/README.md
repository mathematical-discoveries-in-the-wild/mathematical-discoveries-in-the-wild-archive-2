# Problem 4 of arXiv:1201.5232 is already answered negatively

**Status:** `literature_already_answered`

Audenaert and Kittaneh ask in Problem 4 of arXiv:1201.5232 whether each singular value of

\[
A^pB^{1-p}+B^pA^{1-p}
\]

is bounded by the corresponding singular value of (A+B) for all positive semidefinite (A,B). Example 3.2 of Bottazzi--Elencwajg--Larotonda--Varela, arXiv:1403.7472, explicitly cites that problem and disproves it with positive definite (3\times3) matrices.

The status note also records an independently derived exact (2\times2) rank-one witness at (p=1/3). It is much simpler than the supporting paper's numerical example, but the original problem was already settled in 2014, so this packet is not classified as a new counterexample.
