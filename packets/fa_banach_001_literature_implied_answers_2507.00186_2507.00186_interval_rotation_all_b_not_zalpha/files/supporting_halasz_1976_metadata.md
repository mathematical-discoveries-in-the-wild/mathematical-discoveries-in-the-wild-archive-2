# Halász 1976 supporting theorem

G. Halász, “Remarks on the remainder in Birkhoff's ergodic theorem,”
*Acta Mathematica Academiae Scientiarum Hungaricae* 28 (1976), no. 3–4,
389–395. DOI: https://doi.org/10.1007/BF01896805

The publisher endpoint returned an HTML access page rather than the article
PDF in this environment, so no file is mislabeled as the original PDF.
