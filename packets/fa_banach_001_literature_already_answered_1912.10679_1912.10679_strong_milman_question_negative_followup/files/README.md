# Later negative answer to arXiv:1912.10679, Question 5.2

Status: `literature_already_answered_negative`

The source paper asks whether every sufficiently high-dimensional strongly
`C`-Euclidean space contains a `k`-dimensional subspace that is simultaneously
strongly `(1+epsilon)`-Euclidean and strongly `(1+epsilon)`-complemented.

The authors announce a negative follow-up on source PDF page 21.  That
follow-up is arXiv:2110.03023.  Its Theorem 1.4 gives absolute constants and,
for every sufficiently large dimension, a `C`-Euclidean space with no
two-dimensional subspace having both strong properties.  This negates the
universal statement already at `k=2`.

The original weaker Milman question (Question 5.1) is not answered by the
follow-up and remains outside this packet's scope.
