# arXiv:0012032 — left-multiplier questions answered later

Status: `literature_already_answered (automatic weak-star continuity of left
multipliers and equivalent module actions)`

The target asks whether every left multiplier of a dual operator space is
weak-star continuous. It also proves that this is equivalent to asking
whether a left operator-module action of a dual operator algebra, weak-star
continuous in the algebra variable, must be weak-star continuous in the
space variable.

Blecher--Magajna, arXiv:math/0407220, Theorem 4.1, proves that every left
multiplier of a dual operator space is weak-star continuous. The target's
equivalence then gives a positive answer to the module-action question.
