# 1406.3215 — asymptotic-center weak convergence is topological

Status: literature_already_answered (full positive answer for the cited CAT(0) question).

Model: GPT5.6.

Source: Martin Kell, *Uniformly convex metric spaces*, arXiv:1406.3215v1, source PDF pages 12–13.

Supporting answer: Alexander Lytchak and Anton Petrunin, *Weak topology on CAT(0) spaces*, arXiv:2107.09295v2, Theorem 1.2 on supporting PDF pages 1 and 5–6.

## Identification

The source asks whether weak sequential convergence defined through asymptotic centers is generated by a topology, citing Bačák's CAT(0)/Hadamard-space question.

Lytchak–Petrunin explicitly identify the same question and answer it affirmatively. Every CAT(0) space has a unique sequential topology `T_Delta` in which a sequence converges exactly when it is bounded and weakly (Delta-)convergent. Their weak convergence agrees with the asymptotic-center definition used in the source.

## Scope

The answer is for sequences. The stronger assertion for all weakly convergent nets is false without additional Hausdorff assumptions on bounded sets. The resulting sequential topology itself can also be non-Hausdorff, although it is sequentially Hausdorff.
