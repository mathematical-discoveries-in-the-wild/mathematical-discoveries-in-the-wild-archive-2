# Absolute radical equation: classification and Ulam stability

Candidate full answer to Question 1 of arXiv:2007.01454v1.

For every positive integer `n` and all nonzero real `a,b,c,d`, every exact
solution has the form

`f(x) = Q(x^n) + w`,

where `Q` is quadratic, satisfies the two scaling eigenconditions determined
by `|a|,|b|,c,d`, and `(2-c-d)w=0`.

The packet also proves uniform Hyers--Ulam stability in every real Banach
target, for every parameter quadruple, with an explicit global error bound
and a dyadic formula for the exact quadratic part.
