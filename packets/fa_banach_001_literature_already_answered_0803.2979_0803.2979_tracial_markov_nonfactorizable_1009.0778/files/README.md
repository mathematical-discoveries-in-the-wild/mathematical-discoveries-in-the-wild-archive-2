# arXiv:0803.2979 — negative literature answer

Status: `literature_already_answered (negative)`

Original source:

- Éric Ricard, *A Markov dilation for self-adjoint Schur multipliers*,
  arXiv:0803.2979; Proceedings of the AMS 136 (2008), 4365–4372.
- Exact location: paragraph after Proposition 2, arXiv PDF page 4.

Answering source:

- Uffe Haagerup and Magdalena Musat, *Factorization and dilation problems
  for completely positive maps on von Neumann algebras*, arXiv:1009.0778;
  Communications in Mathematical Physics 303 (2011), 555–594.
- Exact locations: Introduction, arXiv PDF pages 1–2; Example 3.1, pages
  9–10.  Remark 4.8 on page 19 records examples for every `n >= 3`.

Ricard asks whether the factorizable maps generated by his examples and the
permanence operations can exhaust all tracial Markov maps on `M_n`.
Haagerup--Musat's Example 3.1 gives an explicit tracial Markov map on `M_3`
and proves that it is not factorizable.  It therefore cannot be obtained by
Ricard's factorizability-preserving construction, so the answer is no.

The later paper also records the sharp dimension split relevant to the
question: all trace-preserving Markov maps on `M_2` are factorizable, while
nonfactorizable examples exist for every `n >= 3`.
