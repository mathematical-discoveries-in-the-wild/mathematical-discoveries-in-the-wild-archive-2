# Totally-positive frame-set conjecture answered by arXiv:2608.04992

Status: `literature_already_answered`.

The precise conjecture in Gröchenig--Stöckler, arXiv:1104.4894, says that
every continuous totally positive function in `L^1(R)` has the maximal
Gabor frame set `alpha beta < 1`.

Theorem 1 of de Dios Pont--Gröchenig--Liehr--Shafkulovska--Taylor,
arXiv:2608.04992, proves exactly that equivalence for every continuous,
integrable, totally positive function.  The resolving paper explicitly
names the 2011 conjecture and states that it settles it in full generality.

The compact PDF records the exact statement match and the proof architecture.
Official arXiv PDFs of both papers are included.
