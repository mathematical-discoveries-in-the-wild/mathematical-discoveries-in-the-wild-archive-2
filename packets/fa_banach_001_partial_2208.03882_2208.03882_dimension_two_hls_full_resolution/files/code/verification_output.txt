Corrected-phase axisymmetric search in dimension n=3
====================================================

The spherical Fourier multiplier includes the phase
(-1)^(degree/2). An initial run without this phase produced a spurious
ratio above one; restoring it removed the false counterexample.

n=3 p=0.7 degree=12 transform_degree=80 nodes=1000 seed=4
best_ratio=0.999999999996

n=3 p=1.1 degree=12 transform_degree=80 nodes=1000 seed=2
best_ratio=0.999999999999

n=3 p=1.2 degree=12 transform_degree=80 nodes=1200 seed=1
best_ratio=0.999999999996

n=3 p=1.4 degree=12 transform_degree=80 nodes=1000 seed=1
best_ratio=0.999999999999

In every corrected run, differential evolution followed by Nelder-Mead
converged to the Legendre expansion of an ellipsoidal radial power. These
checks support but are not used in the dimension-two proof.
