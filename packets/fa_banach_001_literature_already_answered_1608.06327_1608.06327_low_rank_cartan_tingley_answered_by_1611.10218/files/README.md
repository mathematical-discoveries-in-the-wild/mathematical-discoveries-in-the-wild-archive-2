# Low-rank Cartan-factor Tingley problem answered by arXiv:1611.10218

Status: `literature_already_answered`

## Source question

Antonio M. Peralta and Ryotaro Tanaka, *A solution to Tingley's problem for isometries between the unit spheres of compact C*-algebras and JB*-triples*, arXiv:1608.06327; *Science China Mathematics* 62 (2019), 553--568.

Problem 3.20 (printed page 17) asks: if `C` and `B` are Cartan factors of rank at most 4 and `f:S(C) -> S(B)` is a surjective isometry, must `f` extend to a surjective real linear isometry from `C` into `B`?

## Explicit later answer

Francisco J. Fernández-Polo and Antonio M. Peralta, *Low rank compact operators and Tingley's problem*, arXiv:1611.10218; *Advances in Mathematics* 338 (2018), 1--40.

The later paper explicitly identifies Peralta--Tanaka as its source and says that the rank-2-to-4 cases were left open there. It then says that it completes that study. Theorem 2.5 (printed page 8) proves the stronger statement that every surjective isometry between the unit spheres of arbitrary weakly compact JB*-triples extends to a surjective real linear isometry. In particular this applies to the source's rank-at-most-4 Cartan factors. Theorem 4.1 additionally gives a complex-linear or conjugate-linear extension for elementary JB*-triples of rank at least 2, while Theorem 4.7 directly covers finite-dimensional elementary JB*-triples.

This is an author-explicit, separate-paper resolution, so it belongs in `literature_already_answered`; no new mathematical result is claimed here.

The broad Tingley problem for arbitrary Banach spaces, mentioned elsewhere in the source and still open even in dimension two at the time, is outside this packet. Only Problem 3.20 is classified.
