# Verification

- Source questions: arXiv:1607.08024, Section 10, PDF page 38, Q3 and Q5.
- No-overlap input: arXiv:1607.08024, Theorem 1.6, PDF page 5.
- Later construction: arXiv:2209.05616, Example 8.4, PDF page 33.
- The later example explicitly states that `mu_{24,D}` is spectral for
  `D={0,1,16,17}` and that there is no `L` for which `(24,D,L)` is an
  ordinary Hadamard triple.
- The four digits are pairwise incongruent modulo 24, so `D` is simple.
  Theorem 1.6 of the source therefore supplies the no-overlap property.
- Consequently the example refutes Q3 and, with the source theorem, Q5.
- Q4 is not claimed to be answered.
