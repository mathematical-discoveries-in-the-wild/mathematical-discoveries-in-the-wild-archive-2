# Singular-continuous spectrum in the intermediate band

This packet fully answers the explicit alternative in item (c) of Theorem 2.6
of arXiv:1106.4852.

The mixed reducing tensor sectors `H_pp ⊗ H_sc` and `H_sc ⊗ H_pp` are purely
singular continuous.  Using the one-dimensional inner singular-continuous
band `[-L,L]` and outer dense pure-point bands `[-2,-L] ∪ [L,2]`, their
Minkowski-sum spectra fill `[-2-theta*L, 2+theta*L]`.  This contains the
paper's entire intermediate interval `(-L(1+theta), L(1+theta))`, so the
singular-continuous intersection in item (c) is never empty under the source's
generic hypotheses.
