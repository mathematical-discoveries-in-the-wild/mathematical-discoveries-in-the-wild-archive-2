# 0906.1162 unconditional translate-basis problem answered by 1209.4619

Status: `literature_already_answered`

The source's Problem 4.6 (official PDF page 27) asks whether, for `4<p<infinity`,
translates of a single function can form an unconditional basis of all
`L_p(R)`. Freeman--Odell--Schlumprecht--Zsak, arXiv:1209.4619, Corollary 2.3,
prove the stronger result that this is impossible for every `1<=p<infinity`.

This packet records the exact ask/answer identification. It does not claim a
new proof and does not settle the conditional Schauder-basis problem.
