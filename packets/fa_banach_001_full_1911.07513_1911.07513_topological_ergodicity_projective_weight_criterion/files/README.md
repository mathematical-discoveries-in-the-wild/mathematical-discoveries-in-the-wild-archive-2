# Exact topological-ergodicity criterion for coechelon shifts

Status: `candidate_full_solution_likely_valid` for Open Problem (1) of
arXiv:1911.07513. Open Problem (2) is not claimed solved.

The packet proves that the backward shift on `k_p(V)` is topologically
ergodic exactly when every projective weight has syndetic epsilon-small
coordinate sets. Equivalently, for every positive scalar sequence
`(a_m)`, every epsilon-small set of the canonical weight
`inf_m a_m v_j^(m)` is syndetic. The criterion is independent of `p`.

Files:

- `solution_packet.pdf`: self-contained proof packet.
- `main.tex`: LaTeX source.
- `source_paper.pdf`: source paper.
- `figures/open_problems_crop.png`: real crop of page 20 of the source PDF.

The source's second problem is reduced to a precise weight construction but
remains open.
