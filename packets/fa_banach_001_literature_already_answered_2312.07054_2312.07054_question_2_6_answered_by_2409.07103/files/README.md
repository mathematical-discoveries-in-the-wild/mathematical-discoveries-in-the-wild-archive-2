Source question: Oezguer Martin and Rebecca Sanders, *Extending Families of

Supporting answer: Frederic Bayart, Sophie Grivaux, Etienne Matheron, and
Quentin Menet, *Hereditarily Frequently Hypercyclic Operators and Disjoint
Frequent Hypercyclicity*, arXiv:2409.07103, Question 7.1 and Theorem 7.2 on
physical PDF page 28; the construction is completed in the proof on physical
page 32.

The source asks whether every frequently disjoint-hypercyclic tuple is densely
disjoint hypercyclic and whether it satisfies the Disjoint Blow-up/Collapse
property. The supporting paper restates the first question and says that its
next theorem solves it. Theorem 7.2 constructs a Banach space and a pair
`(T_1,T_2)` that is disjoint frequently hypercyclic but whose set of ordinary
disjoint-hypercyclic vectors is not dense. This is an explicit negative answer
to the first clause.

The same example answers the second clause negatively. The source's own
implication diagram records that the Disjoint Blow-up/Collapse property
implies dense disjoint hypercyclicity. Therefore the pair from Theorem 7.2,
which is not densely disjoint hypercyclic, cannot satisfy the Disjoint
Blow-up/Collapse property.

The provenance is explicit rather than a new run result. The supporting paper
states the same problem, calls Theorem 7.2 its solution, and cites the source
preprint arXiv:2312.07054 as reference [39]. The second clause follows by the
standard implication already displayed in the source.
