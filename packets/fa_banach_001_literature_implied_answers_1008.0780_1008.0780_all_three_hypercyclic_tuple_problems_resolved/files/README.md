# All three open problems in arXiv:1008.0780v2 resolved

Status: `literature_implied_answer`

- Problems 1–2: the exact minimum number of upper triangular Toeplitz
  generators is `2n` over `C` and `n+1` over `R`. These are the Toeplitz rows
  of Table 3 in Abels–Manoussos, arXiv:1108.1123, PDF page 11. A singular
  Toeplitz generator cannot help on the open set where the last coordinate is
  nonzero, so the invertible-group result answers the source formulation.
- Problem 3: the answer is negative for every `n >= 3`. Any commuting real
  family has a common complex eigenline; the real and imaginary parts span a
  common invariant real subspace of dimension at most two. A nonzero vector
  in that proper subspace cannot have a dense orbit.

The relation is agent-identified rather than explicit in the supporting
paper, so the packet is classified as literature-implied rather than
literature-already-answered. No new theorem is claimed.
