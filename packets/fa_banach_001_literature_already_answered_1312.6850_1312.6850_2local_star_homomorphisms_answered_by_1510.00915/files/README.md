# Problem 3.12: the *-homomorphism half answered by arXiv:1510.00915

Status: `literature_already_answered (partial subcase)`

This is a literature-status record, not a new theorem proved by this run.

## Source question

Antonio M. Peralta, *A note on 2-local representations of C*-algebras*,
arXiv:1312.6850; *Operators and Matrices* 9(2) (2015), 343--358,
doi:10.7153/oam-09-20.

Problem 3.12, arXiv PDF page 12, asks whether every not-necessarily-linear
2-local homomorphism, respectively 2-local *-homomorphism, between
C*-algebras must be a homomorphism, respectively a *-homomorphism. It asks
equivalently whether linearity can be deleted from Theorem 3.9.

## Explicit later answer

Juan Carlos Cabello and Antonio M. Peralta, *Weak-2-local symmetric maps on
C*-algebras*, arXiv:1510.00915; *Linear Algebra and its Applications* 494
(2016), 32--43, doi:10.1016/j.laa.2015.12.024.

Corollary 2.8 on arXiv PDF page 8 states that every 2-local *-homomorphism
between C*-algebras is a linear *-homomorphism. The preceding paragraph
explicitly combines Corollary 2.7 (automatic linearity) with Theorem 3.9 of
the source paper, which it cites as reference [27]. The supporting paper also
says that this gives a positive answer to its stated general C*-algebra
problem. Because Peralta authored both papers and the later paper directly
uses and cites the source theorem, the identification is explicit.

## Scope limitation

This resolves only the *-homomorphism half of Problem 3.12. The supporting
argument uses the symmetry of *-homomorphisms to obtain automatic linearity;
it does not establish that an arbitrary 2-local homomorphism is linear. A
bounded exact-phrase and arXiv-title/abstract search found no general theorem
settling that plain non-* half, so this packet does not claim it is resolved.
