# Local multiplier idempotence: later AF counterexamples

Status: **literature already answered (negative)**. No new theorem is claimed.

Frank and Paulsen's arXiv:math/0106131 asks whether
`M_loc(A)=M_loc(M_loc(A))` for every C*-algebra `A`. Ara and Mathieu's later
arXiv:math/0509437 answers this exactly: Theorem 1.1 constructs unital,
primitive AF algebras for which the second local multiplier algebra is
strictly larger than the first.
