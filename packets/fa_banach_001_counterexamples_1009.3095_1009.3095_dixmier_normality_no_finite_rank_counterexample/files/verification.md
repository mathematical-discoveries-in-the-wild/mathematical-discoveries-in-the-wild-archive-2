# Verification report

Candidate: Open Question 7.1 of arXiv:1009.3095.

## Claim checked

There is a spectral triple `(A,H,D)` of spectral dimension two such that
`A''` contains no nonzero finite-rank operator but
`Phi_omega(S)=Tr_omega(S<D>^{-2})` is nonnormal for every Dixmier trace in
the source conventions.

## Verdict

`likely valid` (confidence 94/100).  The construction is explicit, all
hypotheses reduce to elementary diagonal-operator calculations, and no
external theorem beyond the defining properties of a Dixmier trace is doing
hidden work.

## Step check

| Step | Status | Notes |

| `A` is an admissible algebra | valid | It is unital, nondegenerate, and generated by the countable family `I,P_1,P_2,...`. |
| `D` is self-adjoint with compact resolvent | valid | It is a real diagonal multiplication operator; level `m` has finite multiplicity `m-1`, and the eigenvalues tend to infinity. |

| `<D>^{-2}` is Dixmier measurable | valid | Complete-shell mass is `log M+O(1)` and shell count is `M^2/2+O(M)`; partial shells contribute `O(1/M)`. |

| Finite-row cuts vanish | valid | Each `F_r<D>^{-2}` is trace class because it is a finite sum of convergent `j^{-2}` rows. |
| Failure of normality | valid | `F_r` increases strongly to `I`, but all values are zero and the value at `I` is `1/2`. |
| Traciality on `A''` | valid | `A''` is abelian; this avoids any noncommutative extension issue. |

## Adversarial checks and discarded route

The first construction considered `A''=B(ell_2) tensor I`.  Its normality
obstruction was similar, but a nonzero bounded tracial functional cannot
exist on the properly infinite factor `B(ell_2)`.  Although the source's
question only asks normality, that version would have created an avoidable
tension with the source's description of `Phi_omega` as a trace.  Replacing
the first-factor algebra by the diagonal algebra `ell_infty` removes the
issue without changing the mass calculation.  The promoted construction is
therefore commutative at the von Neumann level.

Potential off-by-one errors in the spectral shells were checked explicitly:
for indices `i,j>=1`, the level `m=i+j` starts at 2, has multiplicity `m-1`,
and the number of eigenvalues through level `M` is exactly `M(M-1)/2`.

The phrase “contains no finite rank operators” must conventionally mean “no
nonzero finite-rank operators,” since every algebra contains the zero
operator.  The packet states this interpretation explicitly.
