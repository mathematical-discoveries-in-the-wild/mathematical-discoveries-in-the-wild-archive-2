# Stable exponent gain toward Coine's Schur-multiplier endpoint

**Status:** substantial partial result, likely valid; pending human review.

**Source:** Clément Coine, *Schur multipliers on* `B(L^p,L^q)`, arXiv:1703.08128, Problem 5.9 (PDF page 24).

## Result

For every `1 < p < r <= 2`,

```text
M(r,r) subset M(p,1).
```

More precisely, if `u_phi:ell_1->ell_infinity` has `r`-factorization norm `gamma_r(u_phi)`, then

```text
L_{1,p'}(u_phi)
  <= (kappa_{r,p}/kappa_{r,1}) gamma_r(u_phi),
```

where `kappa_{r,s}` is the `L^s` norm of a normalized symmetric `r`-stable scalar.  Thus every classical Hilbert-space Schur multiplier lies in `M(p,1)` for every `1<p<2`.

At the endpoint `p=r=2`, the Gaussian version gives a direct proof of the full (already literature-known) equality

```text
M(2,1)=M(2,2).
```

The mechanism is to embed the separable `L^r` factor by an `r`-stable random measure into random variables whose `L^p` norm is controlled and whose `L^1` norm is bounded below.  The output operator then extends from this `L^1` subspace to all of `L^1` because `ell_infinity` is injective.

## Scope

Problem 5.9 remains open here for `1<p<2`: the packet does **not** prove `M(p,p) subset M(p,1)` and supplies no counterexample.  The proof needs `p<r` because a nondegenerate `p`-stable variable has infinite `p`-th moment.  Eight focused upgrade attempts are recorded in the attempt log; the universal-operator route loses the needed information when it passes to a subspace of a quotient.
