# Problem II.2 answered negatively by arXiv:2607.28557

Status: `literature_already_answered`

Neeb's Problem II.2 on arXiv PDF page 40 asks whether every Lie group
modelled on a Mackey-complete locally convex space is regular, or whether
there is a counterexample.

Han and Liu, arXiv:2607.28557, Theorem 1.1, construct a contractible complex
analytic BCH--Lie group modelled on the complete Silva space
`phi_C` which is not even `C^0`-semiregular. Their smooth controls have no
group-valued `C^1` evolution. Since complete locally convex spaces are Mackey
complete and regularity implies evolution existence, this is an exact
negative answer.

The later paper's example has a homeomorphic exponential map, so it does not
answer the separate weaker Problem II.1 about universal existence of smooth
exponential maps.
