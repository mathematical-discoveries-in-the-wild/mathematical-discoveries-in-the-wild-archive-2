# Affine-hyperplane case of Ramm's finite-rank problems

Status: `likely valid partial result`.

For arXiv:math/0603631, Problems 3.1 and 3.2 are proved when the two
transverse algebraic hypersurfaces are affine complex hyperplanes in
`C^n`, `n >= 3`.  The finite-rank assumption produces a finite-dimensional
translation module in any nonzero common tangent direction.  Cayley--Hamilton
then gives a constant-coefficient ODE for the Fourier--Laplace transform,
forcing the original `L^2` density to be supported on a measure-zero algebraic
set.

The result does not settle general curved algebraic hypersurfaces: they need
not possess a global common translation direction.  Problems 1 and 2 of the
source paper are also not claimed here.
