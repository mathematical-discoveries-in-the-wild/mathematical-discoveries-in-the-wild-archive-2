# Atomic JBW*-triple Tingley question answered by arXiv:1701.05112

Status: `literature_already_answered`

## Source question

Francisco J. Fernandez-Polo and Antonio M. Peralta, *On the extension
of isometries between the unit spheres of a C*-algebra and B(H)*,
arXiv:1701.02916.

At the end of its introduction, after proving the extension theorem for
`B(H)` spaces and their `ell_infinity`-sums, the source asks whether Tingley's
problem has a positive answer for Cartan factors and atomic JBW*-triples.

## Explicit separate-paper answer

The same authors answered this question affirmatively in *Tingley's problem
through the facial structure of an atomic JBW*-triple*, arXiv:1701.05112,
posted seven days after the source preprint and later published in *Journal of
Mathematical Analysis and Applications* 455 (2017), 750--760.

Its main theorem (Theorem 2.9 in the published numbering) states that if `E`
and `B` are arbitrary atomic JBW*-triples, every surjective isometry
`f:S(E) -> S(B)` has a unique surjective real-linear isometric extension
`T:E -> B`. Since every Cartan factor is an atomic JBW*-triple, this also
answers the Cartan-factor part of the source question.

This is a direct, author-explicit, separate-paper resolution. No new
mathematical result is claimed.
