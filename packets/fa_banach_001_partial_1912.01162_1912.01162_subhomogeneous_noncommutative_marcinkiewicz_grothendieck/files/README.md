# Bounded-degree noncommutative Marcinkiewicz spaces

**Status:** candidate strong partial answer to the noncommutative extension
question in arXiv:1912.01162, subject to expert review.

For every fixed matrix size, compressing by matrix units and reconstructing
from entries identifies the noncommutative Marcinkiewicz space with a finite
product of scalar Marcinkiewicz spaces.  The same applies to finite central
sums, hence to semifinite type-I von Neumann algebras of uniformly bounded
degree.  The scalar Grothendieck criterion transfers exactly to homogeneous
atomless matrix amplifications.  Unbounded degree and type-II algebras remain
open in this packet.
