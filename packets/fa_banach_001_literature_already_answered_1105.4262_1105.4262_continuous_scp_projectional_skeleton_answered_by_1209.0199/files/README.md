# Continuous SCP versus projectional skeleton: already answered

Status: `literature_already_answered` (Question 1.4 only).

Kalenda--Kubiś, *Complementation in Spaces of Continuous Functions on Compact Lines* (JMAA 2012; arXiv:1105.4262), ask in Question 1.4 whether every Banach space with continuous \(k\)-SCP has a projectional skeleton.

Ferrer--Koszmider--Kubiś, *Almost disjoint families of countable sets and separable complementation properties* (JMAA 2013; arXiv:1209.0199), answer negatively in Theorem 1.6: there is an almost disjoint family \(\mathcal A\) for which \(C(K_{\mathcal A})\) has both controlled SCP and continuous SCP, yet has no projectional skeleton (and no PRI). Their proof gives a continuous chain of 2-complemented separable subspaces, so the counterexample satisfies the source hypothesis with \(k=2\).

The supporting paper cites the source and discusses precisely the implication from continuous SCP to a projectional skeleton. This packet does not claim answers to source Question 1.6 or Conjecture 4.2.
