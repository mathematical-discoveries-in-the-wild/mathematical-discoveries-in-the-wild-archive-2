\section*{Source conjecture}
For a locally convex $k$-space $E$, let $E^b$ denote its von Neumann bornology and $\Cpt(E)$ its compactoid bornology.  A sequence $(x_n)$ converges Mackey-bornologically to zero if there is a bounded set $B$ such that, for every $\lambda\in k^\times$, eventually $x_n\in\lambda B$.

After proving the following equivalence for nuclear Fr\'echet spaces, the source conjectures that nuclearity is unnecessary.

There is a harmless reversal in the last sentence of the source remark: compactoid sets are always von Neumann bounded, so (3)$\Rightarrow$(2) is immediate.  The substantive direction is (1)$\Rightarrow$(3), proved below.

\section*{Slow rescaling of a null sequence}

\begin{lemma}\label{lem:rescale}
Let $k$ be nontrivially valued and let $E$ be a metrizable locally convex $k$-space.  If $x_n\to0$ topologically, then there are $a_n\in k^\times$ such that $|a_n|\to\infty$ and $a_nx_n\to0$ topologically.
\end{lemma}

\begin{proof}
Choose $\pi\in k$ with $0<|\pi|<1$, and choose an increasing defining sequence of seminorms $p_1\leq p_2\leq\cdots$ for $E$.  Recursively choose
$N_1<N_2<\cdots$ so that
\[
 p_j(x_n)\leq |\pi|^{2r}
 \quad(n\geq N_r,\ 1\leq j\leq r).
\]
For $N_r\leq n<N_{r+1}$ set $a_n=\pi^{-r}$ (and define the finitely many earlier $a_n$ arbitrarily).  Then $|a_n|\to\infty$.  If $r\geq j$ and $N_r\leq n<N_{r+1}$, then
\[
 p_j(a_nx_n)\leq|\pi|^{-r}|\pi|^{2r}=|\pi|^r\longrightarrow0.
\]
Thus $a_nx_n\to0$ in every defining seminorm.
\end{proof}

\section*{Affirmative theorem for nontrivial valuations}

\begin{theorem}\label{thm:positive}
Let $k$ be a nontrivially valued field and $E$ a metrizable locally convex $k$-space.  For every sequence $(x_n)\subset E$, the following are equivalent:
\begin{enumerate}[label=(\arabic*),leftmargin=2em]
\item $x_n\to0$ topologically;
\item $x_n\to0$ Mackey-bornologically in $E^b$;
\item $x_n\to0$ Mackey-bornologically in $\Cpt(E)$.
\end{enumerate}
In particular the source conjecture holds for every Fr\'echet space over a nontrivially valued field, without nuclearity or local compactness of the field.
\end{theorem}

\begin{proof}
Assume (1).  Apply Lemma~\ref{lem:rescale} and put $y_n=a_nx_n$.  The set
\[
 K=\{0,y_1,y_2,\ldots\}
\]
is compact: any open set containing zero contains all but finitely many $y_n$.  Hence $K$ is precompact and therefore compactoid.  Its absolutely convex hull
$B=\Ga(K)$ is also compactoid.  Indeed, if $U$ is an absolutely convex zero-neighborhood and
$K\subset U+F$ for a finite $F$, then
\[
 \Ga(K)\subset U+\Ga(F).
\]

Now $x_n=a_n^{-1}y_n$ and $|a_n^{-1}|\to0$.  For any fixed
$\lambda\in k^\times$, eventually $|a_n^{-1}/\lambda|\leq1$; absolute convexity gives $x_n\in\lambda B$.  Thus (3) holds.

Every compactoid set is von Neumann bounded, so (3)$\Rightarrow$(2).  Finally, suppose (2) is witnessed by a bounded set $B$.  Given a zero-neighborhood $U$, boundedness gives a scalar $c\in k^\times$ with $B\subset cU$.  Mackey convergence, applied to $c^{-1}$, yields eventually
$x_n\in c^{-1}B\subset U$.  Hence (2)$\Rightarrow$(1).
\end{proof}

\section*{The trivially valued obstruction}

\begin{theorem}\label{thm:negative}
Let $k$ be a nonzero trivially valued field.  The conjectured equivalence fails for the Fr\'echet space $E=k^{\mathbb N}$ with its product topology.
\end{theorem}

\begin{proof}
Give each copy of $k$ its norm topology; because the valuation is trivial, it is discrete.  The product $E$ is complete and metrizable.  Its standard unit vectors $e_n$ converge coordinatewise, hence topologically, to zero.

We claim that every von Neumann bounded subset of $E$ is contained in $\{0\}$.  If a bounded set $B$ contained a nonzero $x$, choose a coordinate $j$ with $x_j\neq0$ and the absolutely convex open zero-neighborhood
\[
 U_j=\{z\in E:z_j=0\}.
\]
For every $\lambda\in k^\times$, triviality of the valuation gives
$\lambda U_j=U_j$, so no scalar multiple of $U_j$ contains $x$.  This contradicts boundedness.  Consequently a Mackey-null sequence in $E^b$ (and therefore in $\Cpt(E)$) must be eventually zero.  The sequence $(e_n)$ is not eventually zero, so (1) does not imply (2) or (3).
\end{proof}

\section*{Audit notes}
\begin{itemize}[leftmargin=1.4em,itemsep=2pt]
\item Completeness is not used in the positive theorem; metrizability is exactly what permits the diagonal slow rescaling.
\item The proof does not identify the two bornologies.  They can differ greatly; only their convergent sequences agree.
\item The absolutely convex hull step is valid because $U+\Ga(F)$ is absolutely convex and contains $K$.
\item Local compactness and spherical completeness of $k$ are not used.
\item Nontriviality of the valuation is essential, as Theorem~\ref{thm:negative} shows.
\end{itemize}
