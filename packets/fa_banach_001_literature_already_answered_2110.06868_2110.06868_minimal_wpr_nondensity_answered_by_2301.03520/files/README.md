# Problem 9.1 is already answered in later literature

Status: `literature_already_answered`.

Source question:

- F. Akrami, P. G. Casazza, A. Rahimi, M. A. Hasankhani Fard, and B. Daraby,
  *A note on (weak) phase and norm retrievable Real Hilbert space frames and
  projections*, arXiv:2110.06868.
- Location: Section 9, Problem 9.1, PDF page 14.
- Question: prove that weak phase retrievable frames with `2n-2` vectors in
  `R^n` are not dense among all such frames.

Supporting answer:

- P. G. Casazza and F. Akrami, *Classifying weak phase retrieval*,
  arXiv:2301.03520v2.
- Location: Section 5, Theorem 6, PDF page 7.
- The theorem proves non-density for every number of vectors `m >= 2n-2`, so
  `m=2n-2` is exactly the source problem.

The supporting abstract explicitly identifies this as an answer to a
longstanding open problem, so this is author-recognized provenance. Problems
9.2 and 9.3 of the source paper remain outside the theorem's scope.
