\section*{Source question}

F. Akrami, P. G. Casazza, A. Rahimi, M. A. Hasankhani Fard, and B. Daraby,
\emph{A note on (weak) phase and norm retrievable Real Hilbert space frames
and projections}, arXiv:2110.06868 (2021), Section 9, Problem 9.1, page 14:
\begin{quote}
Show that the weak phase retrievable frames with $2n-2$ vectors in $\R^n$
are not dense in all frames with $2n-2$ vectors.
\end{quote}

\section*{Supporting answer}

P. G. Casazza and F. Akrami, \emph{Classifying weak phase retrieval},
arXiv:2301.03520v2 (2023), Section 5, Theorem 6, page 7, proves:
\begin{quote}
The family of $m$-element weak phase retrieval frames is not dense in the set
of $m$-element frames in $\R^n$ for every $m\geq2n-2$.
\end{quote}
Taking $m=2n-2$ gives exactly Problem 9.1.  The supporting paper's abstract
also explicitly says that this result answers a longstanding open problem, so
the relation is author-recognized rather than an agent-only implication.

\section*{Scope}

This literature theorem answers only the non-density question.  It does not
settle Problem 9.2 (existence of $2n-2$ vector examples for $n\geq5$) or
Problem 9.3 (weak phase retrieval by $2n-2$ or $2n-3$ proper subspaces).
A separate candidate partial packet records an independent cofactor
characterization, an algebraic-nullity strengthening in the minimal case, and
a correction to the cited $\R^4$ example.
