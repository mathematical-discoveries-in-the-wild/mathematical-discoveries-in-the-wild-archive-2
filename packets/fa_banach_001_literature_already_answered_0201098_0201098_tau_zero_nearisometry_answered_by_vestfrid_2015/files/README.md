# The tau-zero nearisometry question is answered by Vestfrid (2015)

Status: `literature_already_answered` for the `tau(f(X))=0` branch; the broader
`tau(f(X))<1` branch is not claimed resolved here.

In Section 2.12 on printed page 6 of Jussi Vaisala's survey
arXiv:math/0201098, the author asks whether an epsilon-nearisometry
`f:X -> Y` with `tau(f(X))=0`, or perhaps merely `tau(f(X))<1`, can be
approximated by a surjective isometry.

Igor A. Vestfrid's 2015 paper *Stability of almost surjective
epsilon-isometries of Banach spaces*, J. Functional Analysis 269 (2015),
2165--2170, DOI 10.1016/j.jfa.2015.04.009, explicitly attributes this
question to Vaisala.  Theorem 2(iii) proves the stronger sufficient condition
`tau(f(X))<1/2` and the sharp estimate `||f(x)-Vx|| <= 2 epsilon` for a
surjective linear isometry `V:X -> Y`.  The sentence immediately after the
theorem explicitly says that this answers Vaisala's `tau=0` question.
