# 1106.4735 nonassociative Hindman/Ellis conjectures refuted by 1807.05469

Status: `literature_already_answered`

Moore's arXiv:1106.4735 formulates two central conjectures: a nonassociative
Hindman theorem (Conjecture 1.3) and an idempotent-mean extension of Ellis's
lemma to arbitrary binary systems (Conjecture 1.4). Moore's later
arXiv:1807.05469 explicitly and constructively refutes both.

The later paper builds a subset `Z` of every free binary system for which an
idempotent mean would force contradictory values, and uses the coloring
`c(mu)=mu(Z)` on the free one-generated binary system to force admissible
products arbitrarily close to both zero and one. This directly negates the two
source conjectures.

Scope: the later refutation does not classify all binary systems admitting
idempotent means, settle the product-closure question, resolve every fixed-`d`
version, or settle the finite Ramsey-number question equivalent in the source
to amenability of Thompson's group `F`.
