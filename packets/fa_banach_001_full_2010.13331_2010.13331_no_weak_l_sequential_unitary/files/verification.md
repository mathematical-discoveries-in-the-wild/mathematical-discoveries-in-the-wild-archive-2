# Verification

This is a purely analytic proof.  The decisive checks are:

1. a weakly convergent sequence in a Banach space is norm bounded;
2. `{f in L2(mu): |f| <= C a.e.}` is convex and norm closed, hence weakly
   closed;
3. infinite-dimensional `L2(mu)` contains a function outside `L-infinity`;
4. the cyclic spectral theorem sends the candidate vector to `1` and the
   unitary to multiplication by `z`;
5. the one-dimensional unitary summand in a contraction is excluded by
   simultaneously approximating a nonzero completely-nonunitary coordinate
   and a nonzero scalar coordinate.
