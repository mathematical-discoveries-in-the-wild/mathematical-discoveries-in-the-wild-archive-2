# arXiv:2506.04154 — unbounded d-weak convergence in c0

Status: candidate full counterexample, likely valid, pending human review.

The packet disproves Conjecture 1.5 of Gutiérrez–Nevanlinna. In `c0` with the supremum norm, `x_n = n e_n` is unbounded but d-weakly converges to zero. More generally, arbitrary-amplitude spikes on pairwise distinct coordinates d-weakly converge to zero in every sup-norm coordinate space containing the coordinate vectors.

Files:

- `solution_packet.pdf`: compiled self-contained proof packet.
- `main.tex`: packet source.
- `source_paper.pdf`: official arXiv source PDF.
- `figures/`: rendered source-page evidence and packet QA renders.
- `VERIFICATION.md`: verification and novelty notes.

The formal proof is elementary and does not depend on numerical computation.
