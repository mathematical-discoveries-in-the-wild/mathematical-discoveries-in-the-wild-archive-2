# Complete Copson-to-Cesaro embedding characterization

Status: `literature_already_answered`.

The open `p_2 > q_2` regime in arXiv:1507.07866 is completely covered by
Gogatishvili--Pick--Unver, arXiv:2203.00596 / JFA 283 (2022), Theorem 2.1
and Remark 2.3.  The later theorem characterizes the equivalent four-weight
Hardy--Copson inequality for every finite positive parameter tuple.  Under
the paper's substitution, the old missing inequality `p_2 > q_2` is `q < r`,
and cases (ii), (v), and (vi) of Theorem 2.1 exhaust it.
