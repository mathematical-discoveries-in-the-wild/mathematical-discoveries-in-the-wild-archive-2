# Higher-rank property (T) for Aut(F_n): outcome answered

Status: `literature_already_answered (higher-rank outcome only)`

On PDF page 2 of arXiv:1712.07167, Kaluba, Nowak, and Ozawa ask whether
their proof that `Aut(F_5)` has property (T) can be extrapolated to all
`Aut(F_n)`, `n >= 5`.

Kaluba, Kielak, and Nowak answer the substantive outcome in
arXiv:1812.03456. Theorem 1 on PDF page 2 proves that `Aut(F_n)` has
property (T) for every `n >= 6`; combined with the source result this gives
all `n >= 5`.

Scope limitation: the later proof uses stronger rank-five sum-of-squares
certificates and symmetrization, not property (T) of `Aut(F_5)` as a bare
black-box hypothesis. This packet therefore does not claim a formal abstract
implication, and it does not claim to answer the separate Bridson quotient
Question 12 mentioned in the source.
