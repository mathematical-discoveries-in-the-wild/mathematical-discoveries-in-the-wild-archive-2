# Verification report

Verdict: `candidate_counterexample_likely_valid` for Question 2.14 of
arXiv:1605.03538.

## Proof audit

- `X=ell_infinity^c(omega_1)` is norm closed in `ell_infinity(omega_1)`:
  the support of a uniform limit is contained in the countable union of the
  supports of an approximating sequence.  It is therefore a Banach lattice.
- Every `e in X_+` has countable support.  A coordinate unit vector outside
  that support is not in the closed ideal generated by `e`, so `X` has no
  quasi-interior point.
- The index set of all countable `C subset omega_1`, ordered by inclusion, is
  directed.  The ordinal `gamma_C=min(omega_1 minus C)` is defined for every
  index because no countable `C` exhausts `omega_1`.
- For a fixed `u in X_+`, take the countable index `D=supp(u)`.  If `C` contains
  `D`, then `gamma_C` is outside `D`, so `|x_C| wedge u=0`.  This proves
  un-nullity, not merely convergence along a restricted family of tests.
- Given any sequence `(C_n)`, the set `E={gamma_{C_n}:n in N}` is countable,
  so `u=1_E` belongs to `X_+`.  For every `n`,
  `|x_{C_n}| wedge u=e_{gamma_{C_n}}` has norm one.  Thus no sequence of
  terms is un-null.  This includes every increasing sequence of indices and
  directly negates Question 2.14.

## Upgrade attempts

1. An uncountable `c_0`-sum of non-order-continuous components was examined.
   Its small tails allow a diagonal extraction, so it does not yield a
   counterexample.
2. Non-sigma-compact `C_0(L)` spaces were examined through the compact-open
   interpretation of un-convergence.  Topological sums of compact pieces
   again reduce to the unsuccessful `c_0` mechanism.
3. Passing to bounded functions with arbitrary countable support gives the
   successful construction.  The final argument upgrades the requested
   failure for increasing selections to failure for every sequence of net
   values.
