# Critical Benjamin–Ono–BBM quasi-invariance: literature answer

**Status:** `literature_already_answered (core quasi-invariance; exact density remains open)`.

**Source:** G. Genovese, R. Lucà, and N. Tzvetkov, *Transport of Gaussian measures with exponential cut-off for Hamiltonian PDEs*, arXiv:2103.04408v3, PDF page 4.

**Supporting answer:** G. Genovese, R. Lucà, and N. Tzvetkov, *Quasi-invariance of Gaussian measures for the periodic Benjamin-Ono-BBM equation*, arXiv:2107.03445v2, Theorem 1.1 and Remark 1.2, PDF page 2.

The source plans to extend its BBM quasi-invariance theorem to the critical dispersion `beta=1`.  The same authors' follow-up explicitly says that it extends the previous `beta>1` achievements to the minimal-dispersion case `beta=1`.  Theorem 1.1 proves quasi-invariance for every `s>1`, with the transported density in some `L^p`, `p>1`; Remark 1.2 removes the energy cutoff when only quasi-invariance is sought.

This answers the core quasi-invariance future-work target.  It does **not** reproduce the full density conclusion of the source theorem: the follow-up explicitly says that identifying the Radon–Nikodym density remains open at critical dispersion, and it obtains some `p>1` rather than every finite `p`.
