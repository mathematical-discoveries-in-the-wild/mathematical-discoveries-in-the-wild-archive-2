# Infinite-dimensional separable Hilbert spaces do not have nice geodesics

Status: `candidate_full_likely_valid`.

The source asks whether every separable Hadamard space has its “nice
geodesics structure,” meaning that projections onto the segments determined
by one countable dense set detect projection convergence along every segment.

The answer is no already for `ell^2`.  For any countable dense sequence,
finite-span orthogonal residuals can be rescaled so that their projections
onto every fixed test segment eventually vanish, while their projections
onto one omitted segment stay equal to its endpoint.  The witness sequence
is unbounded.

The packet also proves the exact Hilbert-space classification: a separable
Hilbert space has the stated property if and only if it is finite-dimensional.

review checklist.  The official source PDF is included.
