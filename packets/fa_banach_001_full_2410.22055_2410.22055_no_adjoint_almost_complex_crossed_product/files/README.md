# No adjoint-induced almost-complex structure on the crossed-product quotient

This packet gives a candidate full negative answer to the sole open question
in Table 2 of arXiv:2410.22055.

For every unital associative algebra `A`, proper two-sided ideal `I`, and
`d in A`, the induced inner derivation on `A/I` annihilates the nonzero unit
coset.  It therefore cannot square to minus the identity.  Equivalently,

`(ad_d^2 + I_A)(1) = 1 notin I`.

Thus the crossed (non-fixed)/adjoint question mark in Table 2 is a minus
sign.  This does not classify the partially open Nijenhuis entries in Table
1.
