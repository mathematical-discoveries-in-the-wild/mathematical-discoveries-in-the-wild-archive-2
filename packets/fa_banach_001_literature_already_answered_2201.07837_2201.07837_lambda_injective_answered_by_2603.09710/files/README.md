# The \(\lambda>2\) injectivity problem is answered by arXiv:2603.09710

Status: **literature_already_answered**

## Source question

Tomasz Kania and Grzegorz Lewicki, *A forgotten theorem of Pełczyński:
\((\lambda+)\)-injective spaces need not be \(\lambda\)-injective - the case
\(\lambda\in(1,2]\)*, arXiv:2201.07837 (Studia Mathematica, 2023).

At the end of the discussion following Theorem A in the Introduction, the
authors state that the complementary case \(\lambda\in(2,\infty)\) remains a
mystery. Equivalently, the missing claim is:

> For every \(\lambda>2\), does there exist a \((\lambda^+)\)-injective
> Banach space that is not \(\lambda\)-injective?

## Answer

The same authors answer this affirmatively in *\((\lambda^+)\)-injective
Banach spaces*, arXiv:2603.09710 (2026), Theorem A:

> For every \(\lambda>1\) there exists a Banach space that is
> \((\lambda^+)\)-injective but not \(\lambda\)-injective.

The answering paper explicitly identifies arXiv:2201.07837 as its companion
paper and says that it resolves the complementary range left open there.
Its key zero-sum construction multiplies a non-attained relative projection
constant by \(2-2/N\) while preserving non-attainment; iteration reduces any
\(\lambda>2\) to the previously solved interval \((1,2]\).

## Scope

This is an exact, author-acknowledged literature answer. It completes
Pełczyński's claimed theorem for every \(\lambda>1\). It does not settle the
separate complex-scalar endpoint question whether every
\((1^+)\)-injective complex Banach space is \(1\)-injective.
