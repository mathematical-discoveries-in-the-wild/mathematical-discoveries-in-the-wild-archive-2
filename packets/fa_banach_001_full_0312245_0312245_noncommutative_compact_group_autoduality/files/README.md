# A noncommutative compact group with one-sided Kwapień autoduality

Status: `candidate_full_likely_valid_literal_questions`.

This packet answers both final questions of arXiv:math/0312245.

1. The first answer is yes. Autoduality lifts through compact quotients, so
   `G = T x SU(2)` inherits the torus's one-sided Kwapień property. It is
   noncommutative and has irreducible representations of unbounded dimension.
2. The second answer is no. For this same dual system, the source's spaces
   `R_p` have Banach type 2 (`p>2`) or Banach cotype 2 (`p<2`), but complete
   type/cotype would force `R_p` to be completely isomorphic to `OH`, which
   is impossible for `p != 2`.

More generally, every noncommutative compact group with a torus or Cantor
group quotient satisfies the first property. A stronger quotient-free
version remains open.
