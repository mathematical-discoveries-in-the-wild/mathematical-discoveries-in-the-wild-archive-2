# Sharp Fourier-spectrum Hölder bounds

Candidate full solution to Question 1.4 of arXiv:2210.07019.

The packet proves:

- the published upper bound for an alpha-Hölder Fourier transform is attained
  by finite positive, generally unbounded measures;
- compact support improves the universal bound to
  `dim_F^theta(mu) <= dim_F(mu) + d theta`;
- compact positive measures attain the improved bound for every theta.
