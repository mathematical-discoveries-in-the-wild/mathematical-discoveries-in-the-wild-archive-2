# Semi-skew polarity operators have axis fixed points

This packet gives a full negative answer to the precise semi-skew
nonexistence question in Remark 10.2 of arXiv:1708.09741.

For every two-dimensional semi-skew matrix

    G = [[0, alpha2], [-alpha1, 0]]

with same-sign unequal weights, the two coordinate axes solve
C=(GC)^polar. More strongly, the packet proves that these axes are the only
nonempty solutions in dimension two.

Files:

- solution_packet.pdf: self-contained counterexample and classification.
- source_paper.pdf: the official arXiv v4 PDF.
- figures/open_question_page20.png: real source-page crop containing the
  exact semi-skew question in Remark 10.2.
- code/verify_axis_solutions.py: exact symbolic checks.
- VERIFICATION.md: proof and artifact audit.

The broader classification for arbitrary non-positive-definite operators is
not claimed.
