\section{The source question and the answer}

For an open set $\Omega\subset\R^d$, a locally convex Hausdorff space $E$,
and $k<\infty$, the source calls the implication
\[
  e'\circ f\in\Ck^k(\Omega)\quad(e'\in E')
  \qquad\Longrightarrow\qquad
  f\in\Ck^k(\Omega,E)
\]
the full $\Ck^k$ weak--strong principle. It proves this for semi-Montel
targets and asks whether the $k=0$ result for generalised Schwartz spaces
continues to hold when $0<k<\infty$.

\begin{center}
\includegraphics[width=0.91\textwidth]{figures/open_question_crop.png}
\end{center}

\noindent The answer is \emph{no for every finite $k\geq1$}. The obstruction
is exactly the distinction between precompactness in an incomplete space and
compactness inside the space.

\section{The target space}

Let
\[
 E=c_{00}:=\{x=(x_n)_{n\geq1}\in\K^{\N}:x_n=0\text{ for all but finitely
 many }n\},
\]
over $\K=\R$ or $\mathbb C$, with the topology induced by the product topology of
$\K^{\N}$. Thus the seminorms
\[
 p_F(x):=\max_{n\in F}|x_n|,\qquad F\subset\N\text{ finite},
\]
generate the topology.

\begin{lemma}\label{lem:space}
The space $E$ is a generalised Schwartz space, $E'$ consists exactly of the
finite linear combinations of the coordinate projections, and $E$ is not
semi-Montel.
\end{lemma}

\begin{proof}
If $\ell\in E'$ is continuous, some basic zero-neighbourhood controlling only
a finite coordinate set $F$ is mapped by $\ell$ into a bounded subset of
$\K$. Every vector vanishing on $F$ can be multiplied by arbitrary scalars
while remaining in that neighbourhood, so $\ell$ vanishes on it. Hence
$\ell$ depends only on the coordinates in $F$. The converse is immediate.

A set $B\subset E$ is bounded precisely when
\[
 \sup_{x\in B}|x_n|<\infty\qquad\text{for every }n\in\N.
\]
In particular, $E'$ determines boundedness, as required in the source theorem.
Given a zero-neighbourhood that controls finitely many coordinates, project
$B$ onto those coordinates. This bounded set has a finite net. Lifting its
net points as
finite-support vectors gives a finite net for $B$ in $E$. Consequently every
bounded set is precompact, which is the generalised Schwartz property used in
the source.

Finally, set $s_N=(1,\ldots,1,0,\ldots)$, with the first $N$ coordinates equal
to one. The set $\{s_N:N\geq1\}$ is bounded. Every subsequence with indices
tending to infinity converges in the completion $\K^{\N}$ to
$(1,1,\ldots)$, which is not in $E$, and therefore has no convergent
subsequence in $E$. Since $E$ is metrizable, this bounded set cannot have
compact closure. Thus $E$ is not semi-Montel.
\end{proof}

\section{The counterexample}

\begin{theorem}\label{thm:counterexample}
For every integer $k\geq1$ there is a map $f_k:\R\to E$ such that
\begin{enumerate}[label=\textup{(\alph*)}]
\item $e'\circ f_k\in\Ck^\infty(\R)$ for every $e'\in E'$;
\item $f_k\in\Ck^{k-1}(\R,E)$;
\item $f_k$ is not $k$ times differentiable at zero, and hence is not in
      $\Ck^k(\R,E)$.
\end{enumerate}
In particular, the full finite-order weak--strong principle fails for the
generalised Schwartz space $E$ for every $k\geq1$.
\end{theorem}

\begin{proof}
Choose $\chi\in\Ck_c^\infty(\R)$ such that $\chi=1$ on a neighbourhood of
zero, and define
\begin{equation}\label{eq:curve}
  f_k(t):=\bigl(t^k\chi(nt)\bigr)_{n\geq1}.
\end{equation}
If $t\ne0$, compactness of $\operatorname{supp}\chi$ implies that
$\chi(nt)=0$ for every sufficiently large $n$; and $f_k(0)=0$. Thus
$f_k(t)\in c_{00}$ for every $t$.

By Lemma~\ref{lem:space}, every $e'\in E'$ uses only finitely many
coordinates. Therefore $e'\circ f_k$ is a finite linear combination of the
smooth scalar functions $t\mapsto t^k\chi(nt)$, proving (a).

For $0\leq j<k$, the coordinatewise $j$th derivative at zero is zero. Away
from zero the family in \eqref{eq:curve} is locally finite, so all derivatives
are obtained coordinatewise and remain in $c_{00}$. The product-subspace
topology is precisely coordinatewise convergence on finite coordinate sets;
hence these derivatives are continuous at zero as well. This proves (b).

Suppose that the $E$-valued $k$th derivative at zero existed. Applying the
continuous $n$th coordinate projection would give
\[
 \bigl(f_k^{(k)}(0)\bigr)_n
 =\left.\frac{d^k}{dt^k}\bigl(t^k\chi(nt)\bigr)\right|_{t=0}
 =k!
 \qquad(n\geq1),
\]
because $\chi$ is identically one near zero. The derivative would therefore
have to be $k!(1,1,\ldots)$, which is not an element of $c_{00}$. This
contradiction proves (c).
\end{proof}

\section{Sharp context: the Banach-space case}

The first sentence of the source question also asks whether there are
infinite-dimensional targets beyond the semi-Montel class. For Banach spaces
this was already answered by Bachir and Lancien~\cite{bachir-lancien}.

\begin{proposition}[Bachir--Lancien]
If $X$ is a Banach space with the Schur property, $U$ is open in a Banach
space, and $f:U\to X$ is weakly $\Ck^k$ for a positive integer $k$, then
$f\in\Ck^k(U,X)$.
\end{proposition}

Thus $\ell^1$ is an infinite-dimensional positive example. Their paper also
characterizes the Schur property through weak differentiability. For
completeness, the finite-order converse can be seen directly. If $X$ is not
Schur, choose a weakly null sequence $(x_n)$ with $\|x_n\|=1$. Put
$a_n=4^{-n}$, $\delta_n=a_n/8$, take a nonzero
$\varphi\in\Ck_c^\infty((-1,1))$, and paste the disjoint bumps
\[
 F(t)=a_n^k\varphi\!\left(\frac{t-a_n}{\delta_n}\right)x_n
 \quad\text{for }|t-a_n|<\delta_n,
 \qquad F(t)=0\quad\text{otherwise}.
\]
All scalar $k$th derivatives tend to zero at the accumulating point because
$x'(x_n)\to0$ for every $x'\in X'$, whereas at a fixed nonzero derivative
point of $\varphi$ the norms of the vector $k$th derivatives stay bounded
away from zero. Hence $F$ is weakly $\Ck^k$ but not norm-$\Ck^k$. For each
fixed finite $k\geq1$, the Banach full weak--strong principle is therefore
equivalent to the Schur property.

The new contribution of Theorem~\ref{thm:counterexample} is different: it
settles the source's explicit proposal that \emph{every} generalised Schwartz
space might work. It shows that precompact bounded sets do not prevent a
derivative from escaping into the completion.

\section{Verification, novelty, and limitations}

The accompanying finite-window script checks the support bound and the forced
derivative prefixes for $1\leq k\leq8$. These computations are only sanity
checks; the infinite-support contradiction is the proof.

A bounded web and literature search on 13 August 2026 used the exact source
title together with the phrases ``generalised Schwartz weak--strong,''
``$c_{00}$ weak--strong differentiable,'' and ``$\Ck^k$ weak--strong Schur.''
It recovered the source and Bachir--Lancien, but no occurrence of the
counterexample above. The novelty verdict is therefore \emph{apparently new
within the bounded search}, not an exhaustive bibliographic guarantee.

The result answers Question 5.3.9(i)'s generalised-Schwartz follow-up for all
positive finite orders. It does not settle parts (ii)--(iv) in their full
locally convex generality. Human review should focus on the standard dual and
precompactness facts in Lemma~\ref{lem:space}.
