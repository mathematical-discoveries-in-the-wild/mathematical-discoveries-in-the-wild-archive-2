# Open Problem 7.4 answered by arXiv:2410.04948

Status: `literature_already_answered`

This is a literature-status record, not a new theorem proved by this run.

## Source question

Mihail N. Kolountzakis, Nir Lev, and Máté Matolcsi, *Spectral sets and
weak tiling*, arXiv:2209.04540; *Sampling Theory, Signal Processing, and
Data Analysis* 21 (2023), article 31.

Open Problem 7.4 on arXiv PDF page 18 asks whether there is a bounded
measurable set which weakly tiles its complement, but which is neither a
proper translational tile nor a spectral set.

## Explicit later answer

Gergely Kiss, Itay Londner, Máté Matolcsi, and Gábor Somlai, *A lonely weak
tile*, arXiv:2410.04948; *Expositiones Mathematicae* 44(1) (2026), article
125636, doi:10.1016/j.exmath.2024.125636.

The abstract and introduction explicitly say that the paper answers the
question raised in the source paper, cited as reference [19]. Section 3
constructs a finite-group set which weakly pd-tiles but is neither spectral
nor a tile. The final paragraph lifts it to a finite union of unit cubes in
R^5, preserving all three properties. Máté Matolcsi is an author of both
papers, so this is an author-explicit identification.

## Scope

This completely answers Open Problem 7.4 in the affirmative. It does not
address the source paper's other three open problems: nowhere-dense spectral
sets in dimensions at least two, spectrality of the second factor in certain
spectral products, or the classification of extremal weak-tiling measures of
convex bodies.
