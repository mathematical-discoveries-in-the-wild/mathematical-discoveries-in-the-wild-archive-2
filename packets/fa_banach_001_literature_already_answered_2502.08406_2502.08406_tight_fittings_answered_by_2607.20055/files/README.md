# Literature status: Conjecture 22 of arXiv:2502.08406

Status: fully answered by later literature.

David Kalaj's arXiv:2607.20055v2 proves the missing Gromov--Ros
isoperimetric classification and thereby makes the Li--Su contraction theorem
unconditional in every complex dimension.  Theorem 7.1 and Corollaries
7.2--7.3, combined with the embedding and compactness classifications in the
source paper, prove both tight-fitting equivalences in Conjecture 22.

The Bergman equality cases are stated in Corollary 7.2.  The Hardy endpoint
equality cases follow by inserting an arbitrary intermediate Bergman norm: an
endpoint equality forces equality in the intermediate Bergman--Bergman
contraction, whose equality theorem gives exactly the claimed kernel.

The compact PDF note records the parameter translation between the two papers
and this short endpoint-equality deduction.  Official source PDFs were not
copied into this packet because they were not present in the local corpus at
packaging time; the arXiv identifiers and exact theorem labels are included.
