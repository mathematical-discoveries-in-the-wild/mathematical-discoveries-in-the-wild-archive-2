# Exact mixed-norm Bernstein numbers in aligned parameter regions

This packet gives a substantial partial answer to the Bernstein-number
question in arXiv:2410.10731.  It proves an exact formula, for every index
`n`, on two full aligned cones of the four exponent parameters and transfers
the result to the corresponding critical Besov embeddings on Euclidean
space.

The crossed regions are explicitly not claimed.  See `main.tex` and the
upgrade-attempt record for the proof and the remaining obstruction.
