# Surjectivity of the probability-level lifting map

Candidate full affirmative answer to the open question at the end of
Section 7 of arXiv:2402.04926.

The unrestricted algebraic-dual lifting map `kappa_0` is surjective by a
Hamel-basis construction.  Any lift of a sequentially continuous map
`E -> L^0(Omega)` is automatically probability-continuous, so the restricted
map `kappa_1` is always surjective as well.
