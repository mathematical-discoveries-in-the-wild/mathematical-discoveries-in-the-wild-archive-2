# Scheepers' conjecture: later CH counterexample

Status: `literature_already_answered`.

The source paper is Boaz Tsaban and Lyubomyr Zdomskyy, *Hereditarily
Hurewicz spaces and Arhangel'skii sheaf amalgamations*, arXiv:1004.0211v2.
Section 4.4, PDF page 13, asks whether Scheepers' conjecture---that a space is
wQN if and only if it satisfies `S_1(Gamma,Gamma)`---is provable.

Yinhe Peng, *Scheepers' conjecture and the Scheepers diagram*, Transactions of
the American Mathematical Society 376 (2023), 1199--1229,
<https://doi.org/10.1090/tran/8787>, explicitly states that it refutes the
conjecture under CH. Its main result gives, assuming CH, a set of reals `X`
such that `C_p(X)` has property `alpha_2` while `X` fails
`S_1(Gamma,Gamma)`. The source paper's own Section 4.4 identifies
`C_p(X)` being `alpha_2` with the clopen gamma-selection property and then
identifies that property with `X` being wQN. Thus Peng's set is exactly a wQN
counterexample to the conjectured implication.

Consequently the source's provability question has a negative answer (relative
to the consistency of CH/ZFC). Together with the source's Laver-model positive
result, this gives the expected independence picture. This does not assert an
unconditional ZFC counterexample.
