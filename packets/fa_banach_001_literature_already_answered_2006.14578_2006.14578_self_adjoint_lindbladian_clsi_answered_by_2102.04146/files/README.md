# Self-adjoint finite-dimensional Lindbladians have positive CLSI

Status: **literature already answered (Conjecture 1.4 only)**.

Junge, Li, and LaRacuente conjecture in arXiv:2006.14578 that every
self-adjoint Lindbladian `L` has `CLSI(L)>0`. Gao and Rouzé answer this in
arXiv:2102.04146: their Theorem 3.3 proves a complete modified logarithmic
Sobolev inequality for every finite-dimensional GNS-symmetric quantum Markov
semigroup (with the automatic ambient-matrix extension in the source setting).
The published version of *Graph Hörmander Systems* explicitly acknowledges
this later result.

This packet is deliberately claim-specific. The distinct anti-transference
conjecture in arXiv:2006.14578, concerning recovery of `CLSI(Delta_X)` from
finite-dimensional transferred generators, is not resolved by Gao--Rouzé and
remains open in the 2025 published version.
