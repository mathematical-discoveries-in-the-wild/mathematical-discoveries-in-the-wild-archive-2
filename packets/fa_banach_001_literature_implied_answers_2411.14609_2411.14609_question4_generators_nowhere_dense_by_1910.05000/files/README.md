# Question 4 has a literature-implied negative answer

Status: `literature_implied_answer_full_negative`.

Abbar--Costa Jr., arXiv:2411.14609v1, Question 4 (printed page 31), asks
whether the set of generators of hypercyclic algebras must be residual, or at
least dense, whenever a continuous linear map on an F-space supports a
hypercyclic algebra.

Bayart--Costa Jr.--Papathanasiou, arXiv:1910.05000, Remark 6.7 (printed pages
50--51), had already constructed a commutative Banach-algebra product for
which that generator set is nonempty and nowhere dense. This answers both
parts of Question 4 negatively.

The identification is exact but not a new theorem. The source paper cites the
supporting article in its bibliography without connecting this remark to
Question 4. The example varies the algebra product, so it does not settle the
more special fixed-coordinatewise-product question for tree sequence spaces.
