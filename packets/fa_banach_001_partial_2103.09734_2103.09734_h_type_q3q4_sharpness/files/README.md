# H-type Q3--Q4 sharpness in center dimensions 3 and 7

Status: **candidate substantial partial result, likely valid, human review
requested**.

This packet answers a nontrivial subcase of Remark 1.2(iv) in
Roos--Seeger--Srivastava, arXiv:2103.09734.  A common invariant horizontal
block of dimension `m+1`, together with a compatible tilt, gives the exact
missing `Q3 Q4` Knapp inequality.  Consequently the published local
maximal-region is sharp in the previously untreated `Q3 Q4` direction for
untilted H-type groups with center dimension `m=3` or `m=7`.

The full problem for arbitrary Metivier groups, other center dimensions, and
arbitrary tilts is not claimed.

Files:

- `solution_packet.pdf`: human-readable theorem and proof.
- `source_paper.pdf`: official arXiv v2 source PDF (29 pages).
- `figures/open_problem_crop.png`: source p. 5, Remark 1.2(iv).
- `code/verify_exponents_and_clifford.py`: exact exponent and model checks.
- `verification.md`: build, visual, algebraic, and scope audit.

and the use of the real Clifford-module classification for `m=3,7`.
