# Rank conditions removed by arXiv:1305.1756

Status: `literature_implied_answer (full exact question)`

The 2012 source arXiv:1202.1099 asks on PDF pages 10 and 15 whether the rank hypotheses in Lemma 4.1 and Proposition 6.1 are inherent. The same authors' later paper arXiv:1305.1756 answers both formal questions without those hypotheses.

- Supporting Theorem 1.2(i) iff (ii), PDF pages 3–4: a realization is minimal iff one constant `K` makes `spect(A)` disjoint from `spect(A+BKC)`.
- Supporting Theorem 1.2(i) iff (iv), PDF pages 3–4: minimality is equivalent to absence of an eigenvalue of `A` fixed in the spectrum of every completion `[A B; C D]` (with the paper's minimal square reduction when needed).

Thus neither equality of `rank(B), rank(C)` nor a lower bound by the number of Jordan blocks is inherent.

This is classified as literature-implied rather than literature-already-answered because arXiv:1305.1756 does not cite or explicitly name the 2012 source question, even though it is a separate later paper by the same authors and its theorem is an exact match.
