\section*{Source question}

Eisner's paper \emph{Embedding operators into strongly continuous
semigroups}, arXiv:0808.2419, proves that an embeddable bounded operator
\(T\) must have both \(\dim\ker T\) and \(\operatorname{codim}\operatorname{rg}T\)
equal to either zero or infinity.  Question 3.4 asks for which operator
classes this condition is sufficient.  Later, Remark 5.4 explicitly requests
a non-trivial operator satisfying this necessary condition which is not
embeddable.

\section*{Result}

The necessary condition is not sufficient, even in the much narrower class
of invertible surjective isometries on complex Banach spaces.  An elementary
counterexample is multiplication by the coordinate function on
\(C(\Torus)\).  In fact, this operator has no \(n\)-th root for any
\(n\geq2\), so its failure of embeddability is purely algebraic and does not
depend on continuity estimates for a candidate semigroup.

\section*{Proof}

Let \(X=C(\Torus)\), with the supremum norm, and define
\[
  (Vf)(z)=z f(z) \qquad (z\in\Torus).
\]
The inverse is multiplication by \(\bar z\).  Hence \(V\) is an invertible
surjective isometry.  In particular,
\[
  \dim\ker V=0,
  \qquad
  \operatorname{codim}\operatorname{rg}V=0,
\]
so it satisfies Eisner's necessary condition in its strongest possible form.

\begin{lemma}\label{lem:root}
If \(S\in\mathcal L(C(\Torus))\) and \(S^n=V\) for some integer \(n\geq2\),
then there is a function \(h\in C(\Torus)\) such that \(h^n(z)=z\) for every
\(z\in\Torus\).
\end{lemma}

\begin{proof}
Because \(S^n=V\), the operators \(S\) and \(V\) commute.  Since \(V\) is
invertible, \(S\) also commutes with every integer power \(V^k\),
\(k\in\mathbb Z\).  Thus \(S\) commutes with multiplication \(M_p\) by
every trigonometric polynomial \(p\).  Trigonometric polynomials are
uniformly dense in \(C(\Torus)\), and
\(\lVert M_p-M_f\rVert=\lVert p-f\rVert_\infty\); consequently \(S\)
commutes with \(M_f\) for every \(f\in C(\Torus)\).

Put \(h=S\mathbf1\).  For arbitrary \(f\in C(\Torus)\),
\[
  Sf=S(M_f\mathbf1)=M_f(S\mathbf1)=fh.
\]
Thus \(S=M_h\).  Applying \(S^n=V\) to \(\mathbf1\) gives
\(h^n(z)=z\) on \(\Torus\).
\end{proof}

\begin{theorem}
The surjective isometry \(V\) has no bounded \(n\)-th root for any integer
\(n\geq2\), and therefore cannot be embedded into a \(C_0\)-semigroup.
\end{theorem}

\begin{proof}
If \(h^n(z)=z\), then \(h\) never vanishes and \(|h(z)|=1\) on \(\Torus\).
Let \(d\in\mathbb Z\) be the winding number of \(h:\Torus\to\Torus\).
The winding number of \(h^n\) is \(nd\), whereas the coordinate function
\(z\mapsto z\) has winding number \(1\).  The equality \(h^n(z)=z\) would
therefore imply \(nd=1\), impossible for \(n\geq2\).  Lemma~\ref{lem:root}
now excludes every bounded \(n\)-th root of \(V\).

If \((T(t))_{t\geq0}\) were a \(C_0\)-semigroup with \(T(1)=V\), then
\(T(1/n)^n=T(1)=V\) for every \(n\geq2\), contradicting the preceding
conclusion.
\end{proof}

\begin{corollary}
Eisner's kernel--range condition is not sufficient for embeddability on
general complex Banach spaces, even after restricting to invertible
surjective isometries.
\end{corollary}

This also separates sharply the Banach-space situation from Theorem 4.4 of
the source paper: every unitary operator on a Hilbert space is embeddable,
whereas a surjective isometry on a Banach space need not even possess a
square root.

\section*{Relation to the explicit request in Remark 5.4}

\begin{center}
\includegraphics[width=0.95\linewidth]{figures/nontrivial_request_crop.png}
\end{center}

The operator \(V\) is ``non-trivial in the sense of Theorem 3.1'' exactly as
requested: neither a finite nonzero kernel nor a finite nonzero range defect
explains the failure.  The obstruction instead lies in the topology of the
maximal multiplication algebra generated by \(V\).

\section*{Scope and upgrade audit}

This packet gives a complete counterexample to sufficiency for arbitrary
operators and answers the source's request for a non-trivial example.  It
does not settle the separate compact-operator question in Remark 5.4, nor
does it classify all operator classes for which the condition is sufficient.

The strongest route was checked at each vulnerable point: a hypothetical
semigroup supplies bounded roots; an arbitrary root must commute with \(V\);
commutation with \(V\) and \(V^{-1}\) extends by trigonometric-polynomial
density to every multiplier; and the commutant calculation then forces the
root to be a multiplier.  The final winding-number obstruction excludes all
orders \(n\geq2\), not only square roots.
Human review should check the short commutant lemma and confirm novelty; the
mathematical claim otherwise uses only norm-density of trigonometric
polynomials and \(\deg(h^n)=n\deg(h)\).
