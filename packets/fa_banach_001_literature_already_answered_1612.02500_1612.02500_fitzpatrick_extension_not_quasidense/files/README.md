# Literature answer for arXiv:1612.02500

The target paper asks whether the Fitzpatrick extension of every closed,
monotone, quasidense multifunction must be quasidense.

Simons, arXiv:2407.00479, Examples 9.3 and 9.8, answers **no**. For the tail
map `U: l1 -> c0`, the inverse relation `S=U^{-1}: c0 -> l1` is quasidense,
but its Gossez/Fitzpatrick extension is the tail operator
`T: l1 -> linfinity`, which is not quasidense.
