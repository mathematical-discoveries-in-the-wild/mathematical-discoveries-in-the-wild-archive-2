# 0610420 — continuous images of RN compacta need not be RN

Status: literature_already_answered (full negative answer to the continuous-image problem).

Model: GPT5.6.

Source: Richard Haydon, *Locally uniformly convex norms in Banach spaces and their duals*, arXiv:math/0610420v2, source PDF page 4.

Supporting answer: Antonio Avilés and Piotr Koszmider, *A continuous image of a Radon–Nikodým compact space which is not Radon–Nikodým*, arXiv:1112.4152, abstract and Theorem 1.1 on supporting PDF pages 1–2.

## Identification

Haydon describes as open the problem whether every continuous image of a Radon–Nikodým compact space is again Radon–Nikodým.

Avilés and Koszmider give a full negative answer: they construct a continuous surjection `pi:L_0 -> L_1` such that `L_0` is a zero-dimensional RN compact space but `L_1` is not RN. Their abstract says explicitly that this solves the problem posed by Isaac Namioka, and their introduction restates the closure-under-continuous-images question before Theorem 1.1.

The supporting authors do not cite Haydon’s paper, but they explicitly know they are resolving the same named general problem. This therefore belongs in `literature_already_answered`, not in a new counterexample packet.

## Scope

This settles only the continuous-image problem mentioned on source page 4. It does not settle Haydon’s subsequent question whether `C(K)` is LUR-renormable for every descriptive compact `K`, nor the equivalent w*LUR-dual renorming question.
