# Finite-operator-span classification for Hardy and Bergman compositions

Status: `candidate_substantial_partial_likely_valid` for arXiv:1401.1697 and
Question 21 of arXiv:1505.01945.

For an analytic operator weight whose range spans a finite-dimensional
subspace of `L(X,Y)`, write a minimal decomposition

`psi(z) = sum_k a_k(z) U_k`.

On both `H^p` and `A^p`, the packet proves:

- boundedness iff every scalar `W_{a_k,phi}` is bounded;
- compactness iff every `U_k` and every scalar `W_{a_k,phi}` is compact;
- for `1<p<infinity`, weak compactness iff every `U_k` is weakly compact.

For a constant nonzero operator weight, the `p=1` weak endpoint is also
classified: `U C_phi` is weakly compact iff `U` is weakly compact and scalar
`C_phi` is compact.
