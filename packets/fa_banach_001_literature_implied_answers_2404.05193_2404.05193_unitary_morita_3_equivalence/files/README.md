# Later literature answers the unitary Morita 3-equivalence conjecture

Status: `literature_implied_answer (full conjecture)`.

Original source: Giovanni Ferrer, *Foundations for operator algebraic
tricategories*, arXiv:2404.05193.  The conjecture is on PDF page 26, immediately
after Example 3.15.

Supporting source: Quan Chen, Giovanni Ferrer, Brett Hungar, David Penneys, and
Sean Sanford, *Manifestly unitary higher Hilbert spaces*, arXiv:2410.05120.
Theorem C is stated on PDF page 4 and proved in Section 5 (especially PDF pages
50--54).

The original conjecture asks for an equivalence

`Mod^dag : UmFC ~= FSSU2C`

between the Morita W*-3-category of unitary multifusion categories and the
W*-3-category of finitely semisimple unitary 2-categories.  The later paper,
which cites arXiv:2404.05193 and has Ferrer as a coauthor, proves the enhanced
unitary equivalence

`Mod^dag : H*mFC ~= 3Hilb`.

Its existence results show that the extra unitary-adjoint, spherical-weight,
and trace data can be chosen; its forgetful and unique-unitarizability results
show that forgetting those choices is fully faithful and recovers the bare
unitary categories in the original conjecture.  Thus Theorem C descends to the
conjectured equivalence.  Because the bare statement is recovered by this
forgetful identification rather than restated verbatim as a theorem, this uses
the literature-implied bucket.  It is not a new solution produced by the run.
