# The Banach-valued ergodic questions were answered affirmatively

Result type: `literature_already_answered`

Status: full affirmative literature answer to both questions.

## Source

- Michael J. Gruber, Daniel H. Lenz, and Ivan Veselić, “Uniform existence of
  the integrated density of states for combinatorial and metric graphs over
  Z^d,” arXiv:0712.1740v1 (2007).
- Questions: unnumbered “Questions” subsection, PDF pages 19--20.
- Local source: `source_paper.pdf`.

## Later answers

1. `support_1003.3620.pdf`: Lenz--Schwarzenberger--Veselić, Assumption 2.5,
   Remark 2.6, and Theorem 3.1. Remark 2.6 explicitly says every polynomial
   volume-growth group fits the framework, and Theorem 3.1 is the requested
   Banach-valued ergodic theorem with an error estimate.

2. `support_1211.2089.pdf`: Pogorzelski, corrected arXiv v2, preliminaries and
   Theorem 5.7. The framework is second-countable locally compact unimodular
   amenable groups with Haar measure; it includes both discrete groups and
   abelian groups. Hence one theorem covers Z^d with counting measure and R^d
   with Lebesgue measure.

## Scope caveat

The second answer is an abstract unification. Each concrete model must still
verify the theorem's almost-additivity, boundary, measurability, compatibility,
and weak-compactness hypotheses.
