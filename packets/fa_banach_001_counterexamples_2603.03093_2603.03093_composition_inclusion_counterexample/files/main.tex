\begin{abstract}
Dellepiane and Seco ask whether every analytic self-map \(\psi\) of the disk
induces a bounded inclusion
\(C_\psi\cH(b)\subseteq\cH(b\circ\psi)\) for every Schur function \(b\).
We give a two-dimensional-data counterexample: \(b(z)=z\) and any disk
automorphism not fixing zero. We also prove that \(C_\psi\) is contractive for
arbitrary \(b\) when \(\psi(0)=0\), and is bounded for arbitrary \(\psi\)
whenever \(b\) is non-extreme. Thus the problem as stated has a negative
answer, while its motivating non-extreme case has a positive answer.
\end{abstract}

  C_\psi\cH(b)\subseteq\cH(b\circ\psi)

\section{Definitions and kernel criterion}

For a Schur function \(b\), the de Branges--Rovnyak space \(\cH(b)\) is the
reproducing-kernel Hilbert space on \(\D\) with kernel
\[
  K^b(z,w)=\frac{1-b(z)\overline{b(w)}}{1-z\overline w}.
\]
For an analytic self-map \(\psi:\D\to\D\), write
\(C_\psi f=f\circ\psi\).

\begin{lemma}[Composition-kernel criterion]
\label{lem:criterion}
The operator \(C_\psi:\cH(b)\to\cH(b\circ\psi)\) has norm at most \(M\) if
and only if the kernel
\[
  M^2K^{b\circ\psi}(z,w)-K^b(\psi(z),\psi(w))
\]
is positive semidefinite.
\end{lemma}

\begin{proof}
On reproducing kernels the formal adjoint must satisfy
\[
  C_\psi^*K^{b\circ\psi}(\,cdot\,,w)
  =K^b(\,\cdot\,,\psi(w)).
\]
The inequality \(\|C_\psi^*g\|^2\le M^2\|g\|^2\) on finite linear
combinations of kernel functions is exactly positivity of the displayed
kernel. Density then gives the equivalence and constructs the bounded
operator in the positive-kernel direction.
\end{proof}

We will repeatedly use the elementary factorization
\begin{equation}
\label{eq:factor}
  K^{b\circ\psi}(z,w)
  =K^b(\psi(z),\psi(w))K^\psi(z,w).
\end{equation}

\section{Proof intuition}

The factor \(K^\psi\) in \eqref{eq:factor} is the whole issue. If
\(\psi(0)=0\), Schwarz's
lemma writes \(\psi(z)=zq(z)\) with \(q\) Schur, and then
\(K^\psi-1=z\overline w K^q\) is positive. The kernel criterion therefore
gives contractivity with no assumption on \(b\).

For a general \(\psi\), a disk automorphism moves \(\psi(0)\) to zero.
Weighted composition by that automorphism is unitary between the appropriate
de Branges--Rovnyak spaces. Removing its elementary weight requires
multiplication by a linear polynomial. That multiplication is bounded in the
non-extreme case because the forward shift is bounded there.

The same automorphism reveals why the unrestricted assertion fails. For
\(b(z)=z\), the source space consists only of constants. After composition
with a non-origin automorphism, the target is a different one-dimensional
space, generated by a nonconstant Cauchy kernel, and therefore does not
contain the constant function one.

\section{The result}

\begin{theorem}
\label{thm:main}
Let \(b\) be a Schur function and \(\psi:\D\to\D\) analytic.
\begin{enumerate}
\item If \(\psi(0)=0\), then
\[
  C_\psi:\cH(b)\longrightarrow\cH(b\circ\psi)
\]
is a contraction.
\item If \(b\) is non-extreme in the closed unit ball of \(H^\infty\), then
the same operator is bounded for every \(\psi\).
\item Without non-extremality the inclusion can fail. More precisely, for
any \(a\in\D\setminus\{0\}\), put
\[
  b(z)=z,
  \qquad
  \psi_a(z)=\frac{a-z}{1-\overline a z}.
\]
Then \(1\in\cH(b)\), but
\[
  C_{\psi_a}1=1\notin\cH(b\circ\psi_a).
\]
Consequently Problem~3.11 has a negative answer as stated.
\end{enumerate}
\end{theorem}

\begin{proof}
Suppose first that \(\psi(0)=0\). By Schwarz's lemma,
\(\psi(z)=zq(z)\) for a Schur function \(q\). Hence
\[
  K^\psi(z,w)-1
  =z\overline w\,
    \frac{1-q(z)\overline{q(w)}}{1-z\overline w}
  =z\overline w K^q(z,w),
\]
which is a positive kernel. Using \eqref{eq:factor},
\[
  K^{b\circ\psi}(z,w)-K^b(\psi(z),\psi(w))
  =K^b(\psi(z),\psi(w))\bigl(K^\psi(z,w)-1\bigr)
\]
is positive by the Schur product theorem for positive-kernel Gram matrices.
Lemma~\ref{lem:criterion} with \(M=1\) proves part~1.

For part~2, set \(\alpha=\psi(0)\) and introduce the involutive disk
automorphism
\[
  \varphi_\alpha(z)=\frac{\alpha-z}{1-\overline\alpha z}.
\]
Put \(u=\varphi_\alpha\circ\psi\), so \(u(0)=0\) and
\(\psi=\varphi_\alpha\circ u\). Also put
\(\widetilde b=b\circ\varphi_\alpha\). The automorphism identity gives
\begin{equation}
  K^{\widetilde b}(z,w)
  =h_\alpha(z)\overline{h_\alpha(w)}
    K^b(\varphi_\alpha(z),\varphi_\alpha(w)),
  \qquad
  h_\alpha(z)=\frac{\sqrt{1-|\alpha|^2}}{1-\overline\alpha z}.
  \tag{2}
\end{equation}
Thus the weighted composition operator
\[
  U_\alpha f=h_\alpha(f\circ\varphi_\alpha)
\]
is unitary from \(\cH(b)\) onto \(\cH(\widetilde b)\); this follows directly
from (2) first on kernel spans and then by density.

Non-extremality is preserved under precomposition by a disk automorphism.
Indeed, the boundary change-of-variables density is bounded above and below,
so integrability of \(\log(1-|b|)\) is preserved. The forward shift \(M_z\)
is therefore bounded on \(\cH(\widetilde b)\), using the standard
non-extreme shift characterization recalled in the source paper
\cite[p.~1]{DS}. Since
\[
  C_{\varphi_\alpha}
  =M_{1/h_\alpha}U_\alpha,
  \qquad
  M_{1/h_\alpha}
  =\frac{I-\overline\alpha M_z}{\sqrt{1-|\alpha|^2}},
\]
composition by \(\varphi_\alpha\) is bounded from \(\cH(b)\) to
\(\cH(\widetilde b)\). Part~1 says that
\(C_u:\cH(\widetilde b)\to\cH(\widetilde b\circ u)\) is contractive.
Finally,
\[
  C_\psi=C_uC_{\varphi_\alpha},
  \qquad
  \widetilde b\circ u=b\circ\psi,
\]
which proves part~2.

For part~3, take \(b(z)=z\). Its kernel is
\[
  K^b(z,w)=\frac{1-z\overline w}{1-z\overline w}=1,
\]
so \(\cH(b)=\operatorname{span}\{1\}\). Since
\(b\circ\psi_a=\psi_a\), another direct automorphism calculation gives
\[
  K^{\psi_a}(z,w)
  =\frac{1-|a|^2}
  {(1-\overline a z)(1-a\overline w)}
  =h_a(z)\overline{h_a(w)}.
\]
Consequently \(\cH(b\circ\psi_a)=\operatorname{span}\{h_a\}\). For
\(a\ne0\), the function \(h_a\) is nonconstant, so the constant function
one is not in this one-dimensional target space. But
\(C_{\psi_a}1=1\), proving failure of the inclusion.
\end{proof}

\section{Verification, limitations, and novelty}

The proof is entirely encoded in reproducing kernels. Its three audit points
are: the direction of Lemma~\ref{lem:criterion}; positivity of
\(z\overline wK^q\); and the removal of the automorphism weight using the
bounded forward shift. The counterexample itself only uses the two displayed
rank-one kernel calculations.

The negative example uses the extreme inner symbol \(b(z)=z\). It does not
contradict the source paper's positive monomial-composition theorem for
non-extreme symbols. Part~2 instead confirms boundedness throughout that
non-extreme setting. The packet does not characterize the remaining extreme
symbols and does not fully answer the broader descriptive Problems~3.10 and
3.12.

Before promotion, the run indexes were searched for arXiv:2603.03093, the
paper title, \emph{de Branges--Rovnyak composition operator}, and the exact
inclusion into the composed-symbol space. Bounded web/arXiv searches used the exact
Problem~3.11 wording, title/authors, and nearby variants. They found the source
paper and work on different mappings involving fixed non-inner rational
spaces, but no answer to this problem. The source still had only version~1.
Novelty confidence is moderate because the proof is short and may be folklore;
no priority claim is made.
