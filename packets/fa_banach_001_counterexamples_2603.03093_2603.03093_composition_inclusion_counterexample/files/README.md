# Composition Inclusion Can Fail for de Branges--Rovnyak Spaces

Result type: `counterexample` with a complementary positive theorem.

Status: candidate counterexample, likely valid pending human review.

Source paper: Eugenio Dellepiane and Daniel Seco, "Orthogonal polynomials in
de Branges--Rovnyak spaces", arXiv:2603.03093v1 (2026), Problem 3.11 on PDF
page 13.

## Claimed Contribution

Problem 3.11 asks whether, for every analytic self-map `psi` of the disk and
every Schur function `b`, one always has

```text
C_psi H(b) subset H(b composed with psi),
```

and, if so, whether the induced composition operator is bounded.

The universal inclusion is false. Choose

```text
b(z) = z,
psi(z) = (a-z)/(1-conjugate(a)z),  0 < |a| < 1.
```

The kernel of `H(b)` is identically one, so `H(b)` consists of constants. The
kernel of `H(psi)` has rank one and is generated by

```text
h_a(z) = sqrt(1-|a|^2)/(1-conjugate(a)z).
```

Since `a` is nonzero, the constant function one is not in `H(psi)`, while
`C_psi 1 = 1`. Thus the requested inclusion fails.

The packet also proves two positive statements:

- if `psi(0)=0`, then `C_psi:H(b)->H(b composed with psi)` is contractive for
  every Schur `b`;
- if `b` is non-extreme, then the same operator is bounded for every analytic
  disk self-map `psi`.

The second statement resolves the non-extreme setting surrounding the source
problem, even though the literal all-`b` formulation is false.

## Proof Mechanism

The bounded-composition kernel criterion reduces contractivity to positivity
of a difference of reproducing kernels. The identity

```text
K_(b composed with psi) = (K_b composed with (psi,psi)) K_psi
```

and Schwarz's lemma make that difference positive when `psi(0)=0`.

For a general `psi`, normalize its value at zero with a disk automorphism.
Weighted composition by an automorphism is unitary between the corresponding
de Branges--Rovnyak spaces. Removing the elementary weight only requires the
forward shift, which is bounded precisely in the non-extreme case.
