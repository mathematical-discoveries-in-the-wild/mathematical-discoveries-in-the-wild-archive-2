# Sharp matrix-Riesz a.e.-existence threshold

Candidate full proof answering the open question in arXiv:math/0409100.

- `solution_packet.pdf`: review artifact
- `main.tex`: packet source
- `source_paper.pdf`: source arXiv paper
- `figures/open_problem_crop.png`: source question on PDF page 9
- `verification_report.md`: adversarial verification record

Claim: for every nonzero admissible order in the meaningful range, the exact
universal a.e.-absolute-convergence threshold is
`p < (n+m-1)/(Re(alpha)+m-1)`, not the smaller bound printed in the source.
