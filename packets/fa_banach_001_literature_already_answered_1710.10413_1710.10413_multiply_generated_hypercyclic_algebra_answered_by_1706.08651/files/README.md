# Multiply generated hypercyclic algebras: affirmative literature answer

Status: `literature_already_answered_affirmative`.

ArXiv:1710.10413 says on PDF page 3 that the existence of multiply generated
algebras of hypercyclic entire functions was unknown. Its own main result
constructs an infinitely generated multiplicative group, not an algebra all of
whose nonzero elements are hypercyclic.

Bès--Papathanasiou, arXiv:1706.08651, independently formulate the equivalent
question of whether `D` has a hypercyclic algebra that is not finitely
generated and explicitly answer it affirmatively. Theorem 1.1 and Corollary
1.3 prove the stronger statement that `HC(D) union {0}` contains a dense free
algebra on countably many generators.

The supporting preprint was first submitted in June 2017, before the October
2017 source preprint, and later revised in 2019. This is an exact independent
literature answer, not a new construction of this run. It answers the source's
existential question; it does not assert the corresponding result for every
subexponential convolution symbol.

The folder contains the original and supporting PDFs and a compact
human-facing `solution_packet.pdf`.
