# Horizontal-symbol necessity and Heisenberg Rockland necessity

**Status:** candidate partial result, likely valid; human review recommended.

This strengthens the scalar first-order packet for arXiv:2007.14532 in two
directions.

1. On every stratified homogeneous group, for operators of every order and
   with arbitrary finite-dimensional domain, the endpoint inequality forces
   injectivity of the commutative horizontal principal symbol at every
   nonzero horizontal covector.
2. On every Heisenberg group, the endpoint inequality forces the full
   Rockland condition and therefore maximal hypoellipticity, again in every
   order and for arbitrary finite-dimensional systems.

The first proof uses the all-but-one-coordinate dilation from the preceding
scalar result. The second tests a hypothetical Schrödinger-representation
kernel with a Schwartz matrix coefficient, cutting it off only in the central
variable. The left side grows like \(R^{2(Q-1)/Q}\), while all error terms on
the right remain bounded.

This does not prove the source paper's compatible-cocanceling condition (ii),
nor maximal hypoellipticity on arbitrary higher-step stratified groups. Hence
it is a strengthened partial result, not a full answer to the source question.

See `main.tex` / `solution_packet.pdf` for the proof and `verification.md` for
the proof audit and search bounds.
