# Nonsingular bivariate quartic flat extension: later literature answer

Status: `literature_already_answered`.

Fialkow--Nie, arXiv:0908.3230, Question 3.5 (PDF page 12), asks whether every positive-definite bivariate quartic moment matrix `M_2(y)` admits a flat cubic extension, and whether it has a positive degree-six extension that subsequently admits a flat extension.

Curto--Yoo, arXiv:1412.7882, Theorem 2.1 (PDF page 3), proves that every positive invertible `M(2)` has an exactly six-atomic representing measure and explicitly states the equivalent conclusion that `M(2)` has a flat extension `M(3)`. This answers both parts affirmatively.

The supporting paper cites Fialkow--Nie and presents its theorem as a constructive sharpening of the earlier existential result, so this is an explicit same-problem literature resolution.
