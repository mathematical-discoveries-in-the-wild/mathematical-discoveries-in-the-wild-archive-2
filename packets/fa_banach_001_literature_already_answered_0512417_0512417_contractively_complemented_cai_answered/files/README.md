# Contractively complemented approximate identities: already answered

Status: `literature_already_answered`

The source is David P. Blecher, Damon M. Hay, and Matthew Neal,
*Hereditary subalgebras of operator algebras*, arXiv:math/0512417. In
Section 6 (arXiv PDF page 16; journal page 351) it asks whether every
approximately unital operator algebra has an approximate identity
`e_t = 1 - x_t` with `x_t` in the unit ball of the unitization.

David P. Blecher and Charles John Read, *Operator algebras with contractive
approximate identities*, arXiv:1011.3797, explicitly say that their Theorem
1.1 was prompted by and solves the question on page 351 of the source. The
theorem gives a contractive approximate identity `(e_t)` satisfying both
`||1-e_t|| <= 1` and the stronger `||1-2e_t|| <= 1`. Taking `x_t=1-e_t`
answers the source question immediately. Their Theorem 1.2 also records the
equivalent peak-projection consequence: every closed projection in `A**` is a
`p`-projection.

This is an explicit literature resolution, not a new result of the run. The
compact status note is `solution_packet.pdf`; the original and decisive later
papers are included locally.
