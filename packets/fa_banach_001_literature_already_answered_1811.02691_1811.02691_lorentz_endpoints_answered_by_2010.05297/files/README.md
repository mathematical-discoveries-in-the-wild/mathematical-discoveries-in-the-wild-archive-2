# Lorentz endpoint questions answered by arXiv:2010.05297

status: `literature_already_answered`

source: Daniel Spector and Jean Van Schaftingen, *Optimal embeddings into
Lorentz spaces for some vector differential operators via Gagliardo's
lemma*, arXiv:1811.02691, Questions 1.1 and 1.2.

supporting answer: Dmitriy Stolyarov, *Hardy--Littlewood--Sobolev inequality
for p=1*, arXiv:2010.05297v3.

## Identification

The source asks for the sharp endpoint estimates

```text
||u||_{L^{n/(n-1),1}} <= C ||A(D)u||_1              (order 1),
||D^{k-1}u||_{L^{n/(n-1),1}} <= C ||A(D)u||_1        (order k >= 2)
```

for every homogeneous constant-coefficient elliptic canceling operator.
Stolyarov's abstract explicitly states the second inequality for every order
`m`; order `m=1` is the first inequality. Example 1.4 and Corollary 1.7 give
the underlying `I_1` estimate, while an elliptic symbol left inverse and
Lorentz-bounded degree-zero multipliers recover `D^{m-1}u`.
