# Hexagonal generalized-\(h_1\) Zak counterexample

This packet refutes Conjecture 4.1 of arXiv:2502.09510.

For
\[
a=\sqrt{2/\sqrt3},\qquad s=1/2,
\]
the generalized first Hermite function has the two additional exact Zak
zeros
\[
(1/6,5/6),\qquad (5/6,1/6),
\]
besides the three parity-forced zeros.  The proof uses the order-three affine
symmetry of the squared Gaussian Zak transform at the hexagonal modulus.

- main.tex: self-contained exact proof.
- solution_packet.pdf: rendered packet.
- code/verify_hexagonal_zeros.py: high-precision regression check.

Novelty is provisional.  Exact-phrase, title, rational-point, theta/Zak, and
run-index searches found no prior answer to the conjecture.
