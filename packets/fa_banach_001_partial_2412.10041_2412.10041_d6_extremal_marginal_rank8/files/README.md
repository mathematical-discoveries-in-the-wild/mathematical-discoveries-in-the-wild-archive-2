# Sharp rank-eight extremal marginal state in dimension six

This candidate partial solution settles the first equal-dimension case
omitted by arXiv:2412.10041. It constructs an extreme state in
C(I_6/6,I_6/6) of rank 8, attaining Parthasarathy's upper bound.

Contents:

- main.tex and solution_packet.pdf: proof packet.
- verify_exact.py: dependency-free exact certificate.
- source_paper.pdf: locally compiled source paper.
- figures/source_open_problem_page.png: source PDF page containing the
  concluding construction problem.
- attempts.md: upgrade-attempt record and boundary of the result.

The general all-dimensions construction problem remains open.
