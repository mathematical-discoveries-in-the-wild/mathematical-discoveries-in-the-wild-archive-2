# Regular-modulo-ideal trace commutator theorem

Status: `candidate partial; likely valid`.

For Loreaux--Weiss Question 1 (arXiv:1712.06702), this packet proves that
`tau(AB)=tau(BA)` whenever the coset of either factor is von Neumann regular
modulo the trace ideal. In particular, the identity holds when either factor
has closed range. It also gives two exact reductions of the remaining problem:
global validity is equivalent to validity for square-zero pairs, and a
positive factor's trace defect is unchanged after localization to any
arbitrarily small spectral tail.

The unrestricted case, in which both factors are nonregular modulo the ideal,
remains open. The proof is algebraic and uses no computational dependency.
