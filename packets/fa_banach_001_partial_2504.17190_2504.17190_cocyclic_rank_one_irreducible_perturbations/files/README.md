# Rank-one irreducible perturbations from cyclic approximate eigenvectors

Status: `candidate_partial_result_likely_valid`

This packet proves a rank-one sufficient condition for Problem A in arXiv:2504.17190v6. If an outer boundary point of the spectrum has approximate eigenvectors that are cyclic for the adjoint, then arbitrarily small rank-one perturbations make the operator irreducible. In particular, this holds when cyclic vectors for the adjoint are dense; the adjoint-symmetric version also holds.

The result does not resolve the paper's equivalent type-II1 factor conjecture. Cyclicity of the von Neumann algebra generated by T uses words in T and T*, and does not imply one-sided cyclicity for T or T*.
