# Polyanalytic Toeplitz norm closure and C*-generation

Source question: Question 2 on PDF page 36 of Robert Fulsche and Raffael Hagger, *Quantum harmonic analysis for polyanalytic Fock spaces*, arXiv:2308.11292.

Result: for every true polyanalytic level \(k\geq2\), the linear norm closure of BUC-symbol Toeplitz operators is a proper subspace of \(\mathcal C_1\), while their generated C*-algebra is all of \(\mathcal C_1\). Every Weyl operator on a Laguerre zero circle has distance exactly one from even the full \(L^\infty\)-symbol Toeplitz range.
