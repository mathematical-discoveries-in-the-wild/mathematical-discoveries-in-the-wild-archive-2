# Real local triple derivations: exact literature answer

Status: `literature_already_answered`.

Problem 2.6 of arXiv:1303.4569 asks whether every bounded local triple
derivation on a real JB*-triple is a triple derivation. ArXiv:1309.0367 quotes
that exact problem as its Problem 1.1 and states that it gives a complete
answer. Example 2.4 is a rank-one Cartan-factor counterexample, so the answer is
negative in general; Theorem 3.4 gives a positive theorem under structural
exclusions.
