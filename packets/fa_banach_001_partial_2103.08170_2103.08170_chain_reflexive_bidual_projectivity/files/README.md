# arXiv:2103.08170 — relative and bidual chain projectivity

Status: partial result (sharp relative 1+-lifting and exact C(K)-quotient
lifting; unrestricted optimal constant remains open).

The source asks for optimal projectivity constants for free Banach lattices
generated by lattices. In particular, it leaves open whether the projective
spaces generated by countable bounded chains are 1+-projective.

This packet proves:

1. For every linearly ordered set L, FBL<L> has 1+-controlled lifting
   through quotients of reflexive Banach lattices.
2. The same holds for weak-star closed ideal quotients of dual Banach
   lattices.
3. For arbitrary Banach-lattice quotients, the same lift always exists in
   the bidual.
4. For countable L, every lifting problem through a quotient
   C(K) to C(F) has an exact norm-preserving solution.

The first three statements glue the known finite-chain 1+-lifts by product
compactness. The fourth recursively applies the relative ordered Tietze
extension theorem.
