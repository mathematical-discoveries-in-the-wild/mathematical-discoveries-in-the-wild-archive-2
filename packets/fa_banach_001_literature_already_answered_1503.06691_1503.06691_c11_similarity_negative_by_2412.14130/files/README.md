# Question 18 answered negatively by arXiv:2412.14130

Status: `literature_already_answered`

## Source question

Laszlo Kerchy, *Quasianalytic polynomially bounded operators*,
arXiv:1503.06691. Question 18 on arXiv PDF page 18 asks whether every
polynomially bounded operator of class `C_11` is similar to a contraction.

## Explicit later answer

Maria F. Gamal', *Examples of cyclic polynomially bounded operators that are
not similar to contractions*, arXiv:2412.14130, explicitly says on PDF page 2
that it gives a negative answer to Question 18 of Kerchy's paper. The
construction yields a polynomially bounded operator quasisimilar to the
bilateral shift (and variants quasisimilar to cyclic reductive unitaries) but
not similar to a contraction.

Such an operator is class `C_11`: if `XT=UX` with injective `X` and
`T^n h -> 0`, then `U^n Xh -> 0`, forcing `Xh=0` and `h=0`; applying the
adjoint relation from the reverse quasiaffinity gives the same conclusion for
`T*`. Thus both stable subspaces vanish.

This is an explicit supporting-author answer, not a new result of the run.
The source's other questions about quasisimilarity to contractions, power
bounded operators quasisimilar to singular unitaries, and full-residual-set
invariant subspaces are outside this identification.
