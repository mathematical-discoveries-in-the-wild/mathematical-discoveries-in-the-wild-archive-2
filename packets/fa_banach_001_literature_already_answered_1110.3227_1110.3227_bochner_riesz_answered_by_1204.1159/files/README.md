# The Grushin Bochner--Riesz conjecture was answered by arXiv:1204.1159

**Status:** `literature_already_answered`

arXiv:1110.3227 conjectures uniform `L^p` boundedness of the Grushin Bochner--Riesz means for `delta > (n+1)/2` when `n >= 2`.

Theorem 2 of Martini--Sikora, arXiv:1204.1159, treats

`L = -Delta_{x'} - |x'|^2 Delta_{x''}`

and proves uniform boundedness for `kappa > (D-1)/2`, where `D=max(d1+d2,2d2)`.  With `d1=n` and `d2=1`, this is the same source operator and gives the stronger threshold `delta > n/2`, for every `p in [1,infinity]`. The supporting theorem is sharp in this dimensional regime.
