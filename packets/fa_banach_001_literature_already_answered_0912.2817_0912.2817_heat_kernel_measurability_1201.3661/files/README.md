# Literature answer: heat-kernel Cesàro limit and measurability

The genuine open question on source PDF page 9 of arXiv:0912.2817 asks
whether existence of the heat-kernel Cesàro limit is necessary for Dixmier
measurability. Carey and Sukochev answer this affirmatively in
arXiv:1201.3661, Theorem 7 (supporting PDF page 5), as part of a four-way
equivalence for positive operators in \(\mathcal M_{1,\infty}\).
