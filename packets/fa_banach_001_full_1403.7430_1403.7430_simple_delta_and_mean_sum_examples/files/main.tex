\section{Questions and notation}

For a class $A$ of functions on $J$, Guenzler defines
\[
 M_hf(t)=\frac1h\int_0^h f(t+s)\,ds,
 \qquad
 MA=\{f\in L^1_{\rm loc}(J):M_hf\in A\ \text{for every }h>0\}.
\]
The class $A$ has property $(\Delta)$ if
\[
 \Delta_af=f(\,\cdot+a)-f\in A\quad(a>0)
 \quad\Longrightarrow\quad f-M_hf\in A\quad(h>0).
\]
Open Question 3 asks for a simple $A\subset MA$ without $(\Delta)$,
preferably linear, invariant, uniformly closed and contained in $BC$.
Open Question 10 asks for $U,V$ such that
\[
 MU+MV\subsetneq M(U+V).
\]
Both questions occur on PDF page 30 of the source \cite{Guenzler}.

\begin{center}
\includegraphics[width=0.94\textwidth]{figures/questions_q3_q10.png}
\end{center}

As in the source, mean classes cannot distinguish functions equal almost
everywhere.  Write $\Nul$ for the class of locally integrable functions that
vanish almost everywhere.

\section{Proof intuition}

For Question 3, the simplest mean-stable object is an order cone: averaging
preserves nonnegativity.  A strictly increasing bounded function has every
positive difference in that cone, whereas subtracting a forward average
produces a strictly negative function.  This answers the existence request
with an invariant uniformly closed subset of $BC$; only the optional
linearity refinement remains.

For Question 10, translations rotate the plane spanned by $\cos t$ and
$\sin t$.  Consequently averaging preserves that plane, although it does
not preserve either coordinate axis.  Requiring \emph{every} forward mean
to lie on one axis is so rigid that the original function must vanish almost
everywhere.  Thus the two individual mean classes are null while the mean
class of their sum contains the whole trigonometric plane.

\section{The two constructions}

\begin{theorem}\label{thm:main}
Let $J=\R$ and use real scalar-valued functions.
\begin{enumerate}
\item Define
\[
 A=\{g\in BC(\R):g(t)\geq0\text{ for all }t\}.
\]
Then $A$ is invariant, uniformly closed, contained in $BC(\R)$, satisfies
$A\subset MA$, and does not satisfy $(\Delta)$.
\item Let
\[
 U=\operatorname{span}\{\cos t\},\qquad
 V=\operatorname{span}\{\sin t\}.
\]
Then
\[
 MU=MV=\Nul,
 \qquad
 U+V\subset M(U+V),
\]
and hence $MU+MV\subsetneq M(U+V)$.
\end{enumerate}
\end{theorem}

\begin{proof}
For the first assertion, translation and uniform limits preserve
nonnegativity.  If $g\in A$, then $M_hg$ is bounded, continuous and
nonnegative for every $h>0$, so $g\in MA$.

Now take $f(t)=\tanh t$.  Since $f$ is strictly increasing,
\[
 \Delta_af(t)=\tanh(t+a)-\tanh t>0
 \qquad(t\in\R, a>0),
\]
so every positive difference belongs to $A$.  On the other hand,
\[
 M_hf(t)>f(t)\qquad(t\in\R, h>0),
\]
because the integrand $f(t+s)$ is strictly larger than $f(t)$ for
$0<s\leq h$.  Therefore $f-M_hf$ is strictly negative and is not in $A$.
Thus $(\Delta)$ fails.

For the second assertion, direct integration gives
\begin{align}
 M_h(\cos t)
 &=\frac{\sin h}{h}\cos t+\frac{\cos h-1}{h}\sin t,\label{eq:cosmean}\\
 M_h(\sin t)
 &=\frac{1-\cos h}{h}\cos t+\frac{\sin h}{h}\sin t.\label{eq:sinmean}
\end{align}
Thus every mean of every element of $U+V$ again belongs to $U+V$, proving
$U+V\subset M(U+V)$.

It remains to compute the individual mean classes.  Suppose $g\in MU$.
For every $h>0$ there is a scalar $c_h$ such that
\[
 M_hg(t)=c_h\cos t.
\]
Choose a Lebesgue point $t_0$ of $g$ with $\cos t_0\ne0$.  As $h\downarrow0$,
the one-sided differentiation theorem gives
\[
 c_h=\frac{M_hg(t_0)}{\cos t_0}\longrightarrow
 c:=\frac{g(t_0)}{\cos t_0}.
\]
At every Lebesgue point $t$ of $g$, it follows that
$g(t)=\lim_{h\downarrow0}c_h\cos t=c\cos t$.  Hence $g=c\cos t$ almost
everywhere.  Formula \eqref{eq:cosmean} with $h=\pi$ can lie in $U$ only
when its sine coefficient $-2c/\pi$ vanishes.  Thus $c=0$, proving
$MU=\Nul$.

The same argument for $g\in MV$ first gives $g=c\sin t$ almost everywhere.
Formula \eqref{eq:sinmean} at $h=\pi$ has cosine coefficient $2c/\pi$, so
$c=0$ and $MV=\Nul$.  Consequently $MU+MV=\Nul$, whereas
$\cos t\in U+V\subset M(U+V)$ and $\cos t\notin\Nul$.  The inclusion is
strict.
\end{proof}

\section*{Checks, novelty, and scope}

The proof uses only elementary integration and one-sided Lebesgue
differentiation.  The null class is retained explicitly because the source's
definition of $MA$ uses locally integrable representatives and likewise
records null functions in several examples.  If spaces are taken modulo
almost-everywhere equality, $\Nul$ is simply the zero element.

The Question 3 example satisfies every requested adjective except linearity:
it is an invariant uniformly closed cone in $BC(\R)$.  Hence it fully answers
the literal request for a simple example but does not improve the source's
more elaborate linear examples to an equally elementary linear one.  The
Question 10 construction answers the displayed strict-inclusion problem with
two one-dimensional spaces; replacing $t$ by any nonzero frequency
$\lambda t$ gives the same family of examples.

A bounded novelty search checked the run indexes, the exact source title and
arXiv identifier, the exact Question 10 inclusion, and combinations of
``mean class'', $\operatorname{span}\{\cos,\sin\}$ and the source author's
name.  No later explicit answer or duplicate was located.  Citation-database
coverage of this arXiv-only note was weak, so novelty remains provisional.
