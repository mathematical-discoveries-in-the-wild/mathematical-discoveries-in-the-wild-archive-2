# `V_0` need not be closed

This packet gives a full counterexample to the open question after Example
6.18 of arXiv:1501.06696.  It constructs a real Hilbert ordered gradient
space whose source-defined subspace `V_0=V_+-V_+` is proper dense and
nonclosed.  Both `V_+` and `V_0` are lattices.
