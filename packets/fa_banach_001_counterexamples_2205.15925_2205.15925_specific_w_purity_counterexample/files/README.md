# Counterexample to purity of the specific W=JV

Candidate full counterexample to the open problem following Theorem C of
arXiv:2205.15925.

For the multiplicity-free diagonal operator

    A e_k = (1/k) e_k,  k in Z without 0,

the paper's own spectral restriction produces a pure isometry `V`, but the
derived isometry `W=JV` is the identity on the infinite-dimensional odd
subspace `h_{-n}=-h_n`. Thus `W` is not pure.
