# Free locally convex spaces with a G-base: broad characterization answered

Status: `literature_already_answered (broad Problem 1.1 only)`

Gabriyelyan and Ka̧kol ask in Problem 1.1 of arXiv:1604.02555 (PDF page
2) for which spaces `X` the free locally convex space `L(X)` has a
G-base. Banakh and Leiderman explicitly state that Theorem 8.1 of
arXiv:1606.01967 (PDF page 19) completely resolves the underlying Question
4.15. For every Tychonoff space `X`, it gives the equivalence

`L(X) has a local G-base`

if and only if

`the finest uniformity U(X) has a G-base and C(X) is omega^omega-dominated`.

Here “G-base” for a topological vector space is a local G-base at zero, so
this is the sought full broad characterization.

Scope limitation: this packet does **not** claim that the Ascoli hypothesis
can be removed from Theorem 1.2 of arXiv:1604.02555, nor does it settle the
source paper’s broader compact-resolution Problem 1.3. The later theorem’s
`C_k(C_k(X))` equivalence still assumes that `X` is Ascoli.
