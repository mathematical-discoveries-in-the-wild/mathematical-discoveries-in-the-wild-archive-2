# Finite-Blaschke and compatible-zero extensions

This packet gives a substantial partial answer to the two open questions on
source PDF pages 8--9 of arXiv:1812.08121.

- `solution_packet.pdf`: expert-facing statement and proof.
- `main.tex`: self-contained LaTeX source.
- `source_paper.pdf`: official arXiv source PDF.
- `figures/weighted_question_crop.png`: weighted-Bergman question.
- `figures/infinite_zero_question_crop.png`: infinite-zero question.
- `supporting_papers/2405.05412.pdf`: decisive modern context showing why an
  arbitrary-measure Berezin shortcut is invalid.
- `verification_report.md`: mathematical and visual checks.
- `novelty.md`: bounded novelty search and scope.

Result scope: both questions are fully positive for finite Blaschke
composition symbols.  For arbitrary symbols, the infinite-zero theorem also
holds whenever the zero multiplicities admit an analytic `p/2` power, in
particular for every even integer `p`.  No unrestricted answer is claimed.
