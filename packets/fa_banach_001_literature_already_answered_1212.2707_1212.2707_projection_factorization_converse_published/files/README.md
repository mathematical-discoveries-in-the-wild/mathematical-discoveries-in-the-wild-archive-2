# Projection-factorization converse: answered in the published version

Status: **literature already answered (affirmative, after the necessary
conjugation correction)**. No new theorem is claimed.

The arXiv v2 source of Ji--Sarkar, arXiv:1212.2707, ends by asking whether
similarity to the finite free module implies a bounded factorization of the
coefficient-bundle projection.  The 2019 European Journal of Mathematics
version answers the question in Theorem 7.4: the implication is upgraded to an
equivalence, with the consistent range condition
`ran F(w) = V(conjugate(w))`.
