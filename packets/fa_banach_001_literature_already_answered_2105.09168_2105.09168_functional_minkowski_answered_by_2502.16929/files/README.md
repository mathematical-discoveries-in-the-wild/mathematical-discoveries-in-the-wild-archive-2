# Literature resolution: arXiv:2105.09168

This packet identifies Falah--Rotem, arXiv:2502.16929, Theorem 1.5, as a
complete answer to Problem 6.7 of arXiv:2105.09168.

The later theorem characterizes exactly when finite measures `mu` on `R^n`
and `nu` on `S^{n-1}` arise as the two surface-area measures of an integrable
log-concave function. It also proves uniqueness up to translations.
