# Heat-semigroup endpoint counterexample

This packet answers negatively the all-`sigma` tent/Sobolev equivalence asked
in arXiv `1810.01183`.

Already for the identity-coefficient heat equation, `p=2`, and `sigma=1`, the
first-order tent square function diverges at time zero for every nonzero
Schwartz input, whereas the proposed Sobolev norm is finite. The same holds
for all `sigma>=1`.

The packet also proves the exact positive formula for `0<=sigma<1`, showing
that one is the sharp threshold for the questioned first-order square
function.

Status: candidate full counterexample, likely valid subject to human review.

Main artifact: `solution_packet.pdf`.
