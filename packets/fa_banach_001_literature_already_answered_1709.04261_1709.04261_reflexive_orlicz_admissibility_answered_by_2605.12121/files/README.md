# Question 27 of arXiv:1709.04261 answered positively by arXiv:2605.12121

Status: `literature_already_answered`

Jacob--Schwenninger--Zwart ask in Section 6, arXiv PDF page 16, whether an
`L^infinity`-admissible scalar control operator for an analytic semigroup on a
Hilbert space must be admissible for some Orlicz space when the generator has
no bounded `H^infinity` calculus (Question 27).

Preußler--Schwenninger, arXiv:2605.12121, answer yes in greater generality.
Corollary 3.8 on PDF page 14 states that on every reflexive Banach state space,
every `C`-admissible control operator is `E_F`-admissible for some Young
function `F`. Since `L^infinity`-admissibility implies `C`-admissibility and a
Hilbert space is reflexive, this gives the desired conclusion without
analyticity, exponential stability, scalar input, or a functional-calculus
assumption. Remark 3.10 explicitly identifies and resolves source Question 27.
