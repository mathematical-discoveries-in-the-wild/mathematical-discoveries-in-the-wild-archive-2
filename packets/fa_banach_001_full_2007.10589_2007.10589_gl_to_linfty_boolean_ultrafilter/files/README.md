# Generalized lushness passes to Bochner L-infinity

This packet fully answers one explicit unknown implication on page 3 of
arXiv:2007.10589:

`X generalized-lush  =>  L_infinity(mu,X) generalized-lush`.

The theorem holds for every real Banach space `X` and every measure space;
sigma-finiteness is unnecessary.  The proof builds a slice functional as a
Boolean-ultrafilter limit of a countably valued field of GL witnesses.  For
each test function, a finite binning of one pointwise distance lets the
ultrafilter choose a region on which the two essential-sup distances retain
the required sum bound.
