# Disconnected spectra for constrained Toeplitz operators

Status: candidate_counterexample_and_full_essential_spectrum_theorem_likely_valid

This packet settles two parts of Question 6.1 in arXiv:2110.06379.

- Ordinary spectral connectedness is false, even for one bounded analytic
  rational symbol. Explicit disconnected spectra are given in both the Neil
  and two-point settings.
- Essential spectral connectedness is true in complete generality. The
  compression to any finite-codimensional Hardy subspace has the same
  Fredholm essential spectrum as the classical Toeplitz operator, hence it
  is connected.

The common symbol is

    phi(z) = z / (1-z/2)^2.

For the Neil space generated by (1-z)/sqrt(2) and z^2 H^2, the compression
has spectrum

    {-1/2} union phi(closed unit disk),

and -1/2 is isolated because its only preimage is z=-2.

For the two-point algebra with a=-1/10, b=1/10, and t=11/9, the corresponding
scalar block is -79402/159201. Both of its phi-preimages have modulus greater
than one, so it is again an isolated spectral point.

The relative point-spectrum questions in Questions 6.1 and 6.2 are not
claimed to be settled.
