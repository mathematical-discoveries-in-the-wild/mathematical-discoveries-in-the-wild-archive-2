\section{Source question and operator}

For a homogeneous constant-coefficient operator $\mathcal D$, write
$\mathcal D[\zeta]$ for its complexified symbol.  It is
\emph{boundary elliptic in direction} $\nu\in\mathbb S^{n-1}$ when
\[
 \ker_{\C}\mathcal D[\xi+i\nu]=\{0\}
 \qquad\hbox{for every }\xi\in\R^n.
\]
The source proposes future work on the set of admissible outward normals
for general-domain traces, and closes with the following family \cite{GRV}.

For $n,N\ge3$, the first-order operator $\A$ on
$u=(u_1,\ldots,u_N):\R^n\to\R^N$ contains the equations
\begin{align*}
 \partial_1u_1-\partial_2u_2,&\qquad
 \partial_1u_2+\partial_2u_1,\\
 \partial_j u_1,&\qquad \partial_j u_2
       &&(3\le j\le n),\\
 \nabla u_q&&&(3\le q\le N).
\end{align*}
The source proves that $\A$ is elliptic and canceling but not
$\C$-elliptic, and notes boundary ellipticity for every direction in
$\operatorname{span}\{e_3,\ldots,e_n\}$.  It also composes $\A$ on the
left with arbitrary complex-elliptic operators $\B$.

\section{Idea of the proof}

All possible failure is concentrated in the first two input coordinates.
The gradient rows kill $v_3,\ldots,v_N$.  If a complex covector has any
nonzero coordinate beyond its first two, the remaining rows also kill
$v_1,v_2$.  On the first coordinate plane, only the Cauchy--Riemann block
remains, and its determinant factors into two complex linear forms.  Its
two characteristic lines can then be projected exactly onto their
imaginary parts.  This turns the algebraic characteristic variety into
the desired geometric set of bad normals.

\section{The characteristic cone}

\begin{theorem}[Exact characteristic variety]\label{thm:cone}
For the operator $\A$ above,
\[
 \{\zeta\in\C^n\setminus\{0\}:\ker_{\C}\A[\zeta]\ne\{0\}\}
 =\C^*(1,i,0,\ldots,0)\ \cup\
   \C^*(1,-i,0,\ldots,0).
\]
Consequently,
\begin{equation}\label{eq:normal}
 \A\text{ is boundary elliptic in direction }\nu
 \quad\Longleftrightarrow\quad
 \nu\notin\operatorname{span}\{e_1,e_2\}.
\end{equation}
\end{theorem}

\begin{proof}
Fix $\zeta\ne0$ and suppose $\A[\zeta]v=0$, with
$v=(v_1,\ldots,v_N)\in\C^N$.  For each $q\ge3$, the gradient block gives
$\zeta_jv_q=0$ for every $j$.  Since $\zeta\ne0$, this forces
$v_q=0$.  The remaining symbol equations are
\[
 \begin{pmatrix}\zeta_1&-\zeta_2\\
                 \zeta_2& \zeta_1\end{pmatrix}
 \binom{v_1}{v_2}=0,
 \qquad
 \zeta_jv_1=\zeta_jv_2=0\quad(3\le j\le n).
\]
If some $\zeta_j\ne0$ for $j\ge3$, then $v_1=v_2=0$, so the kernel is
trivial.  Otherwise $\zeta$ lies in the first coordinate plane, where a
nonzero kernel exists exactly when
\[
 \zeta_1^2+\zeta_2^2
 = (\zeta_1+i\zeta_2)(\zeta_1-i\zeta_2)=0.
\]
This proves the formula for the characteristic variety (and explicit
nonzero kernel vectors verify both lines).

If $\nu$ has a nonzero coordinate $\nu_j$, $j\ge3$, every
$\xi+i\nu$ lies outside these two lines, so $\A[\xi+i\nu]$ is injective
for every real $\xi$.  Conversely, take a unit vector
$\nu=(a,b,0,\ldots,0)$ and put
$\xi=(b,-a,0,\ldots,0)$.  Then
\[
 \xi+i\nu=(b+ia,-a+ib,0,\ldots,0)
 =(b+ia)(1,i,0,\ldots,0),
\]
which is a nonzero characteristic covector.  Thus boundary ellipticity
fails for every direction in the first coordinate plane, proving
\eqref{eq:normal}.
\end{proof}

The exact set is open and dense in the sphere.  In particular, it includes
every mixed direction having both a component in
$\operatorname{span}\{e_1,e_2\}$ and a nonzero component orthogonal to
that plane; these directions are not covered by the sufficient subspace
recorded in the source.

\section{Every order and the sharp estimates}

\begin{lemma}[Complex-elliptic left factors preserve the cone]
Let $\B$ be any homogeneous complex-elliptic operator whose domain is the
target space of $\A$.  Then for every $\zeta\in\C^n\setminus\{0\}$,
\[
 \ker_{\C}(\B\A)[\zeta]=\ker_{\C}\A[\zeta].
\]
\end{lemma}

\begin{proof}
Constant coefficients give $(\B\A)[\zeta]=\B[\zeta]\A[\zeta]$ (up to
the harmless common symbol convention).  Complex ellipticity says that
$\B[\zeta]$ is injective.  Hence
$\B[\zeta]\A[\zeta]v=0$ if and only if $\A[\zeta]v=0$.
\end{proof}

\begin{corollary}[Exact admissible halfspaces]\label{cor:estimates}
Let $\mathcal D=\A$, or let $\mathcal D=\B\A$ be any order-$k$
operator in the source's family.  For a unit normal $\nu$, each of the
following holds if and only if
$\nu\notin\operatorname{span}\{e_1,e_2\}$:
\begin{enumerate}
 \item the sharp trace estimate into the source's space
       $\mathrm T_k(H_\nu,V)$;
 \item the limiting halfspace Sobolev estimate
 \[
  \|D^{k-1}u\|_{L^{n/(n-1)}(H_\nu^+)}
  \le C\|\mathcal D u\|_{L^1(H_\nu^+)}
  \quad(u\in C_c^\infty(\R^n,V)).
 \]
\end{enumerate}
\end{corollary}

\begin{proof}
The lemma and Theorem \ref{thm:cone} give the exact boundary-elliptic
directions.  The source's Theorems 1.2--1.3 identify boundary ellipticity
with the appropriate first- or higher-order trace estimate.  The operator
$\A$ is real elliptic by Example 6.5, and $\B[\xi]$ is injective for every
real $\xi\ne0$, so $\B\A$ is real elliptic as well.  Theorem 1.1 of the
source therefore identifies the same normal set with the limiting
Sobolev estimate.
\end{proof}

\section{Scope and novelty}

This is a full characterization for the explicit arbitrary-order family,
not for general operators or curved domains.  In particular, it does not
prove sufficiency of a pointwise normal condition after flattening a
general boundary; that is part of the broader future-work program.

The current v1 PDF and source TeX state only the smaller sufficient set.
A bounded search of the run's full-source indexes and exact web searches
using the authors, the example, and the admissible-normal terminology found
no later characterization or erratum.  Novelty is provisional pending
specialist review.
