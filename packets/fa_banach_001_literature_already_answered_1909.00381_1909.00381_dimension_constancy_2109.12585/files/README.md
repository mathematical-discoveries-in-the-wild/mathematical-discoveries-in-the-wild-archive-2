# arXiv:1909.00381 — dimension constancy answered later

Status: `literature_already_answered (dimension constancy and one-stratum
perimeter representation)`

The source asks whether reduced boundaries of finite-perimeter sets have
constant tangent dimension in an `RCD(K,N)` space and whether its stratified
perimeter formula can be sharpened.

The same authors answer this in arXiv:2109.12585.  Theorem 1.3 / Corollary 3.2
shows that, when the ambient essential dimension is `n`, every lower stratum
`F_k E` with `k != n` is perimeter-null.  Hence

```
|D chi_E| = (omega_{n-1}/omega_n) H^h | F_n E.
```

The later Theorem 3.1 proves the stronger BV-measure concentration result,
and Theorem 3.4 gives constant dimension of the tangent module over the
boundary.
