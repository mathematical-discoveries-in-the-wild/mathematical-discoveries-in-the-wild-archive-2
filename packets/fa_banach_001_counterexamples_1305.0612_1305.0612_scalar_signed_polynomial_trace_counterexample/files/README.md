# Scalar counterexample to the signed polynomial trace conjecture

This packet disproves the polynomial half of Conjecture 7.3 in arXiv
`1305.0612` (restated as Conjecture 13.4 in the authors' later Matrix
Efron--Stein paper).

The counterexample is already one-dimensional and uses the application-relevant
odd exponent `q=3`. Take

`A=1/100`, `B=-1`, `C=1`, and `s=1`.

All three scalar matrices are invertible. The conjectured left side is
`1.000001`, while the right side is `0.000303015`. Thus the failure is strict
and robust under small perturbations. A second argument gives scalar
counterexamples for every integer `q>=2`.

This fully disproves the signed polynomial conjecture as stated. It does not
disprove the separate signed exponential inequality.
