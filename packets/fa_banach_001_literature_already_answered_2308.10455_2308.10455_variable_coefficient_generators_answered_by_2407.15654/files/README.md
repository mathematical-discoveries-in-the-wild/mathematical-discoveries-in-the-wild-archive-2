# Variable-coefficient positivity generators: answered by later literature

Open Problem 6.1 of arXiv:2308.10455 asks for all degree-preserving
variable-coefficient differential operators `A` for which `exp(tA)`
preserves polynomials nonnegative on `R^n` for every `t >= 0`.

The same lead author's later paper with Konrad Schm\u00fcdgen,
arXiv:2407.15654, answers this exactly in Theorem 5.12.  After the harmless
normalization `a_alpha = alpha! q_alpha`, it gives an if-and-only-if
pointwise L\u00e9vy--Khintchine characterization.
