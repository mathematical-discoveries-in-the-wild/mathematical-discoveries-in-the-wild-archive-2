# Center index four gives the minimal Fourier-algebra amenability constant

Candidate full solution to Question 6.2 of arXiv:2012.14413.

The packet proves that for every locally compact nonabelian group `G`,

`AM(A(G)) = 3/2` if and only if `[G : Z(G)] = 4`.

The new direction has no discreteness, countability, compactness, or
second-countability assumption.  It uses a central spectral splitting of a
contractive operator approximate diagonal.  The two surviving blocks have
asymptotic operator-projective norms `1/2` and tensor-inverse costs `1` and
`2`, giving the sharp upper bound `3/2`.
