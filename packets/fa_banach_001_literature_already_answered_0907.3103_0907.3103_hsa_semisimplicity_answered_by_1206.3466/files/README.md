# Semisimplicity passes to HSA's: answered by arXiv:1206.3466

Status: `literature_already_answered`.

Remark 2.6 on PDF page 4 of arXiv:0907.3103 says that the authors do not
know whether semisimplicity passes from an operator algebra to its
approximately unital hereditary subalgebras (HSA's).

Theorem 4.2 on PDF page 7 of arXiv:1206.3466 proves the stronger radical
identity

```text
J(D) = D intersect J(A)
```

for every HSA `D` in an operator algebra `A`. Hence `J(A)=0` implies
`J(D)=0`. The supporting theorem explicitly says that it answers a question
posed in the source paper, cited there as reference [3].
