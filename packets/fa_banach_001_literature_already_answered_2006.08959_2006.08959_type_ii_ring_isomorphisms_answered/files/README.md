# Type-II locally measurable ring isomorphisms: literature answer

Status: **literature already answered**. No new theorem is claimed.

The packet clears Conjectures 5.1 and 5.2 of arXiv:2006.08959.

- arXiv:2010.01627, Theorem 1.4, proves the stronger inner-twisted
  real-star-isomorphism description for type II_1 measurable-operator
  algebras; Corollary 1.5 gives the projection-lattice classification.
- arXiv:2206.00875, Theorem 1.2, proves the remaining type II-infinity case.
  Theorems 1.3 and 1.4 state the combined ring and projection-lattice
  classifications.
