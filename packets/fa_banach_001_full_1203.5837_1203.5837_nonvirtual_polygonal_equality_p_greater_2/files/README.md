# arXiv:1203.5837 — full negative answer for p>2

Status: `candidate full counterexample, proved`

The source asks whether virtual degeneracy, known to be sufficient for a
nontrivial `p`-polygonal equality, is also necessary when `p>2`.  It is not.

For every `p>2`, the packet constructs a completely refined weighted
three-vertex simplex in `ell_p^2`.  Its two scalar-coordinate gaps have
opposite signs; an explicit scale makes them cancel exactly.  The first
coordinate simplex is nondegenerate, so the equality is not virtually
degenerate.
