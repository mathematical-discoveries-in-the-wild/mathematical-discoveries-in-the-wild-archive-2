# Bernoulli singularity conjecture answered by arXiv:1812.09016

Status: `literature_already_answered`

## Source question

Mark Rudelson and Roman Vershynin, *The Littlewood--Offord Problem and
invertibility of random matrices*, arXiv:math/0703503.

Section 1.1, arXiv PDF page 3, calls the singularity probability of an
$n\times n$ random sign matrix a longstanding open problem and records the
conjectured optimal exponential rate
\[
  \mathbb P\{M_n\text{ is singular}\}=\bigl(\tfrac12+o(1)\bigr)^n.
\]

## Explicit later answer

Konstantin Tikhomirov, *Singularity of random Bernoulli matrices*,
arXiv:1812.09016, published in *Annals of Mathematics* 191 (2020), 593--634,
proves exactly
\[
  \mathbb P\{M_n\text{ is singular}\}=\bigl(\tfrac12+o_n(1)\bigr)^n.
\]
The statement appears in the abstract and equation (1) on arXiv PDF page 1;
the paper says explicitly that it confirms the conjecture.

This is a literature identification, not a new mathematical result.
