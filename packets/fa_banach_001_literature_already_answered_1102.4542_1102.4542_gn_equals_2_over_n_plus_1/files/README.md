# The optimal exponent is `g_n = 2/(n+1)`

Status: `literature_already_answered`.

Source question: A. T. Bernardino, *On cotype and a Grothendieck-type theorem
for absolutely summing multilinear operators*, arXiv:1102.4542, Problem 1.3
on PDF page 2 and the conjecture at the end of Section 3.

Supporting answer: D. Pellegrino and J. B. Seoane-Sepúlveda,
*Grothendieck's theorem for absolutely summing multilinear operators is
optimal*, arXiv:1307.4809, abstract and Theorem 1.1 on PDF page 1.

The later paper explicitly says it solves Bernardino's 2011 conjecture and
proves

```text
g_n = 2/(n+1).
```

It also proves that for every smaller exponent the continuous nonsumming
multilinear maps contain a continuum-dimensional linear space, except for the
zero vector.
