# arXiv:1610.01659 — same-generator power modules

Status: `candidate_full_solution` (affirmative answer to Question 2.10),
pending expert review.

Source: Maria Infusino and Salma Kuhlmann, *Infinite dimensional moment
problem: open questions and applications*, arXiv:1610.01659 / Contemporary
Mathematics 697 (2017), Question 2.10 on printed page 7.

## Result

Let `(A,tau)` be an lmc unital commutative real algebra, let `G` be any fixed
generator family, and let `M_(2d)(G)` be the `2d`-power module generated by
`G`. For every tau-continuous linear functional `L`, the following are
equivalent:

1. `L` is `M_2(G)`-positive;
2. `L` is `M_(2d)(G)`-positive for every `d`;
3. `L` is `M_(2d)(G)`-positive for some `d`.

This fully and affirmatively answers Question 2.10. The argument allows an
arbitrary, possibly uncountable, generator family and also covers the empty
family.

## Main mechanism

The character positivity set of `M_(2d)(G)` is

`K_G={alpha: alpha(g)>=0 for every g in G}`,

independently of `d`. If condition 3 holds, source Proposition 2.5 gives a
nonnegative representing measure for `L` supported on `K_G`. Every element of
`M_2(G)` is nonnegative on that support, so integration proves condition 1.
The other implications follow from `M_(2d)(G) subset M_2(G)`.
