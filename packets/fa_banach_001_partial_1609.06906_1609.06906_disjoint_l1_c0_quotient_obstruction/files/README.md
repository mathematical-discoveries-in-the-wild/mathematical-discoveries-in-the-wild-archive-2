# Disjoint ell1 / positive c0-quotient obstruction

Status: candidate partial result; the full Chen--Li question is **not**
claimed solved.

The packet proves that failure of L-weak compactness for an almost
Dunford--Pettis set forces a disjoint ell1 sequence in the dual.  For a
KB-space this yields a positive disjoint quotient onto c0 which is not norm
compact on the solid hull; that solid hull also contains a seminormalized
disjoint weakly-null Dunford--Pettis sequence.

Contents:

- `solution_packet.pdf`: expert-facing result and proof.
- `source_paper.pdf`: arXiv:1609.06906.
- `source_excerpt.pdf` and `question_crop.png`: source page/crop containing
  Q1, its equivalent Q1-prime, and the related Wnuk question.
- `refs/el_fahri_machrafi_moussa_pdprcp_2015.pdf`: supporting paper giving
  the PDPrcP reformulation and the disjoint-sequence lemma used in the proof.
- `verification.md`: compilation and proof-audit record.
