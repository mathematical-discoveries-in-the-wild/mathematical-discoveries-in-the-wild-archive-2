# Literature-status packet: arXiv:1011.1524, Question 15.5

Status: `literature_already_answered (metrizable case)`.

The source asks whether there is a (separable metric) group containing an
`f_omega`-productive sequence but no unconditionally
`f_omega`-Cauchy productive sequence. Domínguez and Tarieladze explicitly cite
this as Question 15.5 in Remark 2.16 of *Metrizable TAP, HTAP and STAP groups*
and answer it negatively for every metrizable group via Corollary 2.15(b).

The nonmetrizable version is not answered by that paper; Remark 2.16 says it
remains unknown. A bounded later-literature search found no subsequent
primary-source resolution of that broader version.

Evidence:

- Source: arXiv:1011.1524, Question 15.5, PDF page 31.
- Supporting paper: X. Domínguez and V. Tarieladze, *Topology and its
  Applications* 159 (2012), 2338–2352,
  doi:10.1016/j.topol.2011.09.046.
- Answer: Corollary 2.15(b) and Remark 2.16, supporting PDF page 11.
