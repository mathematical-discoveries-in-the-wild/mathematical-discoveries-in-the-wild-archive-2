# Convolution is not jointly weakly continuous on a nontrivial Våge space

This packet gives a candidate full negative answer to the question immediately
after Theorem 3.6 on page 13 of arXiv:1106.5746.

## Result

Let `F_a'` be a Våge space built on the free commutative monoid generated by
`A`.  Convolution is jointly continuous for the weak topology
`sigma(F_a',F_a)` if and only if `A` is empty.  Thus it fails on every
nontrivial Våge space covered by the source.

## Proof mechanism

Every jointly weakly continuous scalar bilinear form has finite algebraic
rank.  Pairing convolution with a carefully chosen rapidly decreasing test
vector in `F_a` instead produces an infinite-rank Hankel form.  In the concrete
one-generator example `a_n=2^n`, the test vector `phi_n=2^{-n^2}` makes every
finite Hankel minor a nonzero diagonal multiple of a Vandermonde determinant.
