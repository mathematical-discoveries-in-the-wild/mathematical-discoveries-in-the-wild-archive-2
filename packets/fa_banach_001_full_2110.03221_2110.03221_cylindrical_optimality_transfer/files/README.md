# Optimality of the 4D cylindrical approximation exponent

Candidate full answer to the optimality conjecture following Theorem 3.2 of
arXiv:2110.03221.

## Result

In the standard polynomial-depth approximation model used by the source's
cited optimality literature, no representation system can uniformly attain a
squared `L2` N-term error exponent larger than one on the source class `E(A)`.
The proof tensors the ordinary 3D cartoon class with a fixed smooth time
profile, then projects any hypothetical 4D scheme back to 3D. Combined with
the source's `N^{-1}(log N)^2` upper bound, the power exponent one is optimal
up to logarithmic factors.
