# Continuity necessity in two broad t-conorm regimes

Status: candidate substantial partial result; likely valid.

This packet answers Remark 4.7 of arXiv:2411.11876 in two regimes:

- for the maximum t-conorm, closure of continuous distance distribution
  functions under `M* tensor T` holds exactly when the left-continuous
  t-norm `T` is continuous;
- for addition, and hence for every t-conorm with an additive generator,
  closure fails whenever `T` has a nilpotent-minimum ordinal-sum component.

The first statement is an exact subcase. The second gives an explicit jump
witness for a large class of discontinuous t-norms. The packet does not
settle arbitrary right-continuous t-conorms satisfying `(LS)` or arbitrary
discontinuous left-continuous t-norms.
