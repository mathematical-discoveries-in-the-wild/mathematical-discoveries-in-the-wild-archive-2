# arXiv:2407.18455 — Fredholm-index counterexample to Question 6.4

This packet gives a candidate full negative answer to the source's final
question about essential unitary equivalence of two quotient-module
`C*`-extensions.

Specialize to `p=z-w`, `B1=B2=id`, and an explicit infinite Blaschke product
whose zeros cluster at every boundary point and avoid zero. The extension for
`[z-w]^perp` has the Bergman shift as coordinate lift, of index `-1`. The
extension for `[z-w,B(z)B(w)]^perp` has an invertible coordinate lift, of
index `0`, by an explicit Bezout identity modulo `B^2`. Therefore the
extensions are not essentially unitarily equivalent.
