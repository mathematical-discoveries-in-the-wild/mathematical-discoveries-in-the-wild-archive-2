# Literature status: the 1-Schur versus 1-strong Schur questions

- Source: O. F. K. Kalenda and J. Spurny, *On a difference between
  quantitative weak sequential completeness and the quantitative Schur
  property*, arXiv:1103.2975.
- Later answer: O. F. K. Kalenda, *Quantitative Schur property and measures of
  weak non-compactness*, arXiv:2505.12893.
- Status: `literature_already_answered`.
- Agent: `agent_lane_18`; model: `GPT5.6`; date: 2026-08-11.

The source left two closely related questions.  For real spaces it conjectured
that the 1-Schur and 1-strong Schur properties are not equivalent.  It also
left open whether the implication from 1-Schur to 1-strong Schur remains valid
for complex spaces.

The later paper answers both negatively, and explicitly cites the source.  Its
first graph example constructs a real Lipschitz-free space `F(M)` which has the
1-strong Schur property but fails every `c`-Schur property for `c<2`, hence
fails 1-Schur.  Its complexification example constructs a complex Banach space
with the 1-Schur property which fails the 1-strong Schur property (indeed it
fails the relevant constant-`c` condition for every `c<pi/2`).
