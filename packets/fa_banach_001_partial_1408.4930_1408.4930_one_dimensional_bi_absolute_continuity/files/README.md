# One-dimensional metric regularity for nonlinear order isomorphisms

This packet gives a new partial result for the differentiability questions in
arXiv:1408.4930.

For nonempty open intervals `I,J` in the real line and any `p,q >= 1`, every
order isomorphism `C^p(I) -> C^q(J)` has an associated homeomorphism whose
lower metric slope is positive and whose upper metric slope is finite at every
point. The homeomorphism and its inverse are locally absolutely continuous,
and its derivative is finite and nonzero almost everywhere.

The proof uses a Baire-category uniformization of the transformed affine
pencil, followed by a monotone telescoping partition and Banach--Zarecki.
