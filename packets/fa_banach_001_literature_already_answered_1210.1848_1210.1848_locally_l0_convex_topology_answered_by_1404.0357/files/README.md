# Literature answer packet for arXiv:1210.1848

This packet records the exact negative answer supplied by Zapata,
arXiv:1404.0357, to the gauge/topology/countable-concatenation question
cluster in arXiv:1210.1848.

The counterexample is a locally `L0`-convex topology on `E=L0`.  Although
the ambient module has the countable concatenation property, no equivalent
local base can consist of countable-concatenation-stable sets, the topology
is not generated by `L0`-seminorms, and every basic-neighborhood gauge is
identically zero.

The separate open problem asking whether `L0`-pre-barreled plus countable
concatenation implies `L0`-barreled is expressly outside this packet's
claim.

- `solution_packet.pdf`: compiled packet.
