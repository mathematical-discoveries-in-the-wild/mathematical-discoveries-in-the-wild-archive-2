# Verification

## Source-side checks

1. arXiv:0901.4386 defines the density of a lattice \(A\mathbb Z^2\) by
   \(D(\Lambda)=|\det A|^{-1}\).
2. Its displayed conjecture says that if \(G(h_n,\Lambda)\) is a frame, then
   \(D(\Lambda)>n\).
3. The immediately preceding discussion instead writes the sufficient system
   as \(G(h_{n-1},\Lambda)\), so the packet checks both index readings.

## Supporting-theorem checks

1. Faulhuber--Shafkulovska--Zlotnikov (JFAA 31:21, 2025), Proposition 3.8,
   states that \(G(h_9,3^{-1/2}\mathbb Z^2)\) is a frame.
2. For \(A=3^{-1/2}I_2\), \(\det A=1/3\), hence the source convention gives
   \(D(A\mathbb Z^2)=3\).
3. Literal indexing: \(n=9\), and \(3>9\) is false.
4. Shifted indexing: \(h_{n-1}=h_9\) means \(n=10\), and \(3>10\) is false.

## Duplicate check

Cheap run indexes were searched for arXiv:0901.4386, Gröchenig--Lyubarskii,
Hermite windows, and Gabor lattice density.  The existing arXiv:0804.4613
packet records only the critical-density family \(D=n+1\).  It does not record
the density-3 \(h_9\) counterexample to the displayed conjecture in this source.

## Classification

The implication is exact and requires no numerical inference.  The result is
therefore a full literature-implied counterexample, not a partial result or an
experimental observation.
