# The partially bicyclic semigroup \(S_2\) has \((F_{*s})\)

Status: **literature-implied affirmative answer (full answer to Question 3).**

Lau and Zhang ask in Question 3 on printed page 34 of arXiv:1207.4531
whether

\[
S_2=\langle e,a,b,c:ab=ac=e\rangle
\]

has the fixed-point property \((F_{*s})\). The answer is **yes**.

The decisive later result is Corollary 3.3 of Andrzej Wiśnicki,
*Around the nonlinear Ryll--Nardzewski theorem*, arXiv:1903.12123v2,
printed page 9. It says that every weak-star continuous, nonexpansive,
norm-distal semigroup action on a norm-separable weak-star compact convex
subset of a dual Banach space has a common fixed point.

For an arbitrary \((F_{*s})\)-representation of \(S_2\), write
\(A=T_a\), \(B=T_b\), and \(C=T_c\). The relations give
\(AB=AC=I\). Since all three maps are nonexpansive,

\[
\|x-y\|=\|ABx-ABy\|\leq\|Bx-By\|\leq\|x-y\|,
\]

so \(B\) is an isometry; the same argument applies to \(C\). Therefore the
semigroup generated by \(B,C\) acts isometrically and hence norm-distally.
Wiśnicki's corollary supplies a point fixed by both \(B\) and \(C\). It is
also fixed by \(A\), because \(Ax=ABx=x\), and consequently by all of
\(S_2\).

This is an agent-identified implication, not an explicit claim in the
supporting paper. Wiśnicki cites the Lau--Zhang paper but does not mention
its partially bicyclic semigroup or Question 3.
