# Endpoint sharpness via dilations (candidate new partial result)

Source: E. Liflyand, E. Ostrovsky, and L. Sirota, *Tensor, Sobolev,
Multiplicative and Convolution Operators in the Bide-Side Grand Lebesque
Spaces*, arXiv:0801.3404.

The source leaves the sharpness of its Sobolev trace inequality (in2) and
convolution inequality (in3) open. Its fixed power-log test functions miss the
predicted endpoint exponents by 1/n and 1, respectively.

This packet proves that both gaps disappear at the operator-norm level for the
two-sided power gauges explicitly analyzed in the source:

- normalized smooth dilations recover the full Sobolev endpoint exponents;
- normalized Gaussian dilations recover the full convolution endpoint
  exponents;
- the lower bounds match the source target gauges up to constants at both
  endpoints;
- the argument extends to positive-index regularly varying endpoint factors.

The result is partial because it does not determine exact constants or handle
every arbitrary generating function and every unimodular group. It is a
candidate new theorem and should receive expert review.
