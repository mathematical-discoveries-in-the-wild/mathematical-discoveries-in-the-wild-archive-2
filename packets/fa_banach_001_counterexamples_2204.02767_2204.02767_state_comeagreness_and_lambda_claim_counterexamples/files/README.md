# Two counterexamples in orthogonality of measures and states

Status: candidate full counterexamples; likely valid; human review
recommended.

The packet contains three connected results:

- Question 3.5 has a negative answer in its broad universal form.  If a state
  has support one in the bidual, its analytic singleton has empty
  strong-orthogonal complement.  This applies to `M_2(C)` and, nontrivially,
  to the infinite-dimensional algebra `K(ell_2)+C1`.
- Claim 3.7 is reversed: for the source's random recursive splitting law,
  `Lambda(mu^perp)=1` for every fixed measure `mu`.
- Consequently, `Lambda(A^perp)=1` for every countable family `A`; the same
  equality also holds for the uncountable analytic family of all Dirac masses.

The arbitrary uncountable analytic case of Question 3.6 and the search for
positive C*-algebra classes in Question 3.5 remain open.
