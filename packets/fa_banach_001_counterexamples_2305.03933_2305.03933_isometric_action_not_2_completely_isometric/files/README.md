# Candidate counterexample: an isometric action need not be completely isometric

## Source question

In Remark 2.4(i) of arXiv:2305.03933, Wang and Zhu ask whether their
crossed-product nuclearity theorem remains valid for merely isometric actions
and add that it is unclear whether an isometric action must be
\(p\)-completely isometric.

## Result

The subsidiary automatic-complete-isometry assertion is false as stated,
already for \(p=2\), a finite-dimensional unital operator algebra, and the
amenable group \(\mathbb Z_2\).

Let \(C_1=e_{21},C_2=e_{31}\) and \(R_j=C_j^{\mathsf t}\) in \(M_3\), and set
\[
 B_C=\operatorname{span}\{I,C_1,C_2\},\qquad
 B_R=\operatorname{span}\{I,R_1,R_2\}.
\]
Transpose is an isometric algebra isomorphism \(\theta:B_C\to B_R\).  On
\(A=B_C\oplus B_R\), swapping the two summands through \(\theta\) defines an
isometric automorphism \(\alpha\) of order two.  However, for
\[
 X=\begin{bmatrix}(C_1,0)&0\\(C_2,0)&0\end{bmatrix}\in M_2(A),
\]
one has \(\|X\|=\sqrt2\) while \(\|\alpha^{(2)}(X)\|=1\).  Thus the
\(\mathbb Z_2\)-action generated by \(\alpha\) is not 2-completely isometric.

## Scope

`candidate_counterexample_likely_valid (full negative answer to the auxiliary automatic-complete-isometry question at p=2)`.

The construction does **not** show that the source's crossed-product
\(p\)-nuclearity equivalence fails for merely isometric actions.  It also does
not settle the intended non-Hilbertian range \(p\ne2\); the row and column
spaces cease to have the same level-one norm there.  These are the explicit
obstructions that ended the upgrade loop.
