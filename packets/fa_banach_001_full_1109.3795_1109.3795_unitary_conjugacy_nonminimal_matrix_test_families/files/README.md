# Unitary conjugacy makes both matrix test families nonminimal

This packet gives candidate full negative resolutions of the two
matrix-minimality questions in arXiv:1109.3795.

For a matrix test psi and a constant unitary U, the conjugate U psi U*
imposes exactly the same admissibility condition: in the paper's positivity
criterion it is absorbed by the dummy-function substitution X -> U*X.
Both normalized test families are invariant under this conjugation and
contain noncentral tests for every N >= 2.  Deleting a small open
neighborhood disjoint from its conjugate leaves a proper closed family with
exactly the same admissible kernels and Schur-Agler class.

Thus both the constrained-Hardy test family and the annulus family are
nonminimal for every N >= 2.  Since scalar minimality is known, each family
is minimal exactly for N = 1.
