# arXiv:2012.13460 — smooth wavelet asymptotic and phase correction

This packet proves the phase-invariant version of Remark 7.4 for every
axisymmetric profile in `C_c^infty((0,pi))` satisfying the paper's cancellation
condition.  Thus the conjecture is true, with an absolute square on the
right-hand side, on a natural strong regularity class.

It also gives a full counterexample to the displayed formula as written for
complex-valued profiles.  The left side is invariant under multiplication of
the profile by `i`, whereas the ordinary square on the right changes sign.  A
nonzero real smooth compactly supported cancellation profile makes the Hankel
energy strictly positive, so its `i`-multiple is an explicit contradiction.

The proof closes the domination gap identified by the authors using four
ranges in the rescaled parameter `c = ell a`: cancellation at the origin,
uniform Hilb/Bessel oscillation for `1 <= c <= delta ell`, nonstationary phase
for `a` in a compact subinterval of `(0,infinity)`, and elementary `a^{-2}`
decay at infinity.
