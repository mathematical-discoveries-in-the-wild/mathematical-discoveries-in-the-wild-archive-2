# arXiv:2208.11431 — locally smooth-conical partial resolution

Status: `candidate partial result, proved`

The source asks whether the coaugmentation from the constant sheaf to
sheafified smooth singular cochains on `spec B` always induces an isomorphism
on hypercohomology.

The packet proves a local criterion: the answer is yes on every locally
smoothly contractible predifferentiable space.  It then verifies the criterion
for local products of manifold charts and positive integral weighted cones.
Consequently the answer is positive for isolated positively
weighted-homogeneous real algebraic singularities and for normal-crossing
real algebraic sets.

This is not a full solution for arbitrary algebraic sets.  The known local
Lipschitz contraction is not automatically smooth in the ambient-subspace
predifferentiable structure, and no general relative smoothing theorem was
found.
