# Polynomial and Hardy-equivalent cyclicity in P^2(mu)

Candidate substantial partial answer to Question 2.1 of arXiv:1809.10182.

## Main result

Under the full hypotheses in the source, a closed shift-invariant subspace
contains a nonzero polynomial if and only if it has finite codimension. Every
such subspace is exactly `d P^2(mu)` for a polynomial `d` whose zeros lie in
the open disk, and is therefore cyclic. In addition, all invariant subspaces
are cyclic whenever the `P^2(mu)` norm is equivalent to the Hardy norm; this
includes every rotationally invariant measure satisfying the source setup.

## Scope

The unrestricted question remains open for infinite-codimensional,
polynomial-free invariant subspaces associated with genuinely
non-Hardy-equivalent measures.
