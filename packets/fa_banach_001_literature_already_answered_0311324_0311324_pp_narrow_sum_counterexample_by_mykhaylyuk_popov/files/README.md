# PP-narrow sums on L1: later counterexample

The source paper arXiv:math/0311324 asks whether, for an arbitrary Banach
space `X`, the sum of two PP-narrow operators `L_1[0,1] -> X` must be
PP-narrow.

Mykhaylyuk--Popov answered no in JMAA 404 (2013), 554--561,
DOI `10.1016/j.jmaa.2013.03.008`.  They prove the stronger statement that
for every Köthe Banach space `E` there are a Banach range `Y` and two narrow
operators `E -> Y` whose sum is not narrow.  Setting `E=L_1[0,1]` answers the
source question.
