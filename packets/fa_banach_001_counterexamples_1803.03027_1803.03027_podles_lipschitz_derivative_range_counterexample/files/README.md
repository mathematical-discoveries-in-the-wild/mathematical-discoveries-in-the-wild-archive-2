# Maximal Podles Lipschitz derivatives need not lie in `SU_q(2)`

Status: **candidate counterexample; complete negative answer; likely valid; human review recommended**

## Source question

- Konrad Aguilar and Jens Kaad, *The Podles sphere as a spectral metric space*, arXiv:1803.03027v2.
- Target: Section 3, official PDF page 7.

After extending the coordinate derivations to the maximal Lipschitz algebra,
the authors ask whether the images of both extensions remain in the
`C*`-algebra `SU_q(2)`.

## Result

The answer is **no for both extensions**.  More precisely, the packet gives a
complete characterization on the entire diagonal algebra `C*(A)`.

Write `p_k=chi_{q^(2k)}(A)`, `f_k=f(q^(2k))`, and

```text
w_k = (f_k-f_(k+1)) q^(-k) sqrt(1-q^(2k+2))/(1-q^2).
```

Then

```text
f(A) is in Lip_Dq       iff  (w_k) is bounded,
partial_1(f(A)) in SU_q(2) iff  w_k -> 0.
```

Choose

```text
f_k = sum_(j=k)^infinity
      (1-q^2) q^j (-1)^j / sqrt(1-q^(2j+2)).
```

This defines a continuous real function on the spectrum of `A`, with
`f(0)=0`, and its normalized differences are exactly `w_k=(-1)^k`.
Consequently `x=f(A)` belongs to the maximal Lipschitz algebra while
`partial_1(x)` does not belong to `SU_q(2)`.  Since `x=x*` and
`partial_2(x)=-partial_1(x)*`, the second derivative also fails containment.

## Proof mechanism

The source's matrix-unit formula makes `partial_1(f(A))` an orthogonal
weighted backward shift.  Uniformly bounded finite truncations and lower
semicontinuity of the commutator seminorm prove the maximal-domain criterion.

For the range criterion, use the standard faithful representation

```text
rho(a)=weighted unilateral shift tensor 1,
rho(b)=q^N tensor U.
```

If the maximal derivative were left multiplication by an element `y` of
`SU_q(2)`, its columns would force

```text
rho(y)=sum_k w_k E_(k,k+1) tensor U*.
```

The image of `SU_q(2)` is the Toeplitz pullback generated by
`S tensor 1` and `K tensor C(T)`.  A weighted backward shift is Toeplitz only
when its weights converge; the pullback quotient then forces that limit to
be zero because of the surviving `U*` factor.  Conversely, null weights give
an element of `K tensor C(T)`.  This proves the exact `c_0` criterion.

Run:

```sh

  runs/fa_banach_001/solutions/counterexamples/1803.03027_podles_lipschitz_derivative_range_counterexample/code/verify_diagonal_weights.py
```

The script checks the exact normalized differences, finite weighted-shift
matrix entries, and the uniform truncation boundary estimate for four values
of `q`.  These are normalization audits, not the proof.

Local run indexes and fresh exact-phrase, title, author, maximal-Lipschitz,
derivative-range, and `SU_q(2)` searches on 2026-08-13 found no later explicit
answer to this range question.  A directly relevant later paper by the same
authors, *Polynomial approximation of quantum Lipschitz functions*
(arXiv:2104.04317), emphasizes that the graph-closure algebra is substantially
smaller than the maximal Lipschitz algebra and that maximal derivatives
generally require a von Neumann-algebraic framework.  Its approximation is in
`C*`-norm with a uniform Lip bound, not in graph norm; it does not state the
original `SU_q(2)` inclusion question, exhibit this counterexample, or give
the diagonal `ell-infinity/c_0` characterization.  It strongly anticipates the
negative mechanism, so novelty confidence is **moderate-low** for the yes/no
answer and **moderate** for the explicit characterization.

The separate introduction question about convergence as `q -> 1` was
answered by Aguilar--Kaad--Kyed, arXiv:2102.12761; it is not claimed as new
here.
