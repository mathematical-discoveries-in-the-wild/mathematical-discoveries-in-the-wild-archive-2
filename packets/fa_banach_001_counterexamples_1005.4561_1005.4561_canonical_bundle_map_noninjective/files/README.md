# Canonical bundle-map noninjectivity

Candidate full counterexample to Remark 4.10(b) of arXiv:1005.4561.

The essential `C([0,1])`-module `L^1([0,1])` has zero canonical fiber at
every point, so its map to the associated section module is the zero map.
