# arXiv:1607.01687 — Problem 5.5 answered by arXiv:2503.13146

Status: `literature_already_answered (Problem 5.5; full)`

The source paper asks in Problem 5.5 (arXiv PDF page 13) whether CH
implies that no Sierpiński set is productively Hurewicz.

Marciszewski, Pol, and Zakrzewski explicitly identify their Theorem 3.1
(arXiv:2503.13146, PDF page 6) as a strong positive answer to the same
problem, which they call Problem 7.5 of [ST1] and note was repeated as
Problem 5.5 of [ST2]. Their [ST2] is *Products of general Menger spaces*.
The theorem gives, for every Sierpiński set `S` of cardinality at least
`b`, a Hurewicz λ′-set `H` such that `S × H` is not Hurewicz; if `b=d`,
the product can be made non-Menger. Under CH, every Sierpiński set has
cardinality `c=aleph_1=b=d`, so the source question follows immediately.

The packet does not claim to settle source Problems 5.2–5.4. A bounded
search did not find comparably explicit later resolutions of those items.
