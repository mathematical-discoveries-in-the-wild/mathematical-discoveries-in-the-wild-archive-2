## Result

The connected compact homogeneous space `X = T` and its rotation group
`G = T` give simultaneous negative answers to Questions 5.1 and 5.4.
For every `0<a<1`,

```text
K_a(z,w) = 1 + a z conjugate(w)
```

is continuous, nondegenerate, positive semidefinite, nowhere zero, and
exactly rotation-invariant.  If `0<a<b<1`, then `K_a` and `K_b` have the
same multiplier class (indeed, only constant unimodular multipliers) but
are not positive scalar multiples.  This refutes Question 5.1.

For Question 5.4, use any one `K_a` and the continuous homomorphism
`alpha=0`.  All covariance hypotheses hold, but `K_a` is not a constant
function on `T x T`.
