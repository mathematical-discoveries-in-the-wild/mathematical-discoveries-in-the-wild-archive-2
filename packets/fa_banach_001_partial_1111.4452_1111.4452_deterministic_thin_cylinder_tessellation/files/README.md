# Deterministic tessellation of the Gaussian thin-cylinder obstruction

This packet gives a new partial result for the hyperplane-tessellation
conjecture in arXiv:1111.4452.

The lifted thin-cylinder family used by arXiv:2508.05194 to disprove the
Gaussian-random specialization is not an obstruction to the original
not-necessarily-Gaussian conjecture. An explicit equally spaced projective
grid in the cylinder-axis/lift plane gives a deterministic uniform
tessellation with `Theta(eta^{-1})` hyperplanes, whereas iid Gaussian
hyperplanes require `Theta(eta^{-3})` on the same family.

Files:

- `solution_packet.pdf`: self-contained theorem, proof, application, scope,
  and references.
- `source_paper.pdf`: arXiv:1111.4452.
- `supporting_2025_paper.pdf`: arXiv:2508.05194.
- `main.tex`: source of the packet.
- `VERIFICATION.md`: mathematical and artifact audit.

The unrestricted deterministic conjecture remains open.
