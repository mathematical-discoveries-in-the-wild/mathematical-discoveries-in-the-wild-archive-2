\section{The source question}

For a product system $\mathcal E$ and a unit $u$, Liebscher associates a
stationary factorizing random-set measure type $\mathcal M^{\mathcal E,u}$.
Note 3.11 asks first whether
\[
  \mathcal M^{\mathcal E,u}=\mathcal M^{\mathcal E,v}
  \qquad(u,v\text{ normalized units}),
\]
so that this construction would be independent of the chosen unit. The note
then records a sufficient mechanism: the equality follows whenever some
automorphism $\theta$ of $\mathcal E$ satisfies
\[
  v_t=\theta_tu_t\qquad(t>0).
\]
It explicitly calls the universal existence of such an automorphism an open
problem.

\section{The later counterexample}

Tsirelson's paper is directed at precisely this transitivity conjecture. Its
Theorem 1.10 states:
\[
\boxed{\begin{minipage}{0.82\linewidth}
There exists an Arveson system of type $\mathrm{II}_1$ such that the action of
its automorphism group on the set of normalized units is not transitive.
\end{minipage}}
\]
Thus there are a product system $\mathcal E$ and normalized units $u,v$ for
which no automorphism $\theta$ has $v_t=\theta_tu_t$ for every $t>0$.
This is a literal counterexample to the universal assertion in the final
sentence of Liebscher's Note 3.11.

\section{Scope and logical crosswalk}

It is important not to overstate what the counterexample proves. The source
passage contains two statements:
\begin{enumerate}
  \item unit-independence of $\mathcal M^{\mathcal E,u}$;
  \item transitivity of $\operatorname{Aut}(\mathcal E)$ on normalized units.
\end{enumerate}
Liebscher proves that (2) would imply (1). Tsirelson proves that (2) is false.
The converse implication was not asserted, so the counterexample does not by
itself show that the two measure types in (1) differ. Accordingly this packet
claims a complete negative answer only to the automorphism-transitivity
subquestion, not to the unit-independence question.

The matching quantifiers are exact:
