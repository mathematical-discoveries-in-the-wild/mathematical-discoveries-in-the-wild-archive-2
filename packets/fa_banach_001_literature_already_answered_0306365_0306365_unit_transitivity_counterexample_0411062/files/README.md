# Unit transitivity in Arveson systems: literature counterexample

Status: **literature already answered (scoped negative answer)**. No new theorem is claimed.

Liebscher's arXiv:math/0306365, Note 3.11, asks whether for every product
system an automorphism can carry any normalized unit to any other normalized
unit. Tsirelson's arXiv:math/0411062 answers that statement negatively:
Theorem 1.10 constructs a type II_1 Arveson system whose automorphism group is
not transitive on its normalized units.

Scope warning: Liebscher first asks the stronger/different question whether the
measure types M^{E,u} and M^{E,v} are always equal. Transitivity would imply
that equality, but failure of transitivity does not by itself disprove it. This
packet therefore clears only the explicitly stated automorphism-transitivity
subquestion.
