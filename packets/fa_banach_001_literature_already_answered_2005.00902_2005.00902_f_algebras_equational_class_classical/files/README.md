# arXiv:2005.00902 — Questions 8.3 are classically answered

This packet records that the three homomorphic-image questions for
`f`-algebras are literature-answered, despite being presented as open in the
source paper. arXiv:2511.13299 explicitly states that `f`-algebras form an
equational class, citing Birkhoff's *Lattice Theory*, Theorem VII.8, and says
that free `f`-algebras have been known since 1956.

The packet also gives a self-contained verification via two explicit
identities and a direct quotient proof. It is not presented as novel.
