# Tensor-GUE conjecture answered by arXiv:2205.07695

Status: `literature_already_answered`

## Source conjecture

Ben Hayes, *A random matrix approach to the Peterson--Thom conjecture*,
arXiv:2008.12287.

Theorem 1.1(iii), arXiv PDF page 3, formulates the needed strong convergence
of
\[
 (X^{(k)}\otimes I_k,\ I_k\otimes Y^{(k)})
\]
for two independent GUE families of the same dimension, and proves that this
statement implies the Peterson--Thom conjecture through 1-bounded entropy.
The same random-matrix assertion is restated as a conjecture in Section 4.

## Explicit later answer

Serban T. Belinschi and Mireille Capitaine, *Strong convergence of tensor
products of independent G.U.E. matrices*, arXiv:2205.07695, prove precisely
this statement. Their Theorem 1, arXiv PDF page 3, gives the polynomial norm
convergence almost surely, which is stronger than the convergence in
probability requested by Hayes. The abstract and page 3 explicitly record
that Hayes's implication then proves the Peterson--Thom conjecture.

This is a literature identification, not a new mathematical result.
