# Dimension-gap obstruction to non-Hilbertian tangents

Status: candidate substantial partial result, likely valid.

This packet addresses Question 1.5 of Lučić–Pasqualetto–Rajala, arXiv:2111.06777. At almost every point of an `n`-dimensional differentiability chart in an infinitesimally Hilbertian PI space, every tangent of Hausdorff dimension `< n+1` is infinitesimally Hilbertian. Equivalently, a non-Hilbertian tangent must gain at least one full Hausdorff dimension. For an Ahlfors `Q`-regular source this gives an affirmative answer wherever `Q<n+1`, including every `1<=Q<2` PI space.

The unrestricted question remains open.
