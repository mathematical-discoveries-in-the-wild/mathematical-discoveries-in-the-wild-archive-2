# Classical cube-maximal subcase of Conjectures 2.38 and 2.39

Status: `literature_implied_answer (proper subcase)`.

The source is Zoe Nieraeth, *Extrapolation in general quasi-Banach function
spaces*, arXiv:2211.03458. Conjectures 2.38 and 2.39 appear together on PDF
page 26. They concern boundedness of an abstract-basis maximal operator on the
rescaled space `X_{r,s}` and related convexifications.

Andrei K. Lerner, *A note on the maximal operator on Banach function spaces*,
arXiv:2404.15671 / J. Geom. Anal. 35 (2025), Article 97, explicitly restates
the two conjectures as Conjectures 1.1 and 1.2 and proves them in Section 4,
PDF pages 10-11, for Banach function spaces on `R^n` and the standard
Hardy-Littlewood maximal operator over cubes.

This is a complete affirmative answer in that canonical setting, but only a
proper subcase of the source formulations. It does not settle the abstract
basis setting or the quasi-Banach range allowed in Conjecture 2.38.
