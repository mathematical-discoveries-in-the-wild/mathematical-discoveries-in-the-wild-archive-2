# Trivial-line symmetric-power counterexample

Status: `full_counterexample` to the second question in Remark 5.9 of
arXiv:1402.0458, exactly as written.

Take the trivial holomorphic line bundle `L = O_X` over any compact connected
Riemann surface. Every symmetric power `S^k L = L^k = O_X` is generated by the
constant section. But a Griffiths-positive metric would give a strictly
positive curvature representative of `c_1(L)=0`, impossible after integration.

The source explicitly distinguishes Griffiths nonnegative from Griffiths
positive curvature. Its Theorem 4.6 gives nonnegative curvature for globally
generated bundles, which is consistent with the flat metric on the trivial
bundle. Thus the cited line-bundle statement must be read as semipositivity, or
must include an additional strictness hypothesis.
