# Little-Bloch and VMOA automorphic spectra: already answered

Status: `literature_already_answered`.

Allen--Le--Pons (Involve 2016; arXiv:2207.08992) ask in Section 5, PDF
page 12, for the spectra of composition operators induced by parabolic or
hyperbolic disk automorphisms on the little Bloch space and on `VMOA`.

Matthew A. Pons, *The Spectrum of a Composition Operator with Automorphic
Symbol*, Mediterranean Journal of Mathematics 14:53 (2017), DOI
`10.1007/s00009-017-0858-1`, explicitly answers both:

- Theorem 4: `sigma_B0(C_phi) = partial D` for parabolic or hyperbolic `phi`.
- Theorem 5: `sigma_VMOA(C_phi) = partial D` for parabolic `phi`.
- Theorem 6: `sigma_VMOA(C_phi) = partial D` for hyperbolic `phi`.

The supporting paper cites the source and states that these are the remaining
spectra to compute, so this is an explicit literature answer rather than an
agent-inferred implication.
