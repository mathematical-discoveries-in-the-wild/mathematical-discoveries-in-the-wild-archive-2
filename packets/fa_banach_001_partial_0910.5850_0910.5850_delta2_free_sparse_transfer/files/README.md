# Delta2-free sparse transfer for arXiv:0910.5850

Status: substantial partial result, likely valid, pending human review.

The packet proves that the source paper's three-function modular and
Luxemburg-norm Gagliardo--Nirenberg conclusions require no `Delta_2`
assumption on `M` on any open domain with Lebesgue measure, provided `P,Q`
are Young functions.  It also gives an abstract modular sparse-transfer
criterion and verifies it for densities globally comparable to Lebesgue
measure.  The arbitrary nondoubling Hardy-weighted case remains open.
