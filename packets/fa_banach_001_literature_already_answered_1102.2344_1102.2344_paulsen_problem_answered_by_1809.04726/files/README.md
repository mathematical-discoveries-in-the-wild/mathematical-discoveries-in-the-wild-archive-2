# The Paulsen Problem Answered by arXiv:1809.04726

Status: `literature_already_answered`

## Source question

Jameson Cahill and Peter G. Casazza, *The Paulsen Problem in Operator
Theory*, arXiv:1102.2344, Operators and Matrices 7 (2013), 117–130.

Problem 1.1 on arXiv PDF page 1 asks for a quantitative bound on the squared
distance from an epsilon-nearly equal-norm, epsilon-nearly Parseval frame to an
equal-norm Parseval frame. The source emphasizes the fundamental question of
whether the bound can be independent of the number of frame vectors.

## Explicit later answer

Linus Hamilton and Ankur Moitra, *The Paulsen Problem Made Simple*,
arXiv:1809.04726, Israel Journal of Mathematics 246 (2021), 299–313,
explicitly identifies and cites the Cahill–Casazza Paulsen problem. Theorem 1
on arXiv PDF page 3 proves that every epsilon-nearly equal-norm Parseval frame
in R^d is within squared distance at most 20 epsilon d^2 of an equal-norm
Parseval frame. This supplies a bound independent of the number of vectors.

The supporting authors state that Kwok, Lau, Lee, and Ramachandran had already
resolved the problem with an O(epsilon d^(13/2)) bound; their own theorem gives
a simpler proof and improves the dimension dependence.

Scope: this packet records the standard real finite-dimensional Paulsen
problem. It does not settle the sharp dimension dependence between the known
Omega(epsilon d) lower bound and O(epsilon d^2) upper bound, nor does it classify
the prescribed-norm and prescribed-frame-operator generalizations in Section 5
of the source.
